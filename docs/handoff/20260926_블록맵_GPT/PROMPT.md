# GPT 인계 프롬프트 — XOOX(수스) 블록 맵 제작

아래 전체를 GPT에게 그대로 붙여 넣는다. 첨부 이미지는 `concepts_v2/`와 `current_renders/` 안의 PNG다.

---

## 너의 역할

너는 웹 게임 **XOOX(프로젝트명 '수스')**의 **블록(복셀) 맵 제작자**다. Blender 5.2를 파이썬 스크립트(`blender -b -P ...`)로 돌려 맵을 만든다. 결과는 glb로 내보내 웹 툴(three.js 유닛 랩)에서 확인한다.

이미 1차 결과물(i21 섹터, 정화후)이 있다. 이것을 이어받아 **시안 품질까지 끌어올리고, 나머지 섹터로 넓히는 것**이 일이다.

## 게임 배경 (필요한 것만)

- 오염된 섬을 **정화**하는 게임이다.
  - 정화 전: 보라·검정 블록 땅, 죽은 나무, 떠다니는 보라 큐브
  - 정화 후: 민트 들판, 나무, 꽃, 연못, 작은 집
  - 같은 지형이다. **크기·위치는 같고 색과 소품만 바뀐다.**
- 정화는 단계로 번진다: 0 → 0.22 → 0.55 → 0.85 → 1.0. 코어에서 원형으로 시안(`#0FBEC7`) 링이 퍼지며 색이 돌아온다.
- 캐릭터는 이미 블록 치비(B2 방랑자, glb 있음)다. 맵도 같은 블록 문법이어야 한다.
- **지금은 "정화후" 모습만 먼저 만든다.** 정화전 판은 그 다음이다.

## 반드시 지킬 스케일·규칙 (사용자 확정)

1. **사람 키 1.5m 기준으로 모든 크기를 잡는다.** 시안 README의 "character ~2m"는 무시하고 1.5m를 쓴다.
2. **섬 약 1km, 섹터 3×3 (한 칸 333m)** 은 지도 좌표 기준이다. **게임에서 그리는 섹터 한 변은 110m**다(코드 `world_m = 110`).
3. **걸을 수 있는 칸 = 십자 5칸:** i01(북) · i10(서) · i11(중앙) · i12(동) · i21(남, 시작점·선착장). 네 귀퉁이(i00 · i02 · i20 · i22)는 걸을 수 없는 배경이다.
4. **크기표 (1.5m 기준):**

   | 요소 | 크기 |
   |---|---|
   | 지형 블록 | **30cm** |
   | 소품 블록 | 6~30cm |
   | 나무 | 2.5~4.5m |
   | 작은 집 | 바닥 약 3.6×3m · 벽 2.1m |
   | 분수 | 지름 3~5m |
   | 선착장 | 폭 2m · 길이 10~15m |
   | 길 | 폭 2~3m |
   | 턱 한 단 | 30~60cm (1~2블록) |
   | 먼 언덕 | 한 층 1.5m |

5. **"집은 들판보다 아주 작게."** 들판이 주인공이다. 구역은 칸이 아니라 무리로 배치한다. **맵 안에 설계용 점선·격자선을 넣지 않는다.**
6. **첫 시안(분위기용)처럼 집·절벽을 크게 만들면 실패다.** v2 시안(`concepts_v2/`)의 현실 스케일을 따른다.

### 1차 구조 (`scripts/build_i21.py`)

- **지형:** 110m를 30cm 격자(367×367)로 나눠 칸마다 높이 단·표면(민트/모래/길/물 바닥)을 정한다.
  - 같은 줄의 같은 칸끼리 한 면으로 합쳐서, 지형 면이 약 6천 개뿐이다.
  - 턱 경계는 사인·노이즈로 굽이친다.
- **블록 결은 재질이 그린다** (월드 좌표 노드).
  - 30cm 칸마다 밝기 ±9% 흔들림, 넓은 노이즈 얼룩 ±7%, 칸 모서리 음영 −22%.
  - 기본색은 꼭짓점 색(Col).
- **바다:** 2m 격자 물 면. 해안 거리로 얕은 청록 → 깊은 바다 그라데이션을 꼭짓점 색으로 칠하고, 약하게 발광시킨다. 해안에 거품 큐브.
- **소품 (큐브 조립):**

  | 소품 | 모양 |
  |---|---|
  | 나무 | 줄기 + 둥근 수관 겉면 블록 |
  | 바위 | 3~6개 큐브 + 이끼 |
  | 선착장 | 판자 + 기둥 + 시안 띠 |
  | 작은 집 | 벽 · 문 · 창 · 계단 지붕 · 굴뚝 |
  | 풀 덤불 | 밑둥 + 잎 8~12 |
  | 꽃 | 4색 |
  | 반짝이 | 시안 발광 |

- **배치:**
  - 남쪽 굽이진 해안과 동쪽 만, 선착장(x 55)에서 북쪽으로 굽이진 길
  - 연못, 턱 2단 + 서쪽 고원
  - 나무 숲 7무리, 해안·들판 바위, 북동쪽 집 1채, 반짝이 70개
  - 먼 북쪽 계단식 언덕 5개, 구름
- **풀·꽃:** 파티클 인스턴스(풀 2.2만 · 꽃 3천). 1.5m 칸마다 노이즈 밀도를 줘서 덤불로 뭉친다.
- **조명:**
  - Standard 뷰 변환(AgX는 파스텔을 회청으로 바랜다).
  - 카메라에 보이는 하늘(연파랑→지평선 크림 그라데이션)과 물체를 비추는 빛(중립 따뜻한 환경광)을 Light Path로 나눈다.
  - 남서쪽 해.
- **사람 비교:** B2 방랑자 glb(`C:\xoox\data\tools\unit_lab\character\wanderer_B2.glb`)를 1.5m로 맞춰 선착장 옆에 둔다.

### 1차에서 겪은 함정 (다시 밟지 말 것)

- **월드 볼륨 안개:** 110m 스케일에서 빛을 전부 먹어 화면이 검게 나온다. 쓰지 말 것.
- **파란 하늘빛 + AgX:** 민트가 `#c8fcff` 청록으로 뜬다. 하늘과 조명을 분리할 것.
- **방출체를 `hide_render`:** 파티클도 같이 사라진다. 방출체 보이기(show_instancer_for_render)만 끌 것.
- **파티클 인스턴스 방향:** X축으로 +90° 세워진다. 원본을 미리 반대로 눕혀 둘 것.
- **긴 면에 밀도 가중치:** 꼭짓점이 적어 뭉침이 안 된다. 1.5m 칸 방출 면을 쓸 것.
- **Blender 5.x:** 컴포지터 노드 이름이 바뀌었다(`CompositorNodeMixRGB` 없음).
- **렌더 파일 경로:** 상대 경로면 엉뚱한 곳에 저장된다. 항상 절대 경로를 쓸 것.
- **glb GPU 인스턴싱:** `export_gpu_instances`가 파티클에서 풀어낸 오브젝트를 묶지 못한다. 툴(`MapLab.ts`)에서 같은 지오메트리끼리 InstancedMesh로 묶는다.

## 시안 대비 남은 차이 (다음 할 일 1순위)

1. **풀:** 막대처럼 곧고 굵기가 같다. 시안 03은 끝이 가늘고 살짝 휜 잎, 더 부드러운 덩어리다.
2. **턱 경계:** 얇은 짙은 선으로 보인다. 시안은 턱 윗면 가장자리 풀이 흘러내리고 옆면이 밝은 민트다.
3. **구름:** 평평한 흰 공이다. 시안은 뭉게 블록 구름(파스텔 분홍빛 흰색).
4. **들판 바닥:** 칸 격자가 너무 규칙적이다. 시안은 칸마다 높낮이가 아주 조금(1~3cm) 달라 울퉁불퉁한 결이 있다.
5. **전경:** 이웃 섹터가 없어 섹터 가장자리가 직선으로 잘린다.

## 할 일 순서

1. **i21 다듬기** (위 1~4). 시안 03과 같은 구도로 렌더해 나란히 비교한다(항상 시안 왼쪽/위, 결과 오른쪽/아래).
2. **i11 (중앙)** 을 시안 04처럼 만든다: 교차하는 모래 길, 파스텔 집 몇 채(아주 작게), 둥근 나무, 꽃 덤불, 먼 계단식 언덕.
3. **십자 5칸 연결** (i01 · i10 · i11 · i12 · i21). 칸 경계에서 지형·길이 이어지게 하고, 귀퉁이 4칸은 배경 육지나 바다로 둔다. 섬 전경은 시안 01 clean처럼.
4. **정화전 판:** 같은 지형·소품 위치에 Blight 팔레트(보라·검정 블록, 죽은 나무, 떠다니는 보라 큐브). 블록마다 정화전·정화후 두 색과 정화 순서(코어에서 거리)를 꼭짓점 속성에 넣는다. 게임 셰이더가 시안 링을 따라 색을 바꾸게 한다.
5. 섹터마다 glb로 내보낸다(`export_i21.py` 방식). 유닛 랩 `MapLab.ts`에 버튼을 추가해 확인한다.
