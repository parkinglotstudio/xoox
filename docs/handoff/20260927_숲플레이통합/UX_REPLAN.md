# 숲 플레이 UX 재설계 (2026-09-27)

## 문제

현재 `forest-play-tool.html`은 6개 탭(맵/캐릭/전투/건설/유닛/펫)과 동등한 버튼 나열로 **무엇이 주 행동인지** 알기 어렵다.

- 카메라 슬라이더가 사이드 패널과 인게임 미리보기에 **중복**
- 설치 경로가 3갈래(슬롯 피커 · 건설 그리드 · 카탈로그 DnD)로 **겹침**
- 맵 오브젝트 배치와 유닛 카탈로그가 **역할 중복**
- 인게임 미리보기가 항상 펼쳐져 **뷰포트 공간 잠식**
- 전투/건설 **버튼 벽**

## 목표 UX

상단(또는 사이드 최상단) **모드 바 4개** — 한 번에 하나만 활성.

| 모드 | 목적 | 사이드 내용 | 맵 커서/힌트 |
|------|------|-------------|--------------|
| **플레이** | 이동·사냥·캐릭/펫 | PLAY/STOP, 자동사냥, 캐릭 칩, 애니 퀵 필, 펫, 카메라 고급(접힘) | WASD · F |
| **배치** | 카탈로그 DnD | Units 카탈로그(+미리보기). 맵 소품은 보조 토글 | DnD · 슬롯 스냅/자유 |
| **건설** | 패드 설치 | 선택 슬롯 + 설치/철거. 데모는 `<details>` | 빈 패드 클릭 → 종류 칩 |
| **살펴보기** | 검사·분위기 | 정화/오염, 메시 픽 정보. **설치 없음** | 클릭 검사 |

### 추가 규칙

1. 인게임 미리보기: 기본 **접힘**(좌하단 칩). 펼치면 카메라 슬라이더 표시.
2. 상단 세부 툴 링크: 짧은 라벨 유지.
3. 상태바 한 줄: `모드 · 선택 · 단축키` (+ 기존 FPS/좌표).
4. 한글 UTF-8 정상화(모지바케 제거).
5. forest-map-tool / `src/tools/forestMap/*` **무수정**.

## 구현 범위 (이번 패치)

### Part A — 애니메이션 배선

- `PlayBuild`: GLB `animations` → 설치 루트에 `AnimationMixer`, idle 우선 루프, `update(dt)` / `tick`에서 갱신. Map으로 dispose.
- 자유 프롭(`placeCatalogFreeProp`): 동일하게 `registerFreePropAnim`.
- `PlayCombat`: 몬스터 GLB 클립 보관, `SkeletonUtils.clone` 인스턴스 + per-mob mixer. 이동 시 walk/run, 정지 시 idle.
- 캐릭터: wanderer-anim 스타일 **퀵 필**(대기/걷기/뛰기/쏘기…) — 존재하는 클립만.
- 선택 슬롯 클립 HUD(건설 모드) — nice-to-have.

### Part B — UX

- 모드 바 + 패널 재배치 (`forest-play-tool.html` + `main.ts` `setMode`).
- 미리보기 접기, 카메라 고급 `<details>`, 맵 소품 토글, 상태바 모드 라인.

- 맵 소품 DnD는 기존 “플레이어 위치 배치” 유지(토글 뒤).
- forest-map 쪽 카메라/렌더 파이프라인 변경 없음.
