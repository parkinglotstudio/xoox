# 블록 맵 공통 연결 방법

정본 목록: `C:\xoox\data\maps\block\manifest.json` (브라우저 URL `/maps/block/manifest.json`)

공통 로더: `C:\xoox\src\maps\blockMap\BlockMap.ts`

## 다른 툴에서 사용

```ts
import { loadBlockMap } from "../../maps/blockMap/BlockMap"; // 호출 파일 위치에 맞춰 상대경로 조정

const result = await loadBlockMap({
  sector: "i21",       // i21 또는 i11
  state: "purified",   // 기본 정화 후 / 정화 전은 polluted
  actors: false,       // true이면 몬스터 12마리 포함
});
scene.add(result.view.root);
// 매 프레임: 애니메이션 및 거리별 풀 생략
result.view.tick(deltaSeconds, camera.position);
// 교체/종료할 때 GPU 자원 정리
result.view.dispose();
```

`result.mood`에는 하늘·안개 색과 조명 세기가, `result.entry.cameras`에는 Blender 좌표 기준 카메라 위치가 들어 있다. 카메라는 함께 내보내는 `bl(x,y,z)`로 변환한다. 맵은 Blender에서 제작한 GLB이며 원경은 저부하 원통에 입힌 PNG다.

## 제작 중 업데이트

- GLB를 다른 툴 폴더에 복사하지 않는다. 공통 로더와 공통 목록을 사용한다.
- 로더는 목록을 `cache: no-store`로 읽는다. `readBlockMapManifest()`의 `revision`이 바뀌었을 때 새 맵을 로드한다.
- 새 맵 로드 성공 후 이전 맵을 `dispose()`한다. 로드 실패 시 기존 맵을 유지한다.
- 유닛 랩은 활성 맵 화면에서 10초마다 버전을 확인하며, ‘최신 맵 다시 불러오기’로 수동 갱신할 수도 있다. 다른 툴도 같은 방식으로 연결해야 자동 갱신된다.
- 제작자는 버전별 폴더에 모든 GLB를 먼저 저장하고 검증한 다음, 목록의 경로와 revision을 마지막에 변경한다. 이전 버전은 남겨 둔다.

## 좌표·범위

- 섹터 110m, 사람 1.5m, 지형 블록 0.3m. Blender `(x,y,z)` → Three `(x,z,-y)`.
- 정화 전·후는 같은 지형과 소품 배치를 사용한다. 정화 전에는 풀·꽃이 숨겨지고 나무가 마른 나무로 교체된다.
- `background_*_nonwalkable`은 원경 이음을 위한 배경 면이다. 이동·충돌 대상으로 사용하면 안 된다.
- 현재 로더는 시각 맵을 제공한다. 이동 가능 영역, 충돌·내비게이션, 부분 정화 링은 게임 툴의 별도 연결 대상이다.
- 원본 GLB만 로드하면 지면 셰이더·원경·거리별 풀 표시가 빠진다. 같은 화면을 원하면 공통 로더를 사용한다.

확인 화면: `http://localhost:5179/unit-lab-tool.html?map=1`
