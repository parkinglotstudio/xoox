## 상태 값

- `대기` — 할 일 없음 / 다음 지시 대기
- `작업중` — 지금 손대고 있음
- `막힘` — 질문·승인 대기 (보고/채팅에 이유)
- `완료` — 방금 한 일 끝남. 보고서 경로를 최근 보고에 적고, 곧 `대기`로 돌려도 됨

## 규칙

1. 작업 **시작 직후** 자기 행을 `작업중`으로 바꾸고, 한 줄로 지금 하는 일을 쓴다.
2. 작업 **끝나면** 보고서 쓴 뒤, 최근 보고에 파일 경로를 넣고 상태는 `완료` 또는 `대기`.
3. 막히면 `막힘` + 이유 한 줄.
4. 다른 에이전트 칸은 건드리지 않는다.
