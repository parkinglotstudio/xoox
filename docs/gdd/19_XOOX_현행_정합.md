# 19. XOOX 현행 정합 — 발주 시놉/시나리오 ↔ 현재 게임

발주 원본(노션 04 시놉시스 / 05 구역01 시나리오)은 **서사·용어의 소스**로 보존한다.
이 문서는 그 서사를 **현재 구현된 기계(슬롯·구조 조우·60일)** 에 맞춰 옮긴 정합 기준이다.
(원본은 예전 설계 — Wave 정화전투·팀3고정·15일 구역 — 기준이라 기계가 다르다.)

## 1. 서사는 유지, 기계는 현행으로

| 요소 | 발주 원본(구) | 현행 게임(정합) |
|---|---|---|
| 정화 | Wave 전투(정화 빔·타락 게이지) | **구조 조우 = 5턴 2지선다 태그 매칭 퍼즐**(정화도 0→100%) + 별도 액션 전투 |
| 팀 | 1→3마리 고정 | **성장형 슬롯 2→3→4→5 + 교체 + 도감** |
| 기간 | 15일 구역 | **60일 · 4스테이지(15일씩) · 보스 30/60** |
| 보스 | 파이널 Memory Battle(대화 정화) | 30일=액션 보스 / **60일=Memory Battle(대화 선택 정화)** ← 개발 예정 |
| 첫 조우 | Wave 1 고정 | **2일차 첫 조우 보장** 후 30% 랜덤 |
| 지나치기 | 있음 | 있음(풀에 남아 재조우) |

## 2. 유지하는 서사·용어 (소스 = 발주 원본)

- **세계관**: 버림받은 반려동물의 안식처 = 투명 반구형 우주선 **XOOX (Rainbow) Island**. "눈물이 무지개가 되는 곳."
- **4리더 + 주인공**
  - Tigon — 선장(개+고양이 믹스, 섬을 이끔). 섬을 떠나면 힘·기억 상실 → 최종 회복 대상
  - Piper — 수호자(셰퍼드). 직관·보호 본능. 눈물 보이면 화냄
  - Nashui — 치유자(고양이). 새침·코믹. 타락의 발단
  - Olmas — 정화자(신비·날개). 어둠에서 동료 도울 때 날개. "신호를 감지"
  - **방랑자(플레이어)** — 다리가 불편한 버림받은 반려동물. 화를 놓으며 성장
- **성장 구조(만화식)**: 희망→좌절→배신→분노→도약→눈물→구원→성장
- **용어 통일**: Empathy(공감) / Heal(치유) / Courage(용기) / **Purify(정화)**
- **로그 3계층**: [시나리오] 상황·백스토리 · [코멘터리] 리더 실시간 반응 `— 캐릭터명` · [전투/구조 로그]
- **핵심 메시지**: "모두 가족이다 — 버림받았어도, 다쳤어도, 타락했어도."

## 3. XOOX다움을 위한 개발 항목 (제네릭 카피바라고 → XOOX)

1. **코멘터리 계층** — 구조/전투/이벤트 순간에 Piper·Nashui·Olmas 반응 대사(로그에 `— 캐릭터명`). 데이터: `commentary_config.csv` [진행]
2. **진입 컷신** — 4리더 + 방랑자 도입(구역 시작 시). [진행]
3. **Memory Battle 최종보스(60일)** — 스킬 루프 정지 → 대화 선택지로 정화. [예정]
4. **시그니처 펫 고정 보상** — 뭉치(스테이지1)·하늘이(스테이지2)·열두(도베르만, 최종 보스 보상, 영구). 나머지는 제네릭 조우 풀.
5. **공감(Empathy) 시스템 재도입 여부** — 정화·대화의 핵심 자원(원본). 재도입 시 조우/보스 깊이↑, 개발량↑. [결정 필요]
