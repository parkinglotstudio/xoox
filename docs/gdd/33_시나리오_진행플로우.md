## 0. 왜 다시 쓰나

지금 프로토는 **기능은 많은데 거점이 없다.**  
인트로 직후 하루 루프·탐방·전투·구조·스크랩북·미니게임이 같은 화면에 겹쳐, “무엇을 하러 나온 여정인지”가 흐려진다.

지시자 요청(2026-08-08):

1. **로비**로 시스템을 모은다  
2. **시나리오**를 같이 손본다  
3. **진행 플로우**를 다시 연구한다  
4. 시나리오 성격에 맞게 **파견 · 탐구 · 도전 · 정화**의 역할을 나눈다  

본 문서는 그 네 가지의 **시나리오·플로우 축**이다.

## 1. 시나리오 성격 【확정 제안】

### 1-1. 한 줄

> **버림받은 방랑자가, 무지개섬을 거점으로 오염된 바깥을 오가며  
> 아이들을 구조·정화하고, 선장 Tigon의 잃어버린 기억을 되찾는 60일 구조 오디세이.**

### 1-2. 톤

| 축 | 성격 |
|---|---|
| 감정 | 코믹·귀엽고 밝게. 공포·잔혹 배제 |
| 주제 | “모두 가족이다 — 버림받았어도, 다쳤어도, 타락했어도” |
| 리듬 | 편안하게 하루를 넘기되(버튼), 발품 팔면 비밀이 보임(탐구) |
| 적 | **죽이는 빌런이 아님.** 오염·산업 잔재(도전) / 오염된 생명(정화·구조) |

### 1-3. 공간의 두 축 【핵심】

| 공간 | 이름 | 역할 |
|---|---|---|
| **거점** | 무지개섬 (로비) | 가족·휴식·파견·기록·준비 |
| **바깥** | 오염 구역 여정 (탐방+일차) | 탐구·도전·정화·구조 |

카피바라고식 “끝없이 전진만 하는 로그”에서  
XOOX식 **“섬에 돌아와 아이들을 보고, 다시 나가는”** 호흡으로 바꾼다.

### 1-4. 인물 역할 (서사 장치)

| 인물 | 로비에서의 존재 | 여정에서의 존재 |
|---|---|---|
| 방랑자(플레이어) | 섬을 떠났다가 돌아오는 주체 | 탐구·도전·정화의 손 |
| Tigon | 부재/희미한 흔적(기억조각으로만) | 결말 Memory Battle의 대상 |
| Piper | 수호·출발전 한마디 | 전투·위험 코멘터리 |
| Nashui | 섬 일상·유혹/휴식 톤 | 분기·치유 코멘터리 |
| Olmas | 신호·단말기/지도 안내 | 발견·정화 신호 |
| 합류 아이들 | **파견으로 섬을 지키는 가족** | 일부는 여정 슬롯에 동행 |

## 2. 콘텐츠 4기둥 — 시나리오에 맞게 쓰는 법

> 이름은 지시자가 쓴 네 갈래를 그대로 쓴다.  
> 구현 시스템과 1:1로 대응시킨다(새 장르를 만들지 않음).

### 2-1. 역할표 【확정 제안】

| 기둥 | 시나리오 의미 | 쓰는 시스템(현행/예정) | 주로 어디서 |
|---|---|---|---|
| **파견** | 섬에 남은 아이들이 가족을 지킨다 | 슬롯 밖 펫 자동노동(`23`) → 로비에서 보고/배치 | **로비 메뉴** |
| **탐구** | 발품으로 비밀·흔적·기억을 찾는다 | 탑뷰 맵 · MEMORY · MEMO · 숨은 LOCATION | **여정 안 활동**(별도 메뉴 아님) |
| **도전** | 인간이 남긴 오염·잔재를 돌파한다 | 「다음날」메인 루프 · 액션 전투 · 관문 · 미니게임 | **여정 메인** |
| └ **모험** | 이미 연 구역을 다시 훑어 자원을 모은다 | **자동 사냥/파밍**(모노폴리고식 클리어 스테이지 재도전 레슨) | **로비 메뉴** |
| **정화** | 촉매를 적용해 생명·장소를 되돌린다 | 촉매 줍기(탐구)→적용 · 구조/PURIFY 전투는 **깊은 연출** · Memory Battle | **여정 안** — 루프 SSoT는 [`36`](./36_정화_촉매_지역정화.md) |

> 【확정 2026-08-08】 로비에 버튼 4개로 기둥을 쪼개지 않는다.  
> 로비 메뉴 ≈ **외출(여정)** · **파견** · **모험** · **기록(단말기)** · 파티.  
> 지금 프로토의 메인 = **도전(여정 진행) + 정화 이벤트**. 탐구는 맵 보너스.

### 2-2. 서로 어떻게 먹이느냐 (루프)

```
[로비] 파견 · 모험(자동) · 기록 · 파티
        │ 「외출」
        ▼
[여정] 탐구로 길을 열고 → 도전으로 막힌 길을 뚫고
        → 정화로 가족을 늘리고 → (선택) 더 탐구
        │ 「하루 마침 / 귀환」
        ▼
[로비] 파견 성과 · (선택) 모험으로 지난 구역 파밍 · 스크랩 열람
```

**감정 리듬:**  
로비 = 안심 · 여정 = 긴장과 발견 · 귀환 = “집에 누가 기다려준다” · 모험 = “지나온 길을 편하게 다시”

### 2-1b. 모험(자동) — 도전의 하위 【확정 2026-08-08】

모노폴리고 등에서 **이미 진행·클리어한 스테이지를 자동으로 돌려 보상** 받는 감각을 XOOX에 옮긴다.  
새 기둥이 아니라 **도전 기둥의 로비용 파생**.

| 항목 | 내용 |
|---|---|
| 진입 | 로비 「모험」 |
| 대상 | **이미 연 구역/깬 관문 이전 구간**만 (스토리 미개방 구역 불가) |
| 조작 | 구역 선택 → 「보내기/자동」→ 짧게 결과 연출 → 보상 |
| 시뮬 | 액션 전투 위주 자동 해석(기존 `simulateCombat` 재사용 검토) |
| 보상 | 소량 골드/EXP — 메인 여정·정화보다 **낮게** |
| **넣지 않음** | 자동 구조/정화 서사 · 기억조각 강제 · 관문 스킵으로 스토리 진행 |
| 파견과 차이 | 파견=**아이들**이 섬에서 일함 / 모험=**방랑자**가 지난 길을 다시 훑음 |

시나리오 톤 예: “오염이 걷힌 하수도를 다시 순찰한다.”

### 2-3. 기존 확정과의 정합

| 기존 확정 | 본 문서에서의 위치 |
|---|---|
| 버튼 = 메인 시나리오 유지 (`29`) | **여정 안의 자동 진행** = 도전·정화의 뼈대. 로비가 이걸 지우지 않음 |
| 맵 = 숨은 보너스 (`29`) | **탐구** 기둥. 메인 엔딩을 막지 않음 |
| 구조 = 확률 스폰 유지 (`29`) | **정화**의 일상 발생. 맵 필수로 안 옮김 |
| `_2` = 같은 장소 재방문 (`30`) | 시나리오상 “다시 지나가는 오염 구역” |

### 2-4. 기둥별 “하면 / 안 하면”

| 기둥 | 하면 | 안 하면(버튼만) |
|---|---|---|
| 파견 | 섬이 살아 움직임 · 소량 자원 · 가족감 | 섬이 배경뿐 |
| 모험 | 깬 구역에서 편한 파밍 · 성장 보조 | 자원이 여정에만 묶임 |
| 탐구 | 기억·플레이버·숨은 보상 | 메인 스토리는 여전히 진행 가능 |
| 도전 | 관문 돌파 · 성장 · 미니게임 | 날짜만 흐르고 막힌 길(관문)은 못 넘김 【잠정】 |
| 정화 | 동료·서사·정화 전투 깊어짐 | “아무도 구하지 못한 여정” 엔딩 톤 가능(`29` 후보) |

## 3. 진행 플로우 재설계

### 3-1. 화면 상태 (거시)

```
BOOT / CUTSCENE
    ↓
LOBBY  ←——————— 귀환 ———————┐
    │ 「외출」                    │
    ▼                            │
JOURNEY (지금의 메인 화면)        │
  · 탐방 맵 + 채팅 + 하단 버튼     │
  · 탐구 / 도전 / 정화             │
    └———— 하루 마침 / 스테이지 쉼 ——┘
```

`31`의 IDLE·COMBAT·SCRAPBOOK 등은 **JOURNEY 내부 모드**로 남긴다.  
`LOBBY`는 **새 최상위 모드**다.

### 3-2. 하루(Day) 호흡 【잠정 — 권고안 A】

카피바라고 리듬을 깨지 않으려면, 매일 긴 로비는 부담이다.

| 안 | 내용 | 장단 |
|---|---|---|
| **A. 소프트 로비(권고)** | 여정이 기본. 로비는 「섬」버튼으로 언제든. **스테이지 전환·주요 정화 후**에만 자동 귀환 연출 | 편안함 유지 + 거점 존재감 |
| B. 매일 귀환 | 하루 끝마다 반드시 로비 | 가족감↑ · 템포↓ |
| C. 스테이지만 로비 | 15일마다만 섬 | 거점이 희미 |

**초판 권고 = A.**  
파견 정산은 (1) 로비 입장 시 (2) 하루 마침 시 백그라운드 합산 후, 로비에서 “오늘 아이들 보고”로 보여준다.

### 3-3. 60일 거시 아크

| 구간 | 일차 | 시나리오 호흡 | 기둥 강조 |
|---|---|---|---|
| 구역01 하수도 | 1~15 | 정착 · 첫 구조 · 섬이 “집”이 됨 | 정화↑ 탐구↑ |
| 구역02 항만 | 16~30 | 유혹·감시·구역 보스 | 도전↑ 파견 자리잡음 |
| 구역03 폐자재 | 31~45 | 재방문·긴장 | 도전+탐구 |
| 구역04 중심부 | 46~60 | 기억 수집 수렴 · Memory Battle | 정화(결말) · 탐구(기억) |

시그니처: 뭉치(초반 정화) · 하늘이(중반) · 열두(결말) — `19` 정합 유지.

### 3-4. 플레이어 선택지 (한 순간의 메뉴)

**로비에서**
- 섬 둘러보기(코지 탭무브 【잠정】)
- 파견 보기/살짝 배치
- 단말기: 스크랩북 · 도감 · 구조일지 · 지도
- 파티 슬롯 확인
- **외출**

**여정에서**
- 「다음날」(메인)
- 맵 탐구(보너스)
- 게이지 미니게임(도전 보상)
- 「섬으로」(소프트 로비)

## 4. 시나리오 텍스트·연출이 바뀌는 지점

기능만이 아니라 **카피 톤**도 기둥에 맞게.

| 기둥 | 로그/코멘터리 톤 예 |
|---|---|
| 파견 | “— Nashui: 오늘도 아이들이 섬을 쓸고 있어.” |
| 탐구 | “희미한 기억… Tigon이 문 앞에 서 있었다.” |
| 도전 | “폐기물 병정이 길을 막았다.” (`20` 용어) |
| 정화 | “오염을 거두자, 안에 누군가가 있었다.” |

판타지 어휘(악마·기사·메두사)는 `20` 제안대로 **오염·잔재·유혹** 톤으로 통일하는 작업을 로비 이후 스프린트에 넣는다.
