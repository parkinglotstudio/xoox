## 0. 방법

1. **시나리오 성격 → 플로우 → 로비 → 기둥 시스템** 순으로 붙인다.  
2. 벤치 시스템은 **로비/여정 어디에 사는지** 정한 뒤 구현한다(`34`).  
3. 한 스프린트 = 플레이어가 말할 수 있는 문장 하나가 늘어나게.  
4. 아트 없이도 플레이스홀더로 구조 검증.  
5. 큰 코드 전 백업. 커밋은 지시자 승인 후.

---

## 1. 전체 순서 (한눈에)

```
S0  기획 고정(33·34·35)          ← 지금(+모험 반영)
S1  로비 골격 + 외출/귀환         ← 다음 구현
S2  파견 1차 (로비 보고 + day tick)
S3  단말기 이관 (스크랩→로비)
S4  여정 정리 (관문·클리어 정의)  ← 모험 해금 전제
S5  모험(자동) 1차               ← 도전 하위 · 로비 메뉴
S6  정화 전투 스킨 + 구조 환영 비트
S7  Memory Battle (60일 결말)
S8  도감·일지·섬 탭무브·색 회복
S9  추격 미니게임 등 후순위
```

`32`의 “채팅 디밍 Phase”는 **여정 UX 디테일**로 S4 이후에 재배치한다.  
(지시자: 원하는 방향이 아니었음 → 로비·시나리오가 먼저.)
