# 51. 프로토 1차 요건

> 작성: 2026-09-12 · 상태: 【**확정 · 프로토 v1 범위**】  
> 목적: 플레이어가 **「이게 XOOX다」** 라고 말할 수 있는 **한 판 데모**의 합격선·작업 축·스프린트를 고정한다.  
> 관련: [`00_INDEX`](./00_INDEX.md) · [`47` 입문](./47_XOOX_전반소개_프롬프트.md) · [`39` 시스템](./39_게임시스템_확정.md) · [`44` 필러시나리오](./44_인수인계_필러시나리오.md) · [`48`](./48_들판_퀘스트배치.md) · [`49`](./49_들판_타임어택_상세기획.md) · 색 SSoT [`art/11`](../art/11_XOOX_CYBERPET_PALETTE.md)  
> 철학: **CSV/JSON이 SSoT. 코드는 규칙 엔진.** 새 시스템·새 루프를 만들지 않는다.  
> 이 문서는 **기획만**. 구현 착수는 축별 후속 작업.

## 0. 한 줄 제품 목표

**로비에서 배를 타고 들판(`i21`)을 한 번 정화하면, 방랑자·적·FX·필러가 프로토처럼 보이고 플레이어가 「이게 XOOX다」라고 말할 수 있다.**

우물(`i11`)은 같은 뼈대의 **선택 연장**. 60일 본편·Memory Battle·9칸 풀콘텐츠가 아니다.

---

## 1. 성공 정의

한 사람이 **안내 없이** (또는 필러 튜토리얼만으로) 아래를 통과하면 v1 성공.

| # | 합격 조건 | 실패로 보는 것 |
|---|-----------|----------------|
| 1 | **로비 → 외출 → `i21` 들판 한 칸 정화**가 끊기지 않는다 | 워프·리셋·진행 소실 · 「다음에 뭘 하지」 막힘 |
| 2 | 필러가 **상황·대가·다음 행동**을 안내한다 | 새 튜토리얼 UI · 화면 위 나레이션 · 막힐 때 침묵 |
| 3 | 방랑자 idle/move/throw/aim 이 **게임 화면에서** 프로토처럼 읽힌다 | 머리 위 `000 동작 필요` · 가짜 모션 · 시트와 손 불일치 |
| 4 | 적(점구름)이 **부피**로 보인다 | 스티커·구슬·납작한 점 |
| 5 | 정화 파도+하늘이 **한 호흡**으로 열린다 ([`49` §6.3](./49_들판_타임어택_상세기획.md)) | 하늘만 먼저 확 열림 · 바닥만 변함 |
| 6 | 플레이 후 한 문장: **「이게 XOOX다」** | 「카피바라 클론」 · 「회색 박스 데모」 · 「시스템 더미」 |
| 7 | (선택) `i21` 클리어 후 **우물 `i11` 입구까지** 걸어갈 수 있다 | i11 본편 필수 · 9칸 콘텐츠 |

**본축 전투 = 타임어택** ([`49`](./49_들판_타임어택_상세기획.md)). 필러 전투는 비주얼 안정 **이후** `i21`에 **최소 1회 삽입**만. 카드 배틀은 메인 루프에 넣지 않는다.

## 2. 데모 스크립트 (~5분)

시계는 안내용. 막히면 필러가 다음 손을 말한다.

| 분 | 화면 | 플레이어 손 | 보여야 하는 것 |
|----|------|-------------|---------------|
| 0:00 | 로비 (무지개섬) | 둘러보기 → **배=외출** | [`art/11`](../art/11_XOOX_CYBERPET_PALETTE.md) 톤 · 방랑자 · 「집 / 나가면 여정」 |
| 0:20 | `i21` 부두·들판 스폰 | 걷기 | 장 헤더 필러 · 3D 무대 · 안개 · 지평선 원통 |
| 0:40 | 도착 필러 | 읽기 | 원인(웅덩이/원흉) 암시 · **지금 할 일 한 줄** |
| 1:00 | 갈림 (필수) | **더 모은다 / 바로 간다** | 대가·리스크가 필러로 보임 ([`49` §1](./49_들판_타임어택_상세기획.md)) |
| 1:20 | 들판 걷기 | WASD·패드 | **히어로샷 1** — 방랑자 전신 루프 (idle↔move) |
| 1:50 | 얼룩 → 오염 | 조준·투척 | throw/aim 손맛 · 얼룩→오염 **시나리오 필러** |
| 2:20 | 타임어택 | 얼룩·오염·벌레 | **히어로샷 2** — 적 점구름 클로즈업 · 시계가 압박 |
| 3:20 | 원흉 → 최종 정화 | 정화제 | **히어로샷 3** — 바닥 파도 + 하늘이 같이·천천히 |
| 4:10 | 칸 클리어 | 북으로 걷기 또는 로비 | 클리어 필러 · 로비는 **1칸만** 정화 반영 ([`49`](./49_들판_타임어택_상세기획.md)) |
| 4:30 | (선택) `i11` 방향 | 걸어가기 | 두 원 **붙어 보이지 않음** ([`49` §4.1](./49_들판_타임어택_상세기획.md)). 우물 본편은 안 해도 됨 |

5분에 원흉까지 못 가면: **갈림→얼룩→오염→정화 1차(바닥+하늘)** 까지가 최소 데모. 벌레·원흉은 같은 판에서 이어지면 가산.

## 4. 비주얼 수용선 · 히어로샷

### 4.1 수용선 (한 화면에서)

| 축 | 합격 | 불합격 |
|----|------|--------|
| 색 | [`art/11`](../art/11_XOOX_CYBERPET_PALETTE.md) — 어두운 바탕 · 생명색은 점·띠 | 흰 스튜디오 · 면 전체 네온 · 오두막 무지개 |
| 방랑자 | 3인칭 뒷모습 전신이 루프됨. 손(걷기/투척)과 시트 일치 | 향아 슬롯 혼용 · 번호 플레이스홀더 · 가짜 트윈 |
| 적 | 점구름 **부피** · 실루엣이 먼저 | 펫말 스티커 · 발 앞 구슬 |
| 땅 | 모래 알갱이 그래픽 ([`48` §5](./48_들판_퀘스트배치.md)) | 시안 구슬 랜드마크 · 옛 나무 01–05 재꽂기 |
| 정화 | 바닥 파도와 하늘이 같이·천천히 | 하늘 선개방 · 지평선 투명 띠 |
| 밀도 | 히어로샷 3장이 「XOOX」 | 에셋 전부 갈아엎기 |

### 4.2 히어로샷 체크리스트 (이 3장이 먼저)

전체 덤프 금지. 샷이 만지는 에셋만 고친다.

| # | 샷 | 구도 | 합격 한 줄 | 관련 |
|---|-----|------|-----------|------|
| H1 | **방랑자 전신 루프** | 등 뒤 3/4 · 전신 · idle→move→idle | 「저게 주인공이다」 | [`art/10`](../art/10_XOOX_WANDERER_ANIM.md) |
| H2 | **적 점구름 클로즈업** | 얼룩 또는 벌레를 화면 크게 · 부피·퍼짐 | 「저게 오염이다」 | [`48` §13](./48_들판_퀘스트배치.md) · [`49` §6](./49_들판_타임어택_상세기획.md) |
| H3 | **정화 파도 + 하늘** | 바닥 파도와 원경이 같은 마스크 | 「저기가 맑아진다」 | [`46`](./46_여정3D_원경_맵컨셉.md) · [`49` §6.3](./49_들판_타임어택_상세기획.md) |

촬영은 `i21` 실플레이. 툴 프리뷰만으로 H1–H3를 대체하지 않는다.

## 5. 작업 축 (순서 고정)

한 축을 끝낸 뒤에 다음 축. **비주얼(§5.1–5.3) → 필러 안내(§5.4) → FX(§5.5) → 필러 전투(§5.6).**  
새 시스템 없이, 있는 CSV/JSON·툴·시트를 고친다.

### 5.1 방랑자 애니 (인게임 2.5D)

보이는 네 슬롯만: **idle / move / throw / aim**.

| 순 | 할 일 | 완료선 |
|----|--------|--------|
| 1 | 현행 시트·재생을 [`art/10`](../art/10_XOOX_WANDERER_ANIM.md)과 대조 | 빠진 슬롯·머리 위 번호 목록 |
| 2 | 루프·타이밍·홀스터 연결을 **게임 화면**에서 맞춤 | 손과 그림이 어긋나지 않음 |
| 3 | H1이 전신으로 읽힐 때까지 컷·스케일만 다듬음 | H1 체크 |
| 4 | (병렬) 방랑자만 하이브리드/심플 3D 스파이크 | 본편 2.5D를 갈아끼우지 않음 · §7 |

페이즈 2(풀 리그) 작업은 이 축에 넣지 않는다.

### 5.2 적 부피 스파이크

새 적 종·새 전투 규칙을 만들지 않는다. `i21`에 이미 있는 **얼룩 / 오염 / 벌레** (원흉은 같은 툴).

| 순 | 할 일 | 완료선 |
|----|--------|--------|
| 1 | 점구름 밀도·실루엣·퍼짐/모임을 한 종부터 | 클로즈업에서 납작하지 않음 |
| 2 | 같은 문법으로 벌레·오염에 적용 | 스티커/구슬 잔존 0 |
| 3 | H2 촬영 (한 종 클로즈업이면 됨) | H2 체크 |

### 5.3 오브젝트 예산 · 배치

SSoT: [`48` 다섯 자리](./48_들판_퀘스트배치.md) · [`42` 미터·간격](./42_섹터_스케일_및_배치툴.md) · `area_prop_config` / `area_npc_config` / `quest_spot_config`.

| 순 | 할 일 | 완료선 |
|----|--------|--------|
| 1 | `i21` 프롭·스팟 인벤토리 | 종류·개수 표 |
| 2 | **예산** — 한 카메라에 읽히는 개수만. 랜드마크는 다섯 자리 | 남 부두 / 중 웅덩이 / 서 거르기 / 동 흡착 / 북 출구 |

### 5.4 시나리오 · 튜토리얼 (필러만)

### 5.6 필러 전투 — 계획 후 스파이크

**비주얼 축(§5.1–5.5)이 안정된 뒤.** 본축은 계속 타임어택.

| 순 | 할 일 | 완료선 |

| 2 | `i21`에 **1회** 삽입 (타임어택 사이 또는 직후) | 메인 루프를 카드/턴제로 바꾸지 않음 |

## 6. 스프린트 맵 P0–P4

한 스프린트 = 플레이어가 말할 수 있는 문장 하나 ([`35`](./35_개발순서_로비중심.md)).

|----------|------|---------|------|
| **P0** | 「데모 길이랑 합격선이 문서에 있다」 | 본 문서 · 현행 루프 실측 | 이 파일 · H1–H3 촬영 자리 지정 · Must 갭 목록 |
| **P1** | 「주인공이 걸어가고 던진다」 | §5.1 방랑자 2.5D | H1 · idle/move/throw/aim 인게임 |
| **P2** | 「적이 덩어리고, 땅이 다섯 자리다」 | §5.2 적 부피 · §5.3 예산/배치 | H2 · `i21` 예산 표 · 과밀 제거 |
| **P3** | 「필러가 가르치고, 던지면 파도가 따라온다」 | §5.4 필러 안내 · §5.5 FX | §2 5분이 막히지 않음 · H3 |
| **P4** | 「한 칸 정화 데모가 XOOX다」 | §5.6 필러 전투 1회 · S1 `i11` 입구 · §7 게이트 | 성공 정의 1–6 · 3D 스파이크 go/no-go · 카드는 사이드 후보로만 남김 |

## 7. 열린 게이트

구현이 아니라 **결정 지점**. 닫히기 전엔 Won't를 열지 않는다.

### G1. 방랑자 하이브리드/심플 3D 스파이크 — go / no-go

| | |
|--|--|
| **하는 것** | 방랑자 **한 몸**만. 심플 메시 또는 2.5D+단순 3D. 본편과 **병렬** |
| **안 하는 것** | 풀 리그 · 펫/적 일괄 3D · 본편 시트 교체 |
| **Go** | 인게임에서 2.5D보다 「XOOX 주인공」이 잘 읽히고, 기존 이동/투척 규칙에 붙일 수 있다 |
| **No-go** | 읽힘·손맛·공수가 2.5D만 못하다 → 폐기. **페이즈 2 풀 리그로 넘김** |
| **언제** | P1과 병렬 착수 가능. **판정은 P4** |
| **다음** | Go여도 v1 본편은 2.5D 유지. 교체는 페이즈 2 별도 결정 |

### G2. 카드 — v1 밖, 나중에만

| | |
|--|--|
| **지금** | 메인 루프 금지 (W4). 필러 **로그 카드**(13종)와 다른 축 |
| **나중 후보** | 필러 전투(§5.6)가 **한 번** 안정된 뒤, **로비 또는 휴식** 사이드. 타임어택을 대체하지 않음 |
| **열지 않는 것** | 카드 = 본전투, 카드 = 정화, 카드 = 튜토리얼 강제 |

그 외 미결(모으기 대상 A/B/C/D, 타임어택 블록 vs 단일 시계)은 [`49` §12](./49_들판_타임어택_상세기획.md). v1은 그 문서의 **잠긴 기본값**을 따른다. 여기서 재토론하지 않는다.
