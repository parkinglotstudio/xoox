## 4. 정화 본축 = `combat_loop` 【현행】

진입: `area_npc` PURIFY 노드 (`s1_purify_step` / `s11_purify_step`) → `SectorPurifyLoop`.

비트(둘 다 `combat_loop: true`):

```
arrive → gatherFork → mission(얼룩) → tint1(+오염)
→ showcase(skill) → invade(벌레) → [i11만 memory aside]
→ tint2 → playCulprit(대화→물질 HP) → tint3 → done
```

**중요:** `combat_loop`면 `quest_step_config` 장문 경로 **스킵**. GDD 48 다섯 자리는 【보류·데이터만】.
