## 0. 한 줄 【확정】

> **플레이어가 맵에서 보는 먼 풍경은 스카이박스가 아니다. 지평선 원통에 두른 「산+대기+구름」 한 장이다.**  
> 가까운 능선 → 먼 능선이 **층층**이고, 땅과 맞닿는 아래는 **보카시**, 위는 먹구름 하늘로 이어진다.  
> 정화전도 이 구도의 한 장. 로비 정화전(`lobby_hub_before.png`)의 DNA(어두운 바탕, 판금 실루엣, 시안·마젠타 점)를 **원경 실루엣**으로만 쓴다.

이 문서는 **바닥 타일·섹터 PNG가 아니라**, 3D 여정에서 지평선 너머를 그리는 규칙이다.  
바닥·구역 마스크는 파이프라인 Phase 0~4, 원경은 **이 문서 + Phase 원경**.

## 1. 맵을 그릴 때 레이어가 몇 겹인가

인게임 여정(3인칭)은 한 화면이 아니라 **거리 레이어**다. 맵 아트는 레이어마다 역할이 다르다.

```
카메라 (등 뒤, 거의 수평)
    │
    ├─ 캐릭터 · 근경 프롭(나무·풀)
    ├─ 바닥 타일 / 스플랫          ← 밟는 땅. 마스크·타일 파이프
    ├─ 탐방 안개 (근거리)           ← GDD 45. 노드 숨김용
    ├─ 거리 안개 (3D fog)           ← 원경이 땅과 칼로 안 잘리게
    ├─ ★ 지평선 원통 한 장          ← 이 문서. 산+하늘. 실제로 보이는 원경
    └─ 스카이박스 (equirect)        ← FOV 72에서는 거의 안 보임. 원경 윗색 샘플일 뿐
```

| 레이어 | 플레이어가 보는 것 | 그리는 것 | 그리지 않는 것 |
|---|---|---|---|
| 바닥 | 발밑 풀·흙·길 | 타일 / 스플랫 / 마스크 구역 | 먼 산, 하늘, 로비 타워 |
| 근경 프롭 | 옆의 나무·돌 | 스티커 프롭 | 지평선 실루엣 |
| 원경 원통 | **화면 한가운데 지평선 띠** | 산 능선 + 대기 + 구름 **한 장** | 발밑 디테일, UI, 캐릭 |
| 스카이박스 | 거의 없음 (현재 FOV) | 원경 그림 **맨 위 대기색** | 따로 그린 예쁜 하늘 전경 |

**착각 금지 (2026-08-28 확정):** 파일이 `sky_*.png`와 `horizon_mountains_*.png` **둘**이라고 해서, 그림도 하늘/산으로 **나눠 그리면 안 된다.**  
엔진이 슬롯이 둘인 것뿐이다. **작화는 한 장(원경)** 이고, 하늘 PNG는 그 장의 **윗부분을 샘플**한 보조다.

## 2. 엔진이 그림을 어떻게 붙이는가 (작화 전에 읽을 것)

### 2-1. 카메라 【확정 · 바꾸지 말 것】

`data/ui/layout/journey3d_layout.json` (2026-08-28 인게임 확정본과 동일):

| 키 | 값 | 의미 |
|---|---:|---|
| `fov_deg` | **72** | 넓은 광각(옛 106) 아님. 하늘 텍스처가 거의 안 보이는 이유 |
| `char_height_m` | **1.95** | 3D 방랑자 키. 원통 높이가 이 배수 |
| `view_mode` | `tps` | 3인칭 |
| `tps_distance_mul` | 3.2 | 등 뒤 거리 ≈ 6.2 m |
| `tps_height_mul` | **1.9** | 카메라 높이 ≈ 3.7 m |
| `lookAt.y` | `charH * 1.85` | 코드 고정. **거의 수평**. 땅을 내려다보지 않음 |

**카메라만 올리면** 땅을 내려다보게 되어 **하늘이 더 줄어든다.** 원경이 답답하다고 카메라를 올리지 말 것.  
하늘을 더 넣고 싶으면 **그림 구도**(구름을 원통 중·상단에)로 조절한다. FOV를 올리려면 지시 승인 후 78 전후만.

GDD [`42`](./42_섹터_스케일_및_배치툴.md)의 「사람 ≈ 1 m」는 **2D 섹터 에디터** 비유다. 3D 원경 배수는 `char_height_m` **1.95**를 쓴다. 두 숫자를 섞지 말 것.

### 2-2. 원통 배치 【확정 · 2026-08-28 인게임 「딱 좋음」】

코드: `JourneyStage3D.layoutHorizon()`.

| 항목 | 식 | 대략(키 1.95 m) | 이유 |
|---|---|---|---|
| 반지름 | `max(18, fog.far * 0.86)` | ≈ **38.5 m** | `fog_vision_m 14` × `fog_far_mul 3.2` → far 44.8 |
| **높이** | `max(16, charH * 18)` | ≈ **35 m** | 산이 점도 아니고 화면을 가리지도 않음 |
| 원통 `position.y` | `height * 0.5 - 0.12` | ≈ 17.4 | **텍스처 아래(보카시)가 지면 y=0에 앉음** |
| 원통 중심 xz | 카메라 xz를 따라감 | — | 플레이어가 걸어도 원경은 무한히 멀리 |

텍스처 **아래 변 = 원통 아래 변** (Three.js `flipY` 기본).  
그림을 그릴 때 **캔버스 아래 = 땅과 붙는 보카시**, **캔버스 위 = 하늘**이다.

## 3. 화면에서 원경이 차지하는 느낌 【확정】

FOV 72 · 거의 수평 3인칭에서, 잘 된 원경은 이렇게 읽힌다.

```
┌──────────────────────────────────────────┐
│  먹구름 (화면 위 ~절반)                     │  ← 원통 텍스처의 위쪽
│  두껍고 층층. 밋밋한 민트 그라데이션 금지     │
├──────────────────────────────────────────┤
│  능선 띠 (지평선에 앉은 산·타워)             │  ← 「있다」가 읽히되 화면을 안 먹음
│  오른쪽이 조금 가깝고 큼 · 왼쪽은 더 멈       │
├ - - - - - - - - 지평선 - - - - - - - - - ┤
│  회색 땅 (타일) + 보카시로 산 밑이 녹아듦     │
│              [방랑자]                      │
└──────────────────────────────────────────┘
```

| 좋다 | 나쁘다 |
|---|---|
| 산이 **지평선 위의 띠**로 존재감이 있다 | 점이라 산인지 건물인지 안 보임 (너무 낮음) |
| 꼭대기가 **화면 안에** 들어 있다 | 오른쪽 큰 산·타워 꼭대기가 잘림 (너무 높음) |
| 가까운 능선 / 먼 능선이 **층**으로 읽힌다 | 좌우 대칭 같은 높이의 산 두 덩이 |
| 땅과 산 사이가 **보카시** | 칼로 자른 이음, 또는 산 밑이 땅 아래로 묻힘 |
| 위는 **먹구름 아포칼립스** | 위가 텅 빈 민트·그레이 그라데이션 |

지시자 표현:

- 산이 화면을 다 가리면 → 「너무 높아」  
- 지평선에 점만 남으면 → 「너무 낮아」  
- **그 사이가 「딱 좋음」(2026-08-28 인게임 확정)**

## 4. 한 장 작화 구도 (정화전)

정본 시안: `docs/art/sky_concepts/horizon_polluted_lobby_v16.png`  
색 DNA: `data/ui/lobby/lobby_hub_before.png` + [`art/11`](../art/11_XOOX_CYBERPET_PALETTE.md)

### 4-1. 세로 배분 (2:1 랩 이미지 기준)

원통에 두르면 **이미지 세로 전체가 원통 높이 35 m**가 된다.  
카메라가 보는 것은 그중 **땅 근처 하단 + 중하단**이다. 이미지 맨 위는 거의 안 보이거나 구름으로만 읽힌다.

| 구간 (이미지 아래→위) | 대략 비율 | 내용 |
|---|---|---|
| 맨 아래 | **~8–12%** | **보카시.** 회색 황무지·안개. 타일 땅과 맞붙는 곳. 하드 엣지 금지 |
| 하단 산 | **~28–35%** | 가까운 능선·중경 능선. 오른쪽만 조금 크고 가깝게 |
| 먼 실루엣 | 산 구간의 뒤쪽 | 더 작고 흐린 능선. 대기 원근 |
| 위 | **나머지 ~55%** | 층층 먹구름. 가운데 살짝 옅은 틈(빛)은 점·띠만 |

초기에 「높이의 1/3이 원경」→「1/4」로 낮췄다가, 인게임에서 점이 되어 **다시 키웠다.**  
**작화 비율의 정본은 v16**이다. 숫자만 외우고 엔진 높이를 건드리지 말 것.  
엔진 높이(`charH*18`)와 그림 배분이 **같이** 맞아야 한다.

### 4-2. 원근 · 실루엣

1. **층층 능선.** 한 줄 종이 자른 산 금지. 가까운 능선이 어둡고 크고, 먼 능선은 얇고 흐리다.  
2. **좌우 비대칭.** 한쪽(현행 정화전: **오른쪽**)이 가깝고 크다. 양쪽을 똑같이 높이면 원근이 죽는다.  
3. **가까운 쪽도 화면을 뚫지 않는다.** 오른쪽을 키우다가 v13에서 꼭대기가 잘렸다. 큰 쪽도 **프레임 안에**.  
4. **타워는 원경 실루엣.** 로비처럼 사이버 고딕 침탑·판금을 **산에 박힌 바늘**로. 슬릿은 시안 `#0FBEC7` 주, 마젠타 `#D158BC`는 점·띠. 면 전체를 네온으로 칠하지 않음.  
5. **땅은 황무지.** 로비 부두 클로즈업이 아니다. 회색·회백 평원 위에 방랑자가 서 있는 느낌(오염 로비의 *멀리 본* 버전).

### 4-3. 하늘 (원통 위쪽 = 구름)

정화전 하늘은 **맑은 그라데이션이 아니다.**

- 두꺼운 수평 층운, 어두운 잿빛·먹색  
- 아포칼립스·중압. 「예쁜 석양 일러스트」 금지  
- 중앙에 옅은 틈이 있어도 **면 발광 금지**. 틈은 대기일 뿐  
- 민트 클리어·인상파 색면은 **정화후** 레이어. 정화전에 넣지 않음

### 4-4. 보카시 (땅 이음)

원통 맨 아래가 땅(`y=0`)에 앉는다. 여기가 딱딱하면 산이 땅 위에 **오려 붙인 종이**가 된다.

- 아래 변은 안개·먼지·아웃포커스로 **풀어** 둔다  
- 보카시 안에 시안·마젠타 **보케 점**은 생명색 힌트(면 아님)  
- 16:9 시안을 2:1로 바꿀 때 **아래를 자르면 보카시가 사라진다** → §6

### 4-5. 색 (정화전)

[`art/11`](../art/11_XOOX_CYBERPET_PALETTE.md) 오염 세트.

| 역할 | 쓰는 색 | 금지 |
|---|---|---|
| 하늘·구름 | Void `#030D18` ~ 숯 그레이. 하이라이트는 창백 회청 | 민트 하늘, 살구 노을(GDD 37 초판) |
| 산·판금 | Navy Plate `#0D2336` · Steel `#19314A` · 실루엣은 거의 흑 | 고딕 성 보라 일색, 리얼 메가시티 |
| 생명색 | 시안 슬릿 주, 마젠타·옐로 점 | 네온으로 능선 전체를 칠하기 |
| 땅 이음 | 회백·먼지. 로비 부두의 멀리 본 회색 | 초록 초원(그건 정화후 바닥 타일) |

지역 정화 때 그림이 한 장으로 바뀌면 안 된다. **바닥과 원경이 같은 반경 `waveR`로 퍼진다.**

|---|---|---|---|

## 6. 제작 파이프라인 (시안 → 본편)

생성 PNG는 먼저 `C:\수스이미지 생성\` 작업 폴더. 본편 `data/`는 **지시 승인 후**.

| 순 | 단계 | 규칙 |
|---:|---|---|
| 1 | 시안 | 16:9 또는 와이드. 캐릭·UI·미니맵 **없음**. 로비 before + v16을 레퍼런스로 연다 |
| 2 | 검수(그림) | §3 표. 산 띠 존재감 / 꼭대기 안 잘림 / 층층 / 먹구름 / 보카시 |
| 3 | **2:1 변환** | 원통 Wrap용. **아래를 남긴다** |
| 4 | 좌우 seamless | 원통이라 좌우가 만난다. 가장자리 산·타워가 잘리면 이음 줄 |
| 5 | 하늘 PNG | 변환본 **상단 띠** 샘플. 새 하늘 그림을 그리지 않음 |
| 6 | 본편 복사 | `data/art/sky/horizon_mountains_polluted.png` · `sky_polluted.png` |
| 7 | 인게임 | `npm run dev` · **하드 리프레시** · 외출 · 지평선 높이 확인 |

### 6-1. 2:1 크롭 — keep-bottom 【확정】

가로가 세로의 2배가 되게 자른다.

- **맞음:** `y0 = h - nh` → **아래(보카시·산)를 남기고 위를 자름**  
- **틀림:** `y0 = 0` → 위를 남기고 **아래를 자름** → 보카시 손실, 산이 원통 바닥에 안 붙음

원통 아래 = 텍스처 아래이므로, 보카시를 자르면 산 허리가 땅에 붙는다.

### 6-2. 본편 경로

```
data/art/sky/horizon_mountains_polluted.png   ← 원경 한 장 (정화전)
data/art/sky/sky_polluted.png                 ← 상단 샘플
data/art/sky/horizon_mountains_purified.png   ← 정화후 (구도 동일 · 아직 이 루프 미적용)
data/art/sky/sky_purified.png
```

시안 보관: `docs/art/sky_concepts/` · 작업본: `C:\수스이미지 생성\sky_concepts_*\`

맵·원경을 손볼 때 아래를 **먼저** 읽고, 같은 처방을 반복하지 말 것.

| # | 했던 일 | 인게임 | 바른 처방 |
|---|---|---|---|
| 1 | 하늘 PNG와 산 PNG를 **따로 명작**으로 그림 | FOV 72라 하늘은 안 보이고, 산만 어색 | **한 장**을 원통에 |
| 2 | 원통 `position.y = height * 0.28` | 보카시가 땅 **밑**으로 묻힘 → 칼 이음 | `height * 0.5 - 0.12` |
| 3 | 원통 높이 `charH * 26` (≈51 m) | 카메라가 텍스처 **하단만** 봄 → 거대 산, 꼭대기 잘림 | `charH * 18` |
| 4 | 원통 높이 `charH * 12` | 산이 **점** | `charH * 18` |
| 5 | 그림에서 산을 1/4만 남김 (v11b) | 하늘 밋밋, 산 얇음 | v16 배분 + 엔진 높이 유지 |
| 6 | 오른쪽만 과하게 키움 (v13) | 큰 산 꼭대기 잘림 | 비대칭은 유지하되 프레임 안 |
| 7 | 한 장 원경에 **하늘색 키잉** | 구름 구멍, 민트 클리어 | 상단 알파>240이면 키잉 금지 |
| 8 | 2:1 변환 `y0 = 0` | 보카시 잘림 | keep-bottom |
| 9 | 카메라 높이만 올림 | 땅만 보임, 하늘 감소 | 카메라 유지, **그림**으로 조절 |
| 10 | 정화전을 정화후 인상파로 그림 | 오염 로비와 단절 | 정화전=잿빛·먹구름·슬릿 |

## 8. 맵 파이프라인에서 이 문서의 자리

섬 맵은 여전히 [`island-map-pipeline-plan`](../superpowers/specs/2026-08-23-island-map-pipeline-plan.md) 순서다. 원경은 **바닥과 별 Phase**.

```
Phase 0  레이아웃(섬 외곽·작업구역)
Phase 1  구역(숲·들·물…)
Phase 2  정화후 미니맵/컨셉 플레이트
Phase 3  정화전 미니맵/컨셉 플레이트
Phase 4  타일 · 근경 프롭 · 3D 바닥
Phase 원경  ★ 이 문서 — 지평선 한 장 (정화전 v16 · 정화후 하늘 v1 · 타일 아트는 후속)
```

| 산출 | 쓰는 곳 | 원경을 넣나 |
|---|---|---|
| 마스크 JSON | 칠하기 툴 | 아니요 |
| `sector_iXX_*.png` | 미니맵·에디터 컨셉 | 아니요 (탑뷰) |
| floor 타일 | 발밑 | 아니요 |
| **horizon + sky PNG** | **인게임 3D 지평선** | **예** |

탑뷰 섹터 그림에 먼 산을 구워 넣지 않는다. 3D에서 원통이 그 일을 한다.

## 9. 검증 체크

인게임 (`npm run dev` → 외출, 하드 리프레시):

- [ ] 지평선에 산·타워 **띠**가 있다 (점이 아님)
- [ ] 가장 큰 꼭대기가 **잘리지 않는다**
- [ ] 왼쪽은 멀고 작고, 오른쪽은 조금 가깝다 (또는 시안의 비대칭이 읽힌다)
- [ ] 땅과 산 사이가 보카시 (칼선 없음)
- [ ] 위는 먹구름이지, 민트 공허가 아님
- [ ] 캐릭터 등 뒤 3인칭에서 땅이 화면의 아래쪽을 차지하고, 하늘이 위쪽을 차지한다 (내려다보는 탑뷰가 아님)
- [ ] 정화 연출: 발밑에서 시안 링이 나가 땅과 하늘이 **같이** 열리고, 끝나면 컷이 없다

그림만 보고 통과시키지 말 것. **FOV 72 원통**에서만 높이가 맞다.
