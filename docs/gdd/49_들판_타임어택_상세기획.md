## 1. 게임 철학

### 1.1 본축 = 타임어택

- 이 섹터 루프의 **본게임 밸런스**는 제한 시간 안에  
  **얼룩 → 오염물질 → 벌레 → 원흉 → (최종 정화)** 를 끝내는 것이다.  
- 실패·압박·긴장감의 주 소스는 **시계**다. (HP 싸움을 주력으로 두지 않음)

### 1.2 필수 앞단계 = 갈림길 (모을지 / 바로 갈지)

```
[이동·도착]
    ↓
【갈림길】 ← 타임어택 시작 전 · 지금 부재·약함 (필수 추가)
  A. 더 모은다 (정화제·여유)
  B. 바로 들어간다 (타임어택 즉시)
    ↓
【타임어택】 ← 본밸런스
    ↓
[클리어 / 실패]
```

| 선택 | 얻는 것 | 잃는 것 |
|------|---------|---------|
| **더 모은다** | 정화제·여유 · 실패 확률↓ | 준비 시간·긴장, 또는 본 타임어택 시간 축소 |
| **바로 간다** | 템포·보스까지 빠름 | 탄약 부족 리스크↑ |

- **“바로 가기” 기준**으로 타임어택 숫자를 빡세게 잡는다.  
- **“더 모으기”**는 그 빡셈을 **완화하는 선택**이다.  
- 플레이어가 **스스로 난이도를 고른 느낌**이 나야 원흉 10발·벌레 12가 “불만”이 아니라 “선택 결과”로 읽힌다.

### 1.3 갈림의 기본 축

섹터 안·여정 전반의 갈림은 기본적으로:

- **빠르게 간다 ↔ 느리게 간다** (템포·리스크·연출 밀도)  
- 타임어택 직전 갈림은 그 특수형: **더 모은다 ↔ 바로 사냥/정화 타임어택**

## 2. 1지역(들판) 전체 동선

### 2.1 권장 페이즈 순서

| # | 페이즈 | 플레이어 행동 | 필러·연출 | 비고 |
|---|--------|---------------|-----------|------|
| 0 | 도착 | 섹터 진입 | 도착 필러 | 원인=웅덩이/원흉 암시 |
| 1 | **갈림 (필수)** | 더 모을지 / 바로 갈지 | **상황 상세 필러** | 타임어택 **전** |
| 1b | (선택) 모으기 | 정화제·발사체 추가 확보 | 물방울 퍼짐 연출 | A 선택 시만 |
| 2 | 타임어택 개시 | 시계 시작 | 짧은 경고 필러 | |
| 3 | 얼룩 ×3 | 정화제로 얼룩 걷기 | **얼룩→오염 시나리오 필러 필수** | 퍼뜨려 클리어 |
| 4 | 오염물질 ×5 | 사냥 | 상황 필러 | 얼룩에서 파생  Explicit |
| 5 | (중간 갈림 가능) | 빠르게/느리게 또는 탄 더 | 짧게 | 선택지 확대용 |
| 6 | 벌레 ×12 | 퇴치제 | 벌레·펫 암시 | |
| 7 | 펫 조우 | 구조 퍼즐 | **조우 텍스트는 필러로 재설계** (당분간 UI 텍스트 최소화) | |
| 8 | 원흉 · 10발 | 정화제 | 밑 얼룩 + 위 네모 · 퍼짐/모임 | |
| 9 | 최종 정화 | 캐스팅·색·하늘 | 1·2·3차와 하늘 연동 | 원흉≠칸 클리어일 수 있음 |
| 10 | 닫기 | 다음 노드/일차 | 클리어 필러 | |

> 기존 “캐스팅1→띠→벌레→캐스팅2…” 시퀀스와 **합칠 때**:  
> 타임어택 블록 안에 캐스팅·띠를 넣을지, 갈림 뒤에 한 번의 큰 타임어택으로 묶을지는 **구현 전 한 번 더 확정**.  
> 본 문서의 우선 원칙은 **「갈림 → 타임어택」이 플레이어에게 보이게** 하는 것이다.

### 2.2 시나리오 필러 (필수·권장)

| ID 역할 | 필수 | 내용 |
|---------|------|------|
| 갈림 설명 | **필수** | 모으면 뭐가 좋아지고, 바로 가면 뭐가 위험한지 |
| 스킬 설명 | **필수** | 받는/배우는 스킬이 무엇인지 (총 5종 전제 하 정리) |
| 얼룩→오염 | **필수** | 얼룩을 걷어내면 오염물질이 나온다 |
| 모으기 설명 | **확인** | 마지막·중간 “모으기”가 **무엇을 모으는지** (발사체/게이지/스킬 차지) — 필요하면 필러, 불필요하면 삭제 |
| 조우 | 재설계 | 지금 화면 텍스트·로그는 일단 제거 방향 → 이후 **필러 기획**으로 감정·정보만 |

필러는 **한 줄 요약이 아니라**, 상황·대가·다음 행동을 조금 더 자세히 말한다.

## 3. 밸런스 (1지역 목표치)

### 3.1 본수치 (합의 초안)

| 대상 | 수량 | 비고 |
|------|------|------|
| 얼룩 | **3** | 퍼뜨려서 클리어 |
| 오염물질 | **5** | 얼룩 이후 파생 · 시나리오로 개수 분배 |
| 벌레 | **12** | |
| 원흉 | **10발** | 정화제 기준 |

### 3.2 설계 메모

- **얼룩 3 → 오염 5:** 필러 “걷어내면 나온다”와 맞음. 얼룩별 출현 수를 표로 고정하면 안정적.  
  예: 얼룩A→2, 얼룩B→2, 얼룩C→1.  
- **벌레 12:** 들판·360° 스폰에 무난. “더 모으기” 없이 가면 퇴치제/정화제 압박이 커야 함.  
- **원흉 10발:** 보스감 OK. 텔레포트만 있고 가드가 없으면 **시간만 늘 수 있음** →  
  - 갈림에서 탄 확보, 또는  
  - 원흉전 직전 **정화제 하한/드랍 1회** 권장.

### 3.3 갈림과 숫자의 관계

| 루트 | 체감 |
|------|------|
| 바로 가기 | 위 표가 **빡센 기준선** |
| 더 모으기 | 탄약 +α · 같은 표지만 실패율↓ (또는 시계 +α) |

테스트용 임시 수치(벌레 1·원흉 2발 등)는 **본편과 분리**한다. 본편 목표치는 위 표.

## 4. 2지역 · 구역 배치

| | 1지역 (들판 `i21`) | 2지역 (우물 `i11`) |
|--|-------------|--------|
| 역할 | 갈림+타임어택 뼈대 정착 | **같은 뼈대 · 더 어렵게** |
| 정화 원 | **40m** | **52m** |
| 밸런스 | 3 / 5 / 12 / 10발 | 4 / 7 / 16 / 14발 |
| 난이도 | 기준선 | 시간↓ / 수↑ / HP↑ / 갈림 대가↑ |
| 시스템 | 신규 최소화 | 숫자·필러·압박만 강화 |

### 4.1 두 구역 사이 거리 【확정】

- 1구역과 2구역을 **비슷한 거리·인접 칸에 붙이면 안 된다.**  
- 이유: 한 칸을 정화한 뒤 옆 칸으로 가면, **이미 맑아진 하늘·원경**이 보여서  
  “아직 오염된 새 구역”이 아니라 **정화된 지역에서 플레이하는 것처럼** 보인다.  
- 배치 원칙:
  1. **시야·안개 밖에** 다음 정화 칸이 있게 (한 번에 두 칸 원경이 안 겹침).  
  2. 이동 동선에 **중간 구간**(길·갈림·필러)을 두어 “다른 곳으로 간다” 체감.  
  3. 목표 감각: 들판 클리어 후 **우물이 바로 옆이 아니라**, 걸어가는 거리·연출이 있게.  
- 수치 가이드(초안): 두 정화 원 **중심 간 거리 ≥ max(원반지름 합) + 여유 1칸 이상**  
  예) 40m+52m+여유 → **최소 한 칸 이상 비우거나**, 맵상 대각/떨어져 배치.  
- **실측(2026-08-31):** `i21` 원점 (0, SECTOR_M) · `i11` 원점 (0, 0).  
  중심 거리 = **SECTOR_M(333m)** ≫ 40+52. **§4.1 충족 · 좌표 이동 불필요.**

### 5.2 연출

### 5.3 모으기에 대한 기획 질문 (답 필요)

> 마지막(또는 중간) 모으기에서 **무엇을 모으는가?**  
> - A. 정화제/퇴치제(발사체) ← 스킬 선택 보너스와 맞춰갈 후보  
> - B. 캐스팅/정화 게이지  
> - C. 스킬 차지  
> - D. 불필요 → 단계 삭제 또는 이름 변경  

답이 정해지기 전에는 필러·UI에 “모으기”만 단독으로 쓰지 않는다.

## 6. 적·보스 연출 (현행 합의)

### 6.1 얼룩 · 오염 · 벌레 · 펫

- 얼룩: 동그라미 점구름(툴 기준).  
- 오염물질: 입체.  
- 벌레: 벌레 실루엣 점구름 · 처치 후 펫 조우 가능.  
- 펫 점구름: **원흉 점구름 툴과 동일 로딩·petFit** (본색). 구조 UI 원 링·과도한 확대·흑백 덮개 지양.

### 6.2 원흉

- **밑:** 동그라미 얼룩.  
- **위:** 네모 원흉(툴 `네모·원흉` / culprit) — **항상 보이게** 모인 상태.  
- 이동: 둘 다 **퍼짐 → 이동 → 모임**.  
- 피격: 모임·피격 펄스·살짝 퍼짐 후 다시 모임.  
- HP: 본편 **10발** (테스트 수치는 별도).

### 6.3 정화 1·2·3차와 하늘 【확정】

- 1·2·3차 모두 **바닥 + 하늘/원경**이 정화량에 따라 변한다.  
- 한 지역 3단계까지 가면 **그 지역 하늘까지 완전 정화**. (정화 0/2 칸 카운트와는 별개)  
- **템포:** 하늘이 바닥보다 **빨리 확 바뀌면 안 된다.**  
  - 바닥 파도와 **같은 호흡**으로 하늘을 올린다.  
  - 파도 시작 시 하늘 풀개방 금지 → 파도 진행에 맞춰 천천히.  
  - 목표 체감: 1차 ~3.5초대 · 2차 ~4초대 · 3차 ~5.5초대 전후(조정 가능).  
- 지평선·안개 이음은 **직선으로 끊기지 않게** (하단은 안개색으로 녹임, 투명 띠 금지).

## 8. 펫 능력

- **공격력 중심은 폐기** (현 루프에서 의미 없음).  
- 타임어택·갈림에 맞는 역할로 재정의 후보:  
  - 탄약/줍기 보조  
  - 시계·시야·탐지  
  - 피격 한 번 가드 / 짧은 슬로  
  - 연출·합류 감정 (전투 DPS 아님)  
- 구체 수치는 1지역 타임어택 숫자가 고정된 뒤 맞춘다.

## 9. 선택의 기로 확대

현재 갈림이 너무 적다. 여정·섹터에 **갈림을 추가**하되 규칙:

1. 기본 축 = **빠르게 / 느리게**  
2. 타임어택 직전 = **더 모은다 / 바로 간다** (필수)  
3. 각 갈림은 **필러로 상황·대가 설명**  
4. 보상은 “무조건 이득”이 아니라 **타임어택 리스크와 교환**

예시 슬롯 (1지역 안, 확정은 배치 표로):

| 시점 | 갈림 |
|------|------|
| 섹터 직전 또는 직후 | 빠르게 이동 / 둘러보기 |
| **타임어택 전** | 정화제 더 / 바로 사냥 |
| 얼룩 후·벌레 전 | (옵션) 한 번 더 줍기 / 밀어붙이기 |
