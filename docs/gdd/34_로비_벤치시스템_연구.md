## 0. 연구 질문

1. 로비는 **어떤 화면·상태**여야 흩어짐이 해소되는가  
2. 벤치 게임에서 가져온 시스템 각각을 **로비 / 여정 / 둘 다** 중 어디에 붙이는가  
3. 이미 있는 XOOX 코드·CSV를 **최대한 재사용**하려면 무엇을 새로 만들고 무엇을 안 만드나  

원칙(`25`과 동일): **느낌만 재해석. 리터럴 금지.**

## 1. 로비 = 무지개섬 허브

### 1-1. 한 줄

> 로비는 “앱 런처”가 아니라 **가족이 있는 섬**이다.  
> 단말기는 섬 안의 도구일 뿐이다.

권고 톤: **A(섬 본진) + C의 단말기 조작** — 배경은 섬, 조작은 거점 UI.

### 1-2. 로비에서 보이는 것 (정보 설계)

```
┌──────────────────────────────────────────────────────────┐
│  무지개섬 · 구조연맹 거점              Day N / 구역 이름   │
│                                                          │
│     [섬 장면: 리더 실루엣 · 파견 아이들 점경]              │
│                                                          │
│  ┌ 단말기 ─┐ ┌ 파견 ─┐ ┌ 모험 ─┐ ┌ 파티 ─┐              │
│  │스크랩북 │ │오늘보고│ │지난구역│ │동행 n │              │
│  │도감·일지│ │배치   │ │자동순찰│ │슬롯  │              │
│  └────────┘ └───────┘ └───────┘ └───────┘              │
│                                                          │
│              [ 외출하기 ]     [ 여정으로 돌아가기 ]         │
└──────────────────────────────────────────────────────────┘
```

로비 메뉴【확정】: **외출** · **파견** · **모험** · **기록(단말기)** · 파티  
(탐구/정화는 로비 메뉴로 빼지 않음 — `33` §2-1)

가로 1000×480 유지. 채팅 오버레이는 **로비에선 끄거나 최소화**【잠정】  
— 로비는 “기록 읽기”보다 “집에 있다”가 우선. 로그는 여정 전용.

### 1-3. 로비 상태 머신

| 상태 | 설명 |
|---|---|
| `LOBBY_IDLE` | 섬 기본 |
| `LOBBY_DISPATCH` | 파견 보드/결과 |
| `LOBBY_ADVENTURE` | **모험(자동)** — 깬 구역 선택·자동 순찰 결과 |
| `LOBBY_TERMINAL` | 스크랩·도감·일지·지도 (기존 폰 UI 흡수) |
| `LOBBY_PARTY` | 슬롯·교체(기존 교체 모달 이식) |
| → `JOURNEY_*` | 「외출」또는 「여정으로」 |

### 1-4. 기존 시스템 흡수 위치

| 현행 | 로비 흡수 후 |
|---|---|
| 스크랩북 FAB | 단말기 앱 (여정 FAB는 임시 유지→이후 제거) |
| 학습 스킬북 | 여정에 남김(전투 준비) 또는 단말기 【잠정: 여정】 |
| 파티 교체 모달 | `LOBBY_PARTY` |
| 탐방 맵 | 여정 전용 (로비 섬 장면은 **별 레이어**) |
| 미니게임 게이지 | 여정 전용 |

### 1-5. 섬 장면 연출 (1차)

아트 공백 전제:

- 플레이스홀더 그라디언트 + 파견 펫 아이콘이 섬 바닥에 점경
- 리더 아이콘 3~4개(대사 말풍선은 짧은 한 줄)
- Cozy Grove식 **탭으로 섬 걷기**는 2차(여정 탐방 코드 `explore.ts` 패턴 재사용 가능)

### 2-A2. Monopoly GO / 클리어 스테이지 자동 모험 【확정 채택】

| | |
|---|---|
| **레슨** | 이미 진행·클리어한 구간을 **자동으로 돌려 보상**(흔히 「모험」) |
| **안 가져옴** | 보드·주사위·랜드마크·셧다운 등 모노폴리 규칙 전체(XOOX 비범위, `25`와 동일) |
| **로비** | 「모험」메뉴 · 열린 구역 리스트 · 자동 순찰 결과 패널 |
| **여정** | 스토리 진행·관문 돌파는 여정만. 모험으로 스토리 day를 밀지 않음 |
| **구현** | 클리어 플래그(`stage`/`area`/`clearedNodes` 확장) + 자동 전투 시뮬 + 보상 CSV |
| **우선** | **S5** (`35`) — 관문/클리어 정의(S4) 다음 |
| **파견과 구분** | 파견=섬 아이들 / 모험=방랑자 지난 길 순찰 |

## 4. 데이터·코드 영향 (연구 결과)

### 4-1. 새로 필요할 것

| 항목 | 용도 |
|---|---|
| `src/lobby.ts` (권고) | 로비 렌더·상태 · `main.ts` 비대화 방지 |
| `LOBBY_*` stage/mode | 최상위 모드 |
| `island_task_config.csv` | 파견 문구·산출 (`23`) |
| `lobby_text` 또는 `ui_text_config` 키 | 외출/귀환/파견 보고 카피 |
| (선택) `lobby_spot_config.csv` | 섬 위 탭 스팟(리더·보드·단말기) |

### 4-2. 재사용할 것

| 항목 | 재사용 |
|---|---|
| `joinedPartyMembers` / `getPartySlots` | 파견 대상 산출 |
| `tigon_memory` + 스크랩북 DOM | 단말기 스크랩 |
| `explore.ts` 패턴 | 2차 섬 탭무브 |
| `runMapNode` / 전투 / 구조 | 여정 그대로 |
| 전체화면 패널 규격 | 단말기·파견 보드 |

### 4-3. 건드리면 안 되는 것 (1차)

- day 롤·구조 확률 스폰 공식 (`29`)
- 미니게임 진입 SSoT (`15`)
- CSV SSoT · 한글 표시명 분기 금지

## 5. UX 위험과 대응

| 위험 | 대응 |
|---|---|
| 로비가 매일 강제되어 템포 붕괴 | `33` 권고안 A — 소프트 로비 |
| 로비+여정+채팅이 또 한 화면에 혼선 | 로비에선 채팅 최소화 |
| 단말기=또 다른 흩어짐 | 단말기는 **로비 자식**만. 여정 FAB는 단계적 제거 |
| 아트 없어서 로비 공허 | 파견 아이콘 점경+리더 대사로 “사람이 있는” 느낌 먼저 |

## 6. 성공 기준 (연구 단계의 정의)

로비 1차가 성공하려면 플레이어가 말할 수 있어야 한다:

1. “여기는 **집(무지개섬)** 이야”  
2. “밖으로 나가서 **도전·정화**가 메인, **탐구**는 발로 찾아”  
3. “안 데려간 아이들은 **파견**, 지난 구역은 **모험(자동)**”  
4. “기억은 **찾아서**, 집에 와서 **스크랩으로** 봐”

기능 체크리스트보다 **이 네 문장이 나오는지**가 통과선이다.
