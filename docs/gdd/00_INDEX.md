## 갱신 규칙

1. **기능·수치·연출이 바뀌면** 해당 축 MD + `11_CHANGELOG` 를 같은 작업에서 업데이트한다.  
2. **지시자 확정 사항**은 문서에 `【확정】` , 잠정은 `【잠정】` , 미구현은 `【미구현】` 표기.  
3. CSV가 진실이다. 문서 숫자와 CSV가 다르면 **CSV 우선**, 문서를 고친다.  
4. 한글 CSV는 Windows에서 깨질 수 있음 → `scripts/fix-ui-text.mjs` 등 유니코드 이스케이프 스크립트 사용.
