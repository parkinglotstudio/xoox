## 0. 한 줄 【확정】

> RPG 탐방처럼 **지금 자리만 밝고**, **지나온 길은 조금 밝게 남고**, **안 간 곳은 어둡다.**  
> **안 간 곳의 노드는 보이지 않는다.**  
> 시야 크기 = 사람 **1 m** 기준 **약 10 m** 원.  
> 3D 여정에서 지평선 너머 산·구름은 이 안개가 아니다. 원경 원통 = [`46`](./46_여정3D_원경_맵컨셉.md).

## 1. 규칙

| # | 규칙 | 내용 |
|---|---|---|
| 1 | 현재 시야 | 캐릭터 중심 **원형** · 반지름 ≈ **10 m** |
| 2 | 지나온 길 | 걸은 경로에 발자국을 찍어 **살짝 밝게** 유지 (반지름 ≈ **8 m**) |
| 3 | 미탐방 | 거의 암막 (맵 실루엣만 아주 약하게) |
| 4 | 노드 | 시야 안 **또는** 지나온 발자국 근처만 표시 · 그 외 **숨김** |
| 5 | 적용 범위 | 배경 PNG 있는 육지 섹터(`artMode`) · 바다/단색 구역은 기존대로 |
| 6 | 정화 | after 원형 마스크는 **그대로** (안개와 별 레이어) |

지시 의도: “새로운 지역 탐방” 감 · 멀리 노드가 미리 다 보이면 안 됨.

## 2. 미터 → %

섹터 한 변 ≈ **333 m** → 월드 `x_pct`/`y_pct`가 그 칸을 채움.

| 키 (`sector_scale.json`) | 기본 | 의미 |
|---|---:|---|
| `fog_vision_m` | **10** | 현재 시야 반지름(m) |
| `fog_trail_m` | **8** | 지나온 길 밝기 반지름(m) |
| `character_height_m` | 1 | 기준 키 |
| `sector_world_w_m` / `_h_m` | 333 | % 환산 분모 |

```
visionPct ≈ fog_vision_m / sector_world_m × 100
         ≈ 10 / 333 × 100 ≈ 3.0%
```

튜닝은 JSON만 바꾸면 됨 (코드 재배포 없이 fetch).

## 3. 화면 레이어 (아트 모드)

아래 → 위:

| # | 레이어 | 역할 |
|---|---|---|
| 1 | 검정 월드 | 암막 바탕 |
| 2 | `explore-world-base` | before PNG · opacity ≈ **0.08** (미탐방 힌트) |
| 3 | `explore-world-trail` | before · 발자국 **마스크 합** · opacity ≈ **0.42** |
| 4 | `explore-world-lit` | before · **현재 시야 원** 마스크 · opacity **1** |
| 5 | `explore-world-color` | after · 정화 `purifyFoci` 원형 마스크 |
| 6 | 노드 / 배우 | 노드에 `fog-hidden` 시 비가시 |

걷는 중에는 시야 원이 경로를 따라가도록 `setInterval`로 갱신 (rAF 금지 원칙).

## 4. 데이터 · 저장

| 항목 | 내용 |
|---|---|
| 발자국 | 섹터별 `{x,y}%` 배열 · 걸을 때 경로 샘플링 |
| 상한 | 섹터당 약 400점 (오래된 것부터 절삭) |
| 유지 | **`sessionStorage`** 키 `xoox.exploreFog.<area_id>` |
| 리셋 | 탭/세션 종료 · 또는 스토리지 삭제 |

※ 세이브 슬롯 영구 저장은 **아직 없음**. 필요하면 나중에 run 세이브에 옮김.

## 6. 검수

1. `npm run dev` → 외출 / `__explore()`  
2. 부두 스폰: **원만** 밝고 먼 노드 없음  
3. 걸어가면 지나온 길이 남고, 새 노드가 원에 들어올 때 나타남  
4. `fog_vision_m`을 20으로 바꿔 새로고침 → 원이 커지는지 확인
