## 0. 무엇이 바뀌었나

지금까지 60일은 **날짜 스케줄**이었다. 8일차에 전투, 15일차에 정예… 하는 식으로 *시간표*가 콘텐츠를 결정했다.

이 문서는 그 시간표를 **공간(맵)** 으로 다시 깐다. 각 콘텐츠가 맵 위의 **장소**를 갖고, 플레이어는 그 사이를 오가며 능력을 쌓고 최종 보스에게 도달한다.

> **"이건 RPG 느낌도 이제 나게 되는 거지."** — 지시자

---

## 1. 핵심 발견 — `_2` 접미사는 "같은 장소의 재방문"이었다

데이터를 전수 확인한 결과, 콘텐츠가 전부 **2세트로 복제**돼 있었다.

| 대상 | 원본 | 복제본 | 실제 |
|---|---|---|---|
| 지역 | `loc_mercenary` 버려진 항만 초소 | `loc_mercenary_2` 버려진 항만 초소(임시) | **같은 장소** |
| 분기(NPC) | `b_devil` 등 11종 | `b_devil_2` 등 11종 | **같은 만남** |
| 적 | `c_normal` 등 12종 | `c_normal_2` 등 12종 | **같은 적, 난도만 상승** |

`_2` 세트는 후반 스테이지용으로 **난이도만 올린 동일 콘텐츠**다. 지시자 지적("일부는 같은 구역 혹은 NPC일 거고, 같은 건 하나로 묶어서 지역처럼 만들어야 돼")이 정확히 이 지점이다.

**해결:** 복제본을 지우지 않고, **후반 구역에서 같은 장소를 다시 지나가는 것**으로 배치했다. 데이터를 건드리지 않으면서 "왔다 갔다"의 서사적 근거까지 생긴다.

## 2. 맵 구조

```
        ┌──────────────────────────────────┐
        │  구역 04 · 오염 중심부  (46~60일)  │
        │  👑 탐욕의 근원  ← 최종 목적지     │
        │  ⚔️52 · 도전자 · 신호탑 · 항해일지  │
        │  📡 중계탑 · 🏕️ 마지막 쉼터        │
        └──────────────▲───────────────────┘
        ┌──────────────┴───────────────────┐
        │  구역 03 · 폐자재 지대  (31~45일)  │
        │  ♞ 오염 기사(관문) · ⚔️38          │
        │  🏚️ 항만초소 · 🚢 화물선 ← 재방문   │
        │  정령 · 폐기물거인 · 온기의조각      │
        └──────────────▲───────────────────┘
        ┌──────────────┴───────────────────┐
        │  구역 02 · 좌초된 항만  (16~30일)  │
        │  👑 탐욕의 근원(구역 보스) · ⚔️23  │
        │  🚢 화물선 · 📡 중계탑 · 🗺️ 항해일지│
        │  악마 · 감시카메라 · 생존자갈등      │
        └──────────────▲───────────────────┘
        ┌──────────────┴───────────────────┐
        │  구역 01 · 하수도 지구  (1~15일)   │
        │  ♞ 오염 기사(관문) · ⚔️8           │
        │  🏕️ 대피소 · 🏚️ 초소 · 🎡 룰렛     │
        │  떠돌이 · 사치품상인                │
        │  🚩 여정의 시작                     │
        └──────────────────────────────────┘
```

- **구역 = 스테이지**(`stage_map_id`로 연결). 각 구역은 화면의 5~6배 높이인 세로 맵
- **아래에서 시작 → 위로 전진**. 맨 위는 항상 **관문(정예/보스)**
- 구역 간 통로는 **양방향** — 이전 구역으로 되돌아갈 수 있다(능력 쌓기용 재방문)

## 3. 노드 타입

`area_npc_config.csv`의 `trigger_type`으로 구분하며, 타입별로 외형이 다르다.

| 타입 | 표시 | 참조(`trigger_ref`) | 배치 수 |
|---|---|---|---|
| `REST` | 🏕️ 초록빛 | `location_config` 안전 대피소 | 3 |
| `LOCATION` | 청록 라벨 | `location_config` | 6 |
| `MINIGAME` | 청록 라벨 | `location_config`(미니게임 링크 보유) | 4 |
| `NPC` | 연보라 라벨 | `branch_config` | 11 |
| `COMBAT` | ⚔️ **붉은 경고** | `combat_enemy_config` | 4 |
| `MINIBOSS` | ♞ **보라·크게** | `c_miniboss` | 2 |
| `BOSS` | 👑 **금빛·가장 크게·고동침** | `c_finalboss` | 2 |
| `MEMORY` | ✨ 금빛 반짝임 | `tigon_memory_config` | 8 |
| `MEMO` | 흔적(플레이버) | — | 1 |

**총 41개 노드**를 4개 구역에 배치했다. 고유 지역 6종·NPC 11종·고정 전투 8종이 **하나도 빠짐없이** 맵 위에 올라가 있다.

## 4. 지금 되는 것 / 안 되는 것

### 되는 것
- 4개 구역을 걸어 다니며 **왕복 이동**(구역01 ↔ 02 ↔ 03 ↔ 04)
- 모든 노드가 타입별로 구분되어 표시되고, 탭하면 방랑자가 걸어가 살펴봄
- 기억 조각 8개는 실제로 획득·수집됨(22번 문서)
- 하단 버튼(자동 진행)은 **기존 시나리오 그대로** 동작 — 맵과 충돌하지 않음

### 아직 안 되는 것 (다음 단계)
| 항목 | 메모 |
|---|---|
| **노드 콘텐츠 실행** | 지금은 "어떤 노드인지" 알려주기만 한다. 전투 노드를 눌러도 전투가 시작되지 않음 |
| 날짜와 맵의 관계 | 노드를 밟는 것과 일차 진행이 아직 연결되지 않음. 29번 §6-2 미결 |
| 진행 잠금 | 관문(정예/보스)을 안 깨도 다음 구역으로 갈 수 있음 — 소프트/하드 게이트 미적용 |
| 노드 소진 | 한 번 방문한 노드가 그대로 남음(기억 조각만 사라짐) |
| 자동 진행과 맵 위치 동기화 | 버튼 진행 시 방랑자가 맵의 어디에 있는지와 무관 |

## 5. 배치 원칙 (다음에 노드를 추가·수정할 때)

1. **아래(y 80~94%) = 진입부** — 쉼터·초반 지역
2. **중간(y 30~70%) = 자유 탐방** — NPC·미니게임·기억 조각
3. **위(y 6~20%) = 관문** — 전투 → 정예/보스 순으로 배치
4. 좌우는 20~80% 사이에서 지그재그로 — 직선으로 늘어놓지 않는다
5. 기억 조각은 **길에서 살짝 벗어난 위치**(x 20~24 또는 76~80)에 둔다 — 일부러 찾아가야 하도록

> 지시자 메모: "사이 간격이 좁아도 돼. 그 간격은 나중에 조절할 거니깐." → 현재 간격은 잠정값이며, `world_h_pct`(구역 높이)와 `y_pct`로 언제든 조절 가능.
