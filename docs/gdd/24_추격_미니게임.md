## 0. 결정된 스코프 (중요)

지시자 확인(2026-08-02): **XOOX 코어 루프를 대체하는 게 아니라, 기존 미니게임 슬롯에 들어가는 미니게임 1종**으로 한정한다. `15_MINIGAME_ENTRY.md`의 기존 5종(행운의 보물·신화 슬롯·행운의 룰렛·보물 파내기·마왕 타워 룰렛)과 같은 급의 **6번째 후보**.

---

## 1. 원안 (지시자 구술)

- 주인공이 달리며 특정 목적을 수행하려 하는데, **방해하는 대상이 뒤에서 따라옴**
- 주인공은 갈림길마다 **선택**의 기로에 섬
- 선택에 따라 **방해 대상이 늘어나거나**, 그가 **앞지르면 주인공에게 나쁜 짓을 함**
- 이를 막기 위해 주인공은 계속 선택함
- **같이 달릴 수 있는 펫이 나오면, 그 펫이 적을 마킹**해줌
- 카피바라고의 공식(로그라이크 진행)은 그대로 가져가되 이 연출 부분만 다름
- **목표 = 1등(경쟁 순위)**

## 2. 단서 리스크 코멘트 (원안 그대로 가면 안 되는 이유)

이전 리서치에서 확인한 사실: **카피바라고 원작 자체의 실제 코어 메카닉이 "전진하며 장애물 피하고 갈림길에서 선택하는 엔드리스 러너"**다(BlueStacks 공략 기준 — "moving forward... dodging obstacles... terrain splits"). 지금 XOOX는 이 러너 비주얼을 안 쓰고 하단 텍스트 로그로 추상화해서 오히려 원작에서 멀어져 있는 상태.

→ **이 미니게임을 실제 "옆에서 보는 러너 화면"으로 리터럴하게 구현하면, 카피바라고의 진짜 비주얼에 더 가까워지는 역효과**가 날 수 있다. 그래서:

- **채택:** 서사 구조(쫓김·따라잡히면 나쁜 짓·선택에 따라 적 증가·펫 마킹)는 살린다 — 카피바라고에 없는 진짜 새로운 텐션
- **회피:** 리터럴한 옆스크롤 러너 스프라이트 화면 대신, **지금 XOOX가 이미 쓰는 카드/로그 추상화 방식**으로 구현 — 예: 매 턴 "거리 게이지" 숫자 + 선택지 2~3개 + 카드 텍스트, 실제 캐릭터가 화면에서 달리는 그림은 없음(또는 최소한의 심볼로만)

## 3. 설계 방향 (초안)

### 3-1. 핵심 루프

```
[턴 시작] 거리 게이지 표시(주인공 vs 추격자)
   │
   ├─ 선택지 A/B(2지선다, 구조 조우 태그매칭과 유사한 UI 재사용 가능)
   │     A: 안전하지만 느림 → 추격자 거리 좁혀짐(또는 추격자 늘어남)
   │     B: 위험하지만 빠름 → 거리 벌어짐, 대신 실패 시 페널티
   │
   ├─ 판정: 추격자가 주인공을 앞지르면 즉시 페널티(나쁜 일 발생)
   │
   ├─ (합류 펫 있으면) 펫이 추격자 하나를 "마킹" → 그 턴 그 추격자 무력화/약화
   │
   └─ N턴 반복 → 마지막에 "1등 도착" 여부로 승패
```

### 3-2. 기존 시스템과의 연결점

| 요소 | 재사용 후보 |
|---|---|
| 2지선다 선택 UI | 구조 조우(`rescue_approach_config`)의 태그 선택 UI 그대로 재사용 가능 |
| 펫 마킹 | 합류 펫(`joinedPartyMembers`)이 있을 때만 발동하는 보너스 — 슬롯 밖 펫 개념(23번 문서)과는 별개, 전투 슬롯 펫 사용 |
| 진입 경로 | `15_MINIGAME_ENTRY.md`처럼 게이지 또는 특정 분기(`b_xxx`)로 진입하는 신규 `mg_chase`(가칭) 타입 |
| 등급/보상 | 기존 등급 6단계 체계와 별개로, "몇 등"으로 들어왔는지에 따른 보상 차등만 추가 |

### 3-3. 톤 — "나쁜 짓"의 구체화 필요

지금은 "추격자가 앞지르면 나쁜 짓을 한다"까지만 정해짐. XOOX 톤(귀엽고 밝은, 유기동물 구조 서사)에 맞게 구체화 필요 — 예: 스탯 일시 감소, 자원 뺏김, 다음 날 이벤트 텍스트가 나빠짐 등. **공포·폭력적 표현은 배제** (기존 세계관 원칙과 일치).

## 4. 결정 필요한 것

1. 이 미니게임의 진입 경로(게이지? 특정 스테이지 이벤트? 미니보스 전용?)
2. "추격자"의 정체 — 오염된 산업 잔재(액션 몬스터 계열)로 할지, XOOX 세계관에 맞는 새 존재로 할지
3. "나쁜 짓"의 실제 페널티 내용
4. 턴 수·난이도 곡선(몇 번 선택하면 끝나는지)
5. 펫 마킹 발동 조건 — 항상 발동인지, 특정 펫만인지
