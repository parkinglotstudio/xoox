# 36. 정화 컨셉 — 촉매 · 생명 · 지역

> 작성: 2026-08-08 · 상태: 【**컨셉 SSoT · 프로토 적용**】  
> 목적: 정화가 “전투 UI 하나”가 아니라 **찾아서 → 적용해서 → 되돌리는** 움직임으로 보이게 고정한다.  
> 관련: [`33`](./33_시나리오_진행플로우.md) · [`18`](./18_XOOX_정화전투_연출.md) · [`25`](./25_UI연출_리뉴얼_기획서.md) Cozy Grove · [`35`](./35_개발순서_로비중심.md)  
> 지시자 방향: 지역에서 원하는 아이템을 찾아 적용하면 정화. **반려동물뿐 아니라 지역도** 정화 대상.

---

## 0. 한 줄

> **정화 = 탐구로 촉매를 얻고, 오염된 대상에 적용해 생명·장소를 되돌리는 행위.**  
> 시스템은 나중에 키운다. 지금은 **루프가 눈에 보이게** 하는 것이 목표.

---

## 1. 왜 다시 쓰나

| 기존 | 문제 |
|---|---|
| 정화 전투(`18`) · 구조 조우 | “정화 = 또 다른 전투/퍼즐”로만 읽힘 |
| Cozy Grove 색 회복 | 문서엔 있으나 **정화 기둥과 루프로 연결 안 됨** |
| 4기둥의 정화 | 여정 이벤트에만 붙어 있고, **찾는 행위(탐구)** 와 분리됨 |

지시자 요청을 반영하면 정화의 주연 문장은 이렇게 바뀐다.

```
가다 → 찾다 → 쓰다 → 되살다
```

---

## 2. 컨셉 루프 【확정】

```
[여정 · 탐구]
  맵에서 촉매(아이템) 줍기
        │
        ▼
[소지]  촉매 1~소수 보유 (인벤 풀시스템 아님 · 슬롯 느낌)
        │
        ▼
[적용]  오염 지점(지역) 또는 오염된 생명에게 사용
        │
        ├─ 대상 = AREA  → 구역 톤이 밝아짐 (Cozy 색 회복 레슨)
        └─ 대상 = LIFE  → 구조/합류/환영 비트로 연결 (기존 구조·정화전투는 하위 연출)
        │
        ▼
[여운]  로비·파견·모험이 “맑아진 구역”을 나중에 이용 (디벨롭)
```

### 2-1. 역할 분담 (기둥)

| 기둥 | 이 루프에서 |
|---|---|
| **탐구** | 촉매·오염 지점을 **찾는** 행위 |
| **정화** | 촉매를 **적용**해 되돌리는 행위 |
| **도전** | 관문·액션 전투 — 정화와 겹치지 않음 |
| **파견/모험** | 정화된 구역의 후속 혜택(후순위) |

> 촉매 줍기 카드에는 `[탐구]`, 적용 성공에는 `[정화]` 라벨.

### 2-2. 대상 두 종류 【확정】

| 대상 | 의미 | 1차 피드백 | 나중에 |
|---|---|---|---|
| **AREA** | 오염된 장소 | **거점 원형 색 회복**(다중 합산 · Cozy) · 짧은 카드 | 파견 효율 · 모험 해금 · 구역 정화 % |
| **LIFE** | 오염된 생명 | 성공 카드 + (프로토) 환영 한 줄 | 구조 조우 / 정화 전투 스킨(`18`)으로 깊이 |

둘 다 **같은 “적용” 동사**를 쓴다. UI를 두 개로 쪼개지 않는다.

### 2-3. 촉매 (Catalyst)

| 규칙 | 내용 |
|---|---|
| 정체 | “원하는 아이템” — 약·물·빛·기억 조각형 도구 등 |
| 획득 | 맵 노드 `CATALYST` (탐구) |
| 소지 | `heldCatalysts[]` — **소수**. 창고 게임 아님 |
| 소비 | 적용 성공 시 1개 소모 【확정】 |
| 미스매치 | 잘못된 대상에 쓰면 실패 카드 · 촉매는 **안 씀** 【확정】 |

### 2-4. 오염 지점 (Blight)

| 규칙 | 내용 |
|---|---|
| 정체 | 맵의 탁한 웅덩이·녹슨 기계·병든 나무 등 |
| 노드 | `BLIGHT` + `blight_id` |
| 필요 촉매 | `needs_catalyst_id` 1종 (초판은 1:1) |
| 클리어 | 적용 성공 → 노드 소진 · 대상 정화 플래그 |
| 하드 진행 | **메인 day/관문을 막지 않음** 【확정】 — 보너스·깊이 |

---

## 3. 플레이어가 느끼는 한 판 (통과선)

구역01 하수도에서:

1. 탐방 중 **맑은 물방울(촉매)** 발견 → `[탐구]` 카드 · 소지 표시  
2. **탁한 물웅덩이(오염)** 접근 → 촉매 없으면 “뭔가 더 필요해”  
3. 촉매 있으면 **적용** → `[정화]` 성공 · 웅덩이 사라짐 · **맵이 밝아짐**  
4. (프로토) 오염된 생명 지점에 같은 촉매 적용 → 짧은 환영 비트  

이 네 박자가 보이면 컨셉 검증 통과.

## 4. 기존 시스템과의 관계

| 시스템 | 관계 |
|---|---|
| 구조 조우 / `simulatePurifyCombat` | LIFE 정화의 **깊은 연출 모드**. 초판은 적용 성공 후 연결 가능, 필수는 아님 |
| Memory / 스크랩 | 촉매와 별개. 기억은 서사, 촉매는 도구 |
| 관문 하드 | 그대로. 지역 정화로 관문 스킵 금지 |
| Cozy 색 회복 | **지역 정화의 비주얼 언어**. 비해금=어두운 오염(검정 바탕·before 50%) · 캐릭터 스포트라이트 · 해금=원형 after 마스크. 상세 작업 정리 [`40`](./40_인게임_비주얼_작업정리.md) |

`18` 문서는 “정화 전투 스킨”으로 남기되, **정화의 입구 루프는 본 문서가 상위**다.

## 5. 데이터 (초판)

| CSV | 역할 |
|---|---|
| `purify_catalyst_config.csv` | 촉매 정의 |
| `purify_blight_config.csv` | 오염 지점 · 필요 촉매 · AREA/LIFE · 성공 문구 |
| `area_npc_config` | `CATALYST` / `BLIGHT` 노드 배치 |

상태 (`PlayerState`):

- `heldCatalysts: string[]`
- `purifiedAreas: string[]` — 지도·레거시 호환
- `purifiedBlights: string[]`
- `purifyFoci: { blightId, areaId, xPct, yPct, radiusPct }[]` — **맵 비주얼 SSoT**(원형 색 회복 합산)

`reveal_radius_pct`는 `purify_blight_config` (AREA 기본 28 · LIFE 기본 18).

## 6. 디벨롭 백로그 (지금은 안 함)

## 7. 개발 순서 반영

- **S6a (지금):** 컨셉 프로토 — 줍기→적용→지역 밝아짐 (+ LIFE 짧은 비트)
