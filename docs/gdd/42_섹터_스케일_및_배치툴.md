## 0. 한 줄 【확정】

> **섬 ≈ 1 km · 사람 ≈ 1 m · 3×3 = 9섹터(칸 ≈ 333 m).**  
> **섹터 1장 ≫ 모바일 한 화면.** 화면은 카메라로 섹터 안을 훑는다.  
> 노드 SSoT = `data/area_npc_config.csv`.

폐기: 섹터≈120 m · 섬 수백 m · `world_h_pct=100`(1섹터=1화면) · 9타일 확대 크롭을 섹터 배경으로 쓰기.

## 2. 오브젝트 크기 (1 m 기준)

| 대상 | 실측 |
|---|---|
| 캐릭터 | 1 m |
| 보행 길 | 2.5~3.5 m |
| 부두·큰 길 | 5~8 m |
| 초소·작은 집 | 5~8 m |
| 창고 | 12~20 m |
| 노드 간격 권장 | ≥ 15~25 m (칸당 10~13개 감) |

화면 안 캐릭 픽셀(`map_actor_h_px`)은 **느낌용** — 에디터 슬라이더로 조절. 미터(§1)는 고정.

## 4. 에디터 (`sector-editor`)

```bash
cd C:\xoox
npm run dev:sector
```

| # | 기능 | 설명 |
|---|---|---|
| 1 | 섬 개요 | 9칸 + 육지 5칸 **아트 오버레이** |
| 2 | 노드 | 아이콘만 · 클릭=정보 · 전부 `area_npc_config` |
| 3 | 초록 박스 | 모바일 시야 비율 · 드래그로 섬 훑기 |
| 4 | 아래 패널 | 그 시야를 **섹터 아트 크롭**으로 크게 · 노드 드래그 배치 |
| 5 | after / before | 상단 셀렉트 · 정화 전후 전환 |
| 6 | 패널 리사이즈 | 가로줄=섬↔모바일 높이 · 세로줄=사이드 폭 · `localStorage` 유지 |
| 7 | 저장 | CSV → `POST /__data_save` |

캐릭 높이 슬라이더 = 모바일 패널 안 토큰 크기 미리보기.
