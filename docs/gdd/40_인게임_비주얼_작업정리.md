## 3. 탐방 섬 · 타일 (순서 5~7, 10~11)

### 3-1. 구조 (현행)

```
섬 ≈1km · 3×3 섹터 그래프
  → 플레이 배경 = 섹터 통짜 PNG (육지 5칸) · 화면은 그중 일부
  → 보행 = 육지 십자만
```

```
 i00(바다) | i01(북)   | i02(바다)
 i10(서)   | i11(중앙) | i12(동)
 i20(바다) | i21(부두) | i22(바다)
```

- **스폰:** `area_i21` 부두  
- **연결:** `i01↔i11` · `i11↔i21` · `i10↔i11` · `i11↔i12`  
- 코너 바다는 보행 금지  

(구: 마스터 1장→9타일 풀스크린 — **폐기**, [`42`](./42_섹터_스케일_및_배치툴.md))

### 3-2. 파일

| 경로 | 역할 |
|---|---|
| `data/ui/journey/sector_iXX_{after\|before}.png` | 【**현행 육지 배경**】 → [`44`](./44_섹터배경_정화전후.md) |
| `data/ui/journey/island_overview_1km.png` | 에디터 섬 개요 |
| `data/area_config.csv` | 육지 `world_h_pct=497` · `background_asset`→`sector_*_before` |
| `data/area_connection_config.csv` | 육지 십자만 |
| `journey_tile_*` / `journey_island_master_*` | 【레거시】 구 9타일 크롭 — 플레이 배경으로 쓰지 않음 |

### 3-3. 교훈 (확정)

1. **4등분으로 각각 ‘섬 하나’처럼 그리면 합쳐지지 않는다.**  
2. 바다 여백이 큰 채 자르면 **출구가 바다** → 보행은 육지 십자만.  
3. **1섹터=1화면 크롭 폐기** → 섹터 통짜 + 카메라 ([`42`](./42_섹터_스케일_및_배치툴.md)).

## 5. 정화 비주얼 (순서 3~4, 9, 13~14)

### 5-1. 루프 (시스템)

[`36`](./36_정화_촉매_지역정화.md) 유지:

```
탐구로 촉매 줍기 → 오염(BLIGHT)에 적용 → AREA면 맵 색 회복 / LIFE면 환영·전투
```

### 5-2. 레이어 스택 (아트 모드) 【확정】

아래에서 위로:

| 레이어 | 내용 | 비고 |
|---|---|---|
| 월드 바탕 | `#000` | 정화전을 더 어둡게 |
| `.explore-world-base` | `*_before.png` | **opacity 0.5** |
| `.explore-world-lit` | 같은 before | 캐릭터 주변 **마스크 100%** 그라데이션 강조 (따라다님) |
| `.explore-world-color` | `*_after.png` | `purifyFoci` 원형 마스크로만 보임 |
| props / actor | POI · 주인공 | 최상단 |

### 5-3. 원형 해금 데이터 【확정】

| 키 | 역할 |
|---|---|
| `PlayerState.purifyFoci[]` | `{ blightId, areaId, xPct, yPct, radiusPct }` — **맵 비주얼 SSoT** |
| `purify_blight_config.reveal_radius_pct` | AREA≈28~34 · LIFE≈18 |
| `tryApplyPurify` | BLIGHT NPC 좌표로 focus push |
| `purifiedAreas` | 지도·레거시 호환 (AREA 1개라도 성공 시) |

적용 시 원이 `0 → target`으로 스텝 성장 (rAF 금지 · `setTimeout`).

### 5-4. 부두 데모 (첫 지역)

| 단계 | 행동 |
|---|---|
| 1 | 외출 → `area_i21` 부두 |
| 2 | **맑은 물방울** (`s1_catalyst`) 줍기 |
| 3 | **탁한 물웅덩이** (`s1_blight_pool` / `blight_s1_pool`) 적용 |
| 4 | 웅덩이 좌표에 컬러 원 퍼짐 · 노드 소진 |

콘솔 원샷: `__demoPurifyFirst()` · 토글 미리보기: `__purifyTile()`

### 5-5. Cozy에서 가져온 것 / 안 가져온 것

| 가져옴 | 안 가져옴 |
|---|---|
| 거점 원형 색 회복 · 다중 합산 | 등불 설치 루프 |
| 진행이 맵에서 보이게 | 유령 곰 퀘스트 복제 |
| UI는 월드와 분리(항상 읽힘) | 아이소 스타일 강제(우리는 셀+오염톤) |
| | 비해금=크림 채색북 (우리는 **어두운 오염**) |

## 9. 캐릭터 표현 이원화 — 지도 토큰 / 전투 전신 【조사·제안 2026-08-08】

### 9-1. 문제

지금 탐방 맵에 `lobby_actor_idle`(전신 사람)을 올리면:

| 문제 | 내용 |
|---|---|
| 스케일 | 탑뷰 섬 타일 위에서 **사람 비율이 거대·이질** |
| 제작 | 걷기·방향·애니 프레임을 **전신으로** 맞춰야 해서 난이도↑ |
| 연출 | 맵은 ‘위치 표시’, 전투는 ‘캐릭터 쇼’인데 **역할이 섞임** |

지시자 상태: **맵 이동 비주얼은 아직 미정** · 아래 조사로 후보만 모음.  
전투는 전신으로 두는 쪽은 유지.

#### B. 연출 디테일 (유형과 무관하게 좋은 것들)

| 기법 | 출처·관례 | 효과 |
|---|---|---|
| **발밑 그림자** | 탑다운 공통 | 떠다니는 스티커 방지 · 지면감 |
| **약한 bob/호흡** | 맵 마커 가이드 | ‘살아 있음’ · 과한 번쩍임 금지 |
| **이동 시만 강조** | Metroidvania 맵 마커 | idle은 조용 · 탭 이동·도착만 hop |
| **실루엣 우선** | 아이콘 디자인 | 작은 크기에서 색보다 **형태**가 읽힘 |
| **맵이 주연** | 오픈월드 내비 가이드 | 마커는 안내 · **섬 그림이 주인공** |

#### C. XOOX에 맞춰 다시 보면

지금 탐방은:

- 그림이 이미 **예쁜 섬 타일**(주연)  
- 조작은 **탭투워크**(연속 위치)  
- 전투는 **전신 쇼**를 따로 쓸 예정  
- 테마는 **정화·빛·오염**

그래서 “맵 이동의 좋은 비주얼”은 보통:

> **맵 아트를 가리지 않는 작은 심볼 + 약한 생동감(그림자·bob·hop)**  
> 전신 사람은 ‘전투·로비 장식’에 맡긴다.

#### D. XOOX 추천 후보 3장 (아직 미확정)

| 순위 | 후보 | 한 줄 | 왜 |
|---:|---|---|---|
| ★1 | **랜턴/빛 토큰** | 작은 등불·빛구슬이 섬을 다님 | 정화·스포트라이트와 언어가 같음 · 오염 보라 맵에서 잘 보임 · 제작 쉬움 |
| ★2 | **얼굴 코인** | 원형 메달+얼굴 | ‘나’ 인식 강함 · VTT/보드 검증됨 |
| ★3 | **보드 말(피규어)** | 작은 3D감 말 · hop | Monopoly식 귀여움 · 수집 확장 여지 |

비추천(지금): 탐방용 **로비 전신 PNG** 그대로 · **노드맵만 있는 게임**의 커서(탭워크와 안 맞음).

### 9-3. 이원화 골격 【방향만 · 형태는 미정】

```
탐방 맵 이동  →  「작은 심볼」(위 D 중 택1) + bob/hop
전투          →  「전신 SD」(카피바라식)
로비 거점     →  「전신 장식」가능 (맵 심볼과 별 트랙)
```

형태(랜턴 vs 코인 vs 말)는 **지시자가 고른 뒤** 시안.

### 9-4. 제작·연동 메모

| 항목 | 내용 |
|---|---|
| 폐기(맵용) | 탐방에 `lobby_actor_idle` 전신 사용 |
| 유지 | 로비 장식용 전신 · 전투 전신 시안 |
| 다음 | 후보 1~2개 **맵 위에 올린 목업**으로 비교 (문서만으로 고르기 어려움) |

### 9-5. 다음 (지시자)

아이디어가  lagging이면:  
**랜턴 / 얼굴 코인 / 보드 말** 중 마음에 끌리는 쪽을 하나만 말해 주거나,  
“셋 다 목업으로 맵에 올려봐”라고 하면 비교 시안을 만든다.
