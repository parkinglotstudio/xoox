## 9.1 정보 구조

위에서 아래로 시선:

1. **언제** — 타임라인 (**가운데 정렬** road-track)  
2. **지금 뭐 함** — 상단 스테이지 (이동/전투/스킬/영지)  
3. **얼마나 셈** — HP·ATK·DEF·골드  
4. **무슨 일** — 양피지 로그 카드 (금테·좌측 액센트)  
5. **다음에** — 하단 도크 `64 | 버튼58px | 64` (대박·중박 아이콘=버튼 중심선, 라벨은 아래)

등급 배너: `grade_config.css_key` + Black Han Sans 워드아트  
카피: `ui_text_config` only (코드 폴백 최소)

## 9.2 메인 버튼 상태

| 상태 | 라벨 예 | 동작 |
|------|---------|------|
| idle | 다음날 | 일차 +1 롤 |
| combat | 전투 | 교전 시작 |
| combat-busy | 전투 중 | 입력 잠금 |
| moving | 이동 중 | 연출 |
| choosing | 스킬 선택 등 | 패널 오픈 |
| pending | 오픈/돌리기 | 미니게임 액션 |

카피: `ui_text_config`

## 9.4 스탯 표시 정책 【확정】

- ATK/DEF = **베이스(+이벤트 %)** 만 표시  
- 스킬 배율은 스탯바에 **안 올림** (전투 내부)  
- HP는 K표기 등 포맷 【일부·formatStat】
