## 2. Phase 1 — 채팅 패널을 오른쪽 소형 패널로

### 2-1. 목표
`25` §3 / `26` §1~2 그대로. 새 데이터·새 시스템 없음, **레이아웃 CSS + 컨테이너 구조만** 변경.

### 2-2. 작업 항목 (아래 §6 태스크 목록과 1:1 대응)

1. `index.html`의 `#app` 하위 최상위 레이아웃을 세로 flex-column에서 **가로 2분할**(메인 영역 + 우측 패널)로 변경할 지점 확인
2. `.feed`를 우측 패널 폭(잠정 30~35%, `25` §9-2 결정사항)으로 축소하는 CSS 작성
3. 카드 정렬 규칙 추가: 화자 있는 카드(코멘터리)=왼쪽 정렬+아이콘, 시스템/전투 로그=오른쪽 정렬 또는 중앙(`26` §2)
4. `syncFeedBottomPad` 등 기존 스크롤/패딩 로직이 새 폭에서도 깨지지 않는지 확인
5. 좌측(메인) 영역은 Phase 1 시점엔 **기존 상단 상태뷰를 그대로 두는 임시 상태**로 둔다(탐방 뷰는 Phase 2) — 빈 공간 방치 금지, 임시 배치 결정 필요

### 2-3. 완료 기준
- 로그가 오른쪽 소형 패널에서 정상 표시·스크롤됨
- 기존 게임 로직(구조 조우, 전투, 커맨터리) 전부 정상 동작(로그 위치만 바뀜)
- `npm run build` 통과, 실제 플레이로 최소 1일차~구조 조우 1회 확인

`25`~`27`번 문서에 설계는 돼 있으나, 아래 미결정 사항이 남아있어 Phase 1 완료 후 다시 계획한다:

## 4. 데이터 스캐폴딩 (선제 준비, 이번에 완료)

앞선 기획 문서(22·27번)에서 설계된 CSV 스키마를 **헤더만 있는 빈 스캐폴드**로 미리 만들어둔다. 코드에서 아직 안 읽으므로 게임 동작에 영향 없음(순수 추가, 안전).

- `data/tigon_memory_config.csv` (22번 문서 §2-2)
- `data/area_config.csv` / `data/area_connection_config.csv` / `data/area_npc_config.csv` (27번 문서 §2-1)

> **주의(실제로 스캐폴딩하며 발견):** 27번 문서 초안엔 `location_config.csv`로 적혀 있었으나, 그 이름이 **이미 기존 분기 이벤트 시스템에서 쓰이고 있어**(`loc_mercenary` 등, 완전히 다른 스키마) 충돌 확인 후 `area_*`로 정정했다. 27번 문서 §2-1에도 반영됨.

## 5. 커밋 체크포인트 (승인 필요)

`git status` 확인 결과, 마지막 커밋(`df82c0f`) 이후 미커밋 변경이 여전히 대량(도구 이식, cyber-breeds, gdd 21~28번 문서 등)으로 쌓여 있다. Phase 1 코드 작업(`index.html`/`main.ts`/`style.css` 수정) 전에 지금까지의 문서·에셋 작업을 커밋해 체크포인트를 잡는 걸 권장한다 — **커밋은 지시자 승인 후 실행**(프로젝트 규칙: git commit은 명시적 요청 시에만).
