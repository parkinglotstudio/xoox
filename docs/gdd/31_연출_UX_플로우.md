### 0-1. 읽는 법

각 플로우는 아래 형식으로 적는다.

1. **목표 감정** — 이 순간에 플레이어가 느껴야 할 것  
2. **진입 조건** — 언제 시작되나  
3. **비트 표** — `상태 → 입력 → 연출 → 피드백 → 다음`  
4. **채팅 / 하단 / 탐방** 거동  
5. **현행 구현** vs **목표**  
6. **확정 / 잠정 / 미결**

### 0-2. 전역 원칙 【확정】

| # | 원칙 | 근거 |
|---|---|---|
| P1 | **흐름(로그라이크)은 유지**, 겉모습·연출만 바꾼다 | `25` §0-2 |
| P2 | **버튼 진행 = 메인 시나리오** / **맵 탐방 = 숨은 보너스** | `29` §0-1 |
| P3 | 레퍼런스는 **리터럴 복제 금지**, 플로우 레슨만 쓴다 | `25` §0-2 |
| P4 | 애니 = `setTimeout`/`setInterval`만 (rAF 금지) | 프로젝트 규칙 |
| P5 | 수치·문구·타이밍 수치 = CSV SSoT. UX 규칙은 이 문서 | 데이터 철학 |
| P6 | 한 순간에 **주연 화면은 하나** — 탐방 / 전투 / 전체화면 패널이 동시에 “주인”이 되지 않는다 | 본 문서 신설 |
| P7 | 채팅은 **이야기의 자막·메신저**, 전투의 주연이 아니다 | Coffee Talk 레슨 + 지시자 UX 우선 |

### 0-3. 화면 상태(Mode) 사전 【확정 초안】

코드의 `stage_mode` / 패널 display와 맞춘다. UX 논의는 이 ID로 한다.

| Mode ID | 주연 | 탐방 | 채팅 | 하단 도크 | 비고 |
|---|---|---|---|---|---|
| `BOOT` | 스플래시/인트로 | 숨김 | 숨김·최소 | 숨김 | 최초 1회 |
| `CUTSCENE` | 전체화면 컷신 | 숨김 | 대사 박스 | 숨김 | 기존 컷신 |
| `IDLE` | 탐방(+연출 배경) | **ON** | 오버레이 ON | ON · 「다음날」 | 기본 대기 |
| `EVENT` | 탐방 + 이벤트 카드 | ON | ON | 상황에 따라 | 일차 이벤트 |
| `LOCATION_*` | 탐방 + 지역 내러티브 | ON | ON | ON/잠금 | 기존 LOCATION |
| `BRANCH` | 선택지 | 숨김·디밍 | ON | 선택 UI | 분기 |
| `RESCUE` | 구조 링 연출 | 숨김 | ON(코멘터리) | 잠금 | 구조 조우 |
| `COMBAT_WAIT` | VS/조우 | 숨김 | 요약 카드만 | 「전투」 | 교전 직전 |
| `COMBAT` | 전투 스테이지 | **숨김** | **디밍·요약 모드** | 전투 중 UI | §F4 |
| `SKILL` | 스킬 3택1 패널 | 숨김 | 가림 | 가림 | 전체화면 규격 |
| `MINIGAME` | 미니게임 패널 | 숨김 | 가림 | 가림 | 전체화면 규격 |
| `SCRAPBOOK` | 스크랩북 패널 | 디밍 | 가림 | FAB 유지 가능 | 전체화면 규격 |
| `VICTORY` | 승리 패널 | 숨김 | 가림 | 가림 | 예외 연출 |

> **탐방 노출 규칙(현행=유지):** `IDLE` · `EVENT` · `LOCATION_*` 에서만 ON (`EXPLORE_MODES`). 전투/구조/스킬/미니게임 진입 시 자동 숨김.

## 1. 전체 여정 지도 (한눈에)

```
[BOOT/CUTSCENE]
      ↓
[IDLE 탐방] ←――――――――――――――――――――――――――┐
   │                                      │
   ├─ 「다음날」→ 일차 롤 → EVENT/전투예약…┤
   ├─ 맵 탭 이동 → (선택) 노드 접근 ──────┤
   │     ├ MEMORY → 조각 획득 → FAB 📖     │
   │     ├ REST/MEMO → 플레이버            │
   │     ├ NPC/LOCATION → 분기·지역 ──────┤
   │     ├ MINIGAME → MINIGAME 패널 ──────┤
   │     └ COMBAT* → COMBAT_WAIT → COMBAT ┤
   ├─ 📖 FAB → SCRAPBOOK → 닫기 ──────────┤
   └─ 게이지 풀 → 미니게임(일일) ─────────┘
```

**핵심 루프 문장:**  
하루는 버튼으로 흐르고, 발품은 보너스를 줍니다. 둘 다 끝나면 다시 IDLE의 탐방 위에 채팅이 겹칩니다.

## 2. 공통 연출 규격

### 2-1. 전체화면 패널 전환 【확정 · 구현됨】

출처: `26` §7-3

| 항목 | 값 |
|---|---|
| 등장 | 220ms · opacity 0→1 · 8px 상승 · 0.985→1 |
| 내용 | 60ms 지연 · 12px 상승 |
| 뒤 화면 | `blur(4px)` |
| 퇴장 | **목표:** 160ms 페이드아웃 후 `display:none` 【잠정·미구현, 현재는 즉시】 |
| 적용 | 스킬·미니게임·컷신·보상·악마계약·VS·스크랩북 등 |
| 예외 | `.victory-panel` |

### 2-2. 지역(구역) 전환 【확정 · 구현됨】

| 비트 | 연출 |
|---|---|
| 1 | 출구 방향으로 걸어감 |
| 2 | 페이드 아웃 |
| 3 | 새 구역 enter · 반대편 스폰 |

> `26` §8의 “전환 미정”은 **폐기**. 현행 페이드+워킹을 【확정】으로 승격한다.

### 2-3. 노드 접근 공통 비트 【확정 · 부분 구현】

| # | 비트 | 연출 | 현행 |
|---|---|---|---|
| N1 | 탭 | POI 하이라이트(짧게) | 약함 |
| N2 | 이동 | 거리비례 걷기 · bob · 방향전환 | ✅ |

### 2-4. 채팅 패널 전역 규칙 【확정 제안 → 지시자 확인 필요 항목은 미결 표기】

| 상황 | 채팅 거동 | 상태 |
|---|---|---|
| IDLE / EVENT / LOCATION | 우측 오버레이 · 반투명 · 자동 스크롤 | ✅ 확정·구현 |

| **COMBAT 중** | **디밍(opacity↓) + 신규 전투 로그는 상단 전투 로그에만** · 채팅에는 시작/결과 요약 1~2장 | 【확정 · 구현】 §F4 · `feed-combat-dim` |
| BRANCH / RESCUE | 채팅 ON · 선택·코멘터리 중심 | ✅ |
| 전체화면 패널 | 채팅 가림(패널 아래) | ✅ |

| 긴 나레이션 | 줄당 ~20자 유지 · 카드 과다 시에도 스크롤로 처리(축약 금지) | ✅ |

### 2-5. POI 표시 정책 【확정】

`25` §9-5 / `26` §7-2 미결을 본 문서에서 닫는다.

| 타입 | 표시 | 기둥 배지 | 이유 |
|---|---|---|---|
| MEMORY / MEMO / REST / LOCATION | 상시(MEMORY는 빛남) | **탐구** | 발품·흔적 |
| NPC | 상시 | **탐구** | 만남·발견 |
| MINIGAME / COMBAT / MINIBOSS / BOSS | 상시 · 경고 톤 · cleared | **도전** | 돌파·관문 |
| (구조 조우 — 맵 외 스폰) | 여정 이벤트 | **정화** | 죽이지 않고 되돌림 |

배지는 POI당 **짧은 한글 1단어**만. 아이콘 클러스터·추가 이모지 스팸 금지(`33` 4기둥).

## 3. 플로우 상세

### F1. 부팅 → 첫 IDLE

**목표 감정:** “예쁜 세계가 열린다” → 곧바로 만질 수 있다.

| # | 상태 | 입력 | 연출 | 다음 |
|---|---|---|---|---|
| 1 | BOOT | 자동 | 스플래시 | CUTSCENE |
| 2 | CUTSCENE | 탭/자동 | 전체화면 대사 · fullscreen-in | IDLE |
| 3 | IDLE | — | 탐방 ON · 시작 구역 · 채팅에 인트로 카드 | 대기 |

**현행:** 동작함.  
**다듬기:** 컷신→탐방 첫 페이드가 거친지 실측 후, 필요 시 160ms 크로스페이드 【잠정】.

### F2. 「다음날」 자동 진행 (메인 루프)

**목표 감정:** 편하고 리듬감 있게 하루가 간다. 카피바라고식 편안함 유지.

| # | 상태 | 입력 | 연출 | 채팅 | 탐방 |
|---|---|---|---|---|---|
| 1 | IDLE | 「다음날」 | 버튼 press · 짧게 moving 캡션 | 일차 헤더 카드 | ON 유지 가능 |
| 2 | EVENT 등 | 자동 | 등급 배너/효과칩(기존) | 내레이션·보상 | ON |
| 3 | (전투 예약 시) | — | COMBAT_WAIT로 전환 | 조우 카드 | 숨김 |
| 4 | 종료 | — | IDLE 복귀 | 결과 카드 | ON |

**확정:** 버튼 경로는 기존 `engine` 시나리오를 **변경하지 않는다** (`29`).  
**연출 목표:** 맵 위치와 day는 **아직 강제 동기화하지 않음** 【확정·당분간】 — 탐방은 보너스라 day와 싸울 필요 없음.  
**미결(후순위):** “하루가 지나면 방랑자가 맵에서 살짝 위로 자동 이동” 같은 **장식 동기화**는 Phase 후반에만 검토.

**채팅:** 이동만으로는 카드 안 씀(조용함 유지).

### F4. 전투 (액션 / 정화 공통 골격)

**목표 감정:** 상단이 싸움터, 채팅은 관전 자막. 카피바라고처럼 피드가 전투 로그로 도배되지 않게.

#### F4-a. 진입

| # | 비트 | 연출 |
|---|---|---|
| 1 | 조우 | 채팅에 조우 요약 1장 · mode=`COMBAT_WAIT` · 탐방 숨김 |
| 2 | VS | 전체화면 VS(규격 2-1) · blur |
| 3 | 시작 | mode=`COMBAT` · 상단 액터/게이지 · 하단 전투 UI |

#### F4-b. 전투 중 채팅 【확정 · 구현】

| 규칙 | 내용 |
|---|---|
| R1 | 채팅 패널 **남기되 디밍**(opacity≈0.4) — `feed.feed-combat-dim` |
| R2 | **턴별 전투 로그는 상단 전투 로그에만** 쌓는다 |
| R3 | 채팅에 추가 금지: 매턴 “피해 N” 스팸 |
| R4 | 채팅 허용: 조우/결과 요약 · (맵 노드) 접근 카드 1장 |
| R5 | 플레이어가 채팅을 스크롤해도 전투는 멈추지 않음(관전) |

> 맵 노드 전투도 동일 골격. 종료 후 반드시 `IDLE` 복귀·탐방 재표시(S4.3).

#### F4-c. 종료 → 복귀

| # | 비트 | 연출 |
|---|---|---|
| 1 | 승/패 판정 | 상단 결과 연출 |
| 2 | 보상/패배 | 카드 1~N · 채팅 디밍 해제 |
| 3 | IDLE | 탐방 페이드인 · 노드면 `cleared` · 카메라 유지 |

**정화 전투 추가 비트:** `18` 재설계(HP바·타락바·펫 아이콘 위 배치)는 **F4의 스킨**으로 Phase 2에서 적용. 골격(진입/디밍/복귀)은 액션과 공유.

|---|---|---|---|
| 1 | 원거리 | 희미한 반짝임만 | 상시 ✨ 【목표와 다름】 |
| 2 | 접근 반경 | ✨+라벨 페이드인 | 미구현 |
| 3 | 탭→접근 | N1~N4 | ✅ |
| 4 | 획득 | 조각 카드 + 리더 반응 · `(n/8)` · POI 제거 | ✅ |
| 5 | FAB | 📖 배지 등장/갱신 · 짧게 펀치 | ✅(펀치 약함) |
| 6 | (선택) 자동 오픈 | **하지 않음** — 플레이어가 FAB로 연다 | ✅ 의도 |

**잠정 수치:** 접근 반경 = 화면 좌표 기준 POI 주변 ~12%p 【실측 후 조정】.

### F7. 맵 노드 — REST / MEMO / LOCATION / NPC

| 타입 | 목표 감정 | 결과 비트 | 소진 |
|---|---|---|---|
| REST | 숨 고르기 | 플레이버 + 효과칩 · 반복 가능 | 소진 안 함 ✅ |
| MEMO | 세계 냄새 | 플레이버 1장 | 소진 안 함 |
| LOCATION | 장소 이야기 | 기존 `resolveLocation` · 필요 시 미니게임 링크 | 1회 cleared 【잠정】 |
| NPC | 만남 | `showBranchPrompt` · 선택 | 1회 cleared 【잠정】 |

**복귀:** 패널/분기 종료 후 IDLE · 탐방 유지 또는 재표시.  
**연출 구멍:** 분기 종료→맵 복귀 시 “방랑자가 그 자리에 서 있음” 유지 ✅ / 캡션 동기화 점검 필요.

### F9. 맵 노드 — COMBAT / MINIBOSS / BOSS

맵에서 시작해도 **F4와 동일한 전투 골격**을 탄다.

|---|---|
| 승리 시 | 노드 `cleared` · 외형 흐림 |

| 관문 연출 | 보스/정예는 접근 시 짧은 경고 진동(화면 아님, POI 펄스 강화) 【잠정】 |

**코드 실측(2026-08-08):** `runMapNode`가 COMBAT/MINIGAME/LOCATION/NPC/REST를 **이미 호출**한다.  
`30` §4 “콘텐츠 실행 안 됨”은 **문서 지연** — 실제 과제는 “실행”이 아니라 **실행의 연출·복귀 UX 완성도**.
