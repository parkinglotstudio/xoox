# 01. 개요 (Overview)

> 축: 이 게임이 무엇인지 / 왜 만드는지 / 어디까지만드는지

## 1.1 한 줄 요약

**카피바라 고(Capybara Go)** 원작을 영상·지시로 리버스하여,  
**일일 모험 로그 + 상단 상황/전투 화면**을 CSV 기반으로 재현하는 프로토타입.

---

## 1.2 목표

| 목표 | 설명 |
|------|------|
| 원작 리듬 재현 | 60일 여정, 등급 로그, 분기, 미니게임, 전투·보스 스케줄 |
| 데이터 구동 | 밸런스·카피·연출 수치를 코드에 박지 않고 CSV로 관리 |
| 밸런스 기반 | 맵(30일) 단위로 난이도·드랍·스킬 체감을 맞출 수 있는 골격 |
| 확장 | 추후 「수스」「시드라」 등으로 갈라질 공용 수집 단계 |

---

## 1.3 제품 철학 【확정】

1. **CSV = 단일 진실(SSoT).** 숫자·문구·가중치·구성은 테이블.  
2. **코드 = 규칙 엔진.** 롤·적용·연출 타이밍만.  
3. **하드코딩 금지** (스킬 ID별 if, 매직 넘버 지양). 예외는 문서에 명시 후 제거 예정.  
4. **연출 타이밍:** `setInterval` / `setTimeout` 사용. `requestAnimationFrame` 금지 (프로젝트 규칙).  
5. **프리즘 스쿼드** 문서는 **구조 참조만** (투사체·실시간 서바이버 로직 이식 안 함).

## 1.4 범위

### 범위 안 (현재 프로토)

- 폰 프레임 UI (타임라인 / 상단 상황 스테이지 / 스탯 / 로그 피드 / 게이지·버튼)
- 일차 진행, 콘텐츠 롤, 등급 카드, 분기, 지역·시나리오
- 미니게임 (행운의 보물 골드 슬롯, 룰렛, 카드 매칭 등)
- 전투 (상단 턴 로그, 최대 15턴)
- 스킬 학습·**강화(+)**·북·3택1 (ALWAYS effect 최소)
- 아이템/재화/마일스톤 (item 중심)

### 범위 밖 · 의도적 미구현

| 항목 | 상태 |
|------|------|
| 원작급 3D/캐릭터 액션 전투 | 미구현 (상단은 상황+텍스트 전투 로그) |
| 장비 장착·강화 UI | **없음** → 스탯은 **풀장착 가정** 숫자 사용 【확정】 |
| 상점·육성 메타 전체 | 부분만 (재화 수집, sink 약함) |
| skill_effect 조건부 트리거 완전체 | 확장 예정 (ALWAYS만 구현) |
| 프리즘 EVO / 투사체 | **제외** (`12_SKIPPED_REWORK`) |

---

## 1.5 플레이 한 줄 루프

```
다음날 → (이동 연출) → 전투 or 콘텐츠
  ├ 전투: 상단 교전 로그 → 보상 → (레벨업/상자)
  └ 콘텐츠: 등급 로그 / 지역 / 분기 / 미니게임
→ 스탯·게이지·스킬 갱신 → 반복 (맵1: 1~30일, 맵2: 31~60일)
```

---

## 1.6 용어 (지시자·개발 공통)

| 용어 | 의미 |
|------|------|
| 일차 | 런 안의 Day (1~60) |
| 맵 / 스테이지 맵 | **30일 단위** 난이도 구간 (맵1, 맵2…) — 상단 visual-stage와 다른 개념 |
| 상단 스테이지 | 이동/전투/스킬/영지 **상황 UI** |
| 런 레벨 | 인게임 레벨 (챕터 끝나면 사라지는 성장) |
| 풀장착 가정 | 장비 UI 없이 ATK/DEF/HP를 원작 장착 완료에 가깝게 둔 베이스 |
| SSoT | Single Source of Truth — 주로 CSV |
