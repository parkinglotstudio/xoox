## 7.1 런 구조

| 항목 | 값 |
|------|-----|
| 런 길이 | **60일** (현 스케줄) |
| 맵 단위 | **30일 = 맵 1개** 【확정·지시】 |
| 스테이지1 | 1~15일 · CLEAR (보스까지 무난) |
| 스테이지2 | 16~30일 · EDGE (보스에서 아쉽게) |
| 스테이지3 | 31~45일 · MID (중반까지) |
| 스테이지4 | 46~60일 · EARLY (초반까지) |
| 클리어 | 최종보스 처치 → 챕터 메타 |

챕터를 반복할 수 있음 (localStorage). 런 레벨·인런 스킬은 챕터와 함께 리셋되는 성격.

---

## 7.2 타임라인 UI

- 상단 `day-roadmap`: 검(전투), 해골(정예/최종), ?(이벤트) 등  
- 데이터: `combat_day_schedule`  
- 원작: 전투일이 **미리 박혀 있음** → 순수 확률만으로는 불충분 (RE 결론)

### 스케줄 앵커 (현행)

| 일차 | 내용 |
|------|------|
| 6,8,9,11,19,25,35,50 | 일반 전투 |
| 15,30,56 | 정예(미니보스) |
| 13,40 | 이벤트 마크 |
| 60 | 최종보스 |

30일 = 맵1 클imax(정예), 60일 = 맵2 최종.

## 7.3 맵과 밸런스 연결

`stage_map_config` 배율이 적 HP/ATK/DEF·드랍에 곱해짐.  
상세 숫자: `03_BALANCE.md`.

---

## 7.4 레벨(런 레벨)

- EXP → `levelup_config`  
- 레벨업 시 HP% 회복 + 스킬 지급(CHOICE_3 / AUTO + 티어)  
- **스킬 강도는 런 레벨에 연동** (ATK 스탯과 분리)
