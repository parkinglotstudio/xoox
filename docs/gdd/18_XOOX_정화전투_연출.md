# 18. XOOX 정화전투 연출 재설계

> 축: XOOX 정화 전투(`simulatePurifyCombat`)의 화면 레이아웃·펫 능력 표현
> 갱신: 2026-07-17
> 관련: [`17_XOOX_전환.md §6`](17_XOOX_전환.md) — 이 문서는 §6에서 만든 정화 전투 UI를 실제 플레이해보고 나온 문제를 재설계한 것

---

## 0. 배경

`17_XOOX_전환.md §6`에서 구현한 정화 전투 화면(펫=버프 배지, HP는 텍스트 로그)을 실제로 플레이해보니 시각적으로 문제가 많다는 피드백이 나왔다. 스크린샷 리뷰 + 코드 대조로 원인을 진단하고, [Summoners War의 버프 표시 방식](https://summonerswar.fandom.com/wiki/Abilities)(버프는 유닛 HP바 위에 아이콘으로, 탭하면 툴팁으로 상세 설명) 등 실제 게임 UI를 참고해 재설계한다.

---

## 1. 진단된 문제

| # | 문제 | 원인 |
|---|---|---|
| 1 | 적 아이콘이 VS 화면에서 완전히 빈 칸으로 나옴 | `c_purify_miniboss`의 아이콘 "🌫️"(안개)가 브라우저 폰트에서 렌더링 안 됨 |
| 2 | 모험가 아이콘(🪺 새둥지)이 뭔지 설명 없이 등장, 그 밑에 펫 배지가 나란히 붙어 "여러 존재가 나열된 팀"처럼 보임 | 위계(모험가=나 vs 펫=버프 소스) 구분이 시각적으로 없음 |
| 3 | 정화 게이지가 숫자로만 있고(로그 텍스트 "잔여 183") 시각적 진행 바가 없음 | 진행 바 UI 자체를 안 만듦 |
| 4 | 액션전투용 하단 스탯바(LV/HP18K/ATK/DEF/GOLD)가 정화 전투 중에도 계속 보여서, 서로 다른 HP 두 개(모험가 정화HP 31/80 vs 액션HP 18K/18K)가 동시에 표시됨 | `stageBars`(실드·분노 바)만 숨기고 하단 상시 스탯바는 안 숨김 |
| 5 | 펫 버프가 "정화력 +25%" 같은 모호한 수치라 왜 좋은지 설명이 없음 | 버프 배지에 설명 텍스트 자체가 없음 |
| 6 | 전투 진입 시 게이지(대박/중박 등)가 순간적으로 사라지는 것처럼 보임 | 【확인 필요】 `setGaugesVisible`은 분기·미니게임 모달에서만 호출되는 걸 확인함 — 정화 전투 진입 자체가 원인은 아닐 가능성이 높으나, VS 인트로↔전투뷰 전환 사이 `stageBars` 숨김 타이밍 때문일 수 있음. 구현하면서 재확인 |

## 2. 펫 능력 재설계 — 모호한 %buff → 명확한 효과

**원칙**: 펫마다 서로 다른 방식(고정 스탯 / 주기 스킬 / 조건 스킬) 중 하나를 갖는다. "정화력 +N%"처럼 쌓이기만 하는 수치 대신, **플레이어가 눈으로 확인할 수 있는 구체적 효과**를 준다.

| 펫 | 획득처 | roster_scope | 효과 타입 | 구체 효과 |
|---|---|---|---|---|
| 🐕 뭉치 | Wave1 정화 | RESIDENT(이번 여정 한정) | **FLAT_HP**(고정 스탯 증가) | 모험가 최대체력 **+15** (즉시, 전투 내내 유지) |
| 🐈 하늘이 | Wave2 정화 | RESIDENT(이번 여정 한정) | **PERIODIC_HEAL**(주기 스킬) | **3턴마다 체력 15% 회복**, 발동 시 로그에 "💚 하늘이 치유 발동!" 명시 |
| 🐕‍🦺 열두 | 파이널보스 Memory Battle | PERMANENT(영구 소장) | **EXECUTE_BURST**(조건 스킬) | 타락 게이지가 **30% 이하**로 떨어지는 순간 **즉시 추가 정화 -50**(1회성 피니셔) |

세 가지 타입이 서로 다르게 동작하므로, 향후 펫이 추가돼도 "고정형/주기형/조건형" 세 갈래로만 분류하면 된다 — 새 타입을 무한정 늘리지 않는다.

## 3. 화면 레이아웃 재설계

**핵심 방향**: 펫은 아래 별도 섹션이 아니라 **모험가 초상 위쪽에 작은 아이콘 행으로 배치**(Summoners War의 "버프는 HP바 위에" 관례 참고) — 지시자 피드백("펫들을 위로 올리는 게 더 직관적") 반영.

```
┌───────────────────────────────────────┐
│  🐕 🐈          VS         [오염된 OOO] │
│  [모험가]                   오염 응축체  │
│  모험가                    타락 ████░░░░ 145/220│
│  HP ████████░░ 62/95                   │
├───────────────────────────────────────┤
│  함께하는 동료 (탭하면 상세 설명)          │
│  🐕 뭉치: 체력 +15 (고정)                │
│  🐈 하늘이: 3턴마다 회복 15%              │
├───────────────────────────────────────┤
│  ⚔ 전투 로그                            │
│  T1  모험가 정화 -22.5 → 잔여 197        │
│  T3  💚 하늘이 치유 발동! 체력 +15%       │
│  ...                                    │
└───────────────────────────────────────┘
```

### 3.1 좌(모험가) 영역
- 펫 아이콘 행(작게, 모험가 초상 바로 위) — 탭하면 툴팁으로 "체력 +15 (고정)" 같은 상세 설명
- 모험가 아이콘 + 이름
- **정화 전투 전용 HP바**(진행 바, 색상·라벨로 액션전투 HP와 명확히 구분)

### 3.2 우(적) 영역
- 적 아이콘(렌더 확인된 이모지로 교체 — 🌫️ 대신 다른 것) + 이름
- **타락 게이지 진행 바**

### 3.3 하단
- 펫 카드형 요약(아이콘+이름+효과 한 줄) — 탭 시 전체 설명 툴팁
- 전투 로그: 스킬 발동 시(하늘이 치유, 열두 피니셔) 아이콘과 함께 눈에 띄게 표시

### 3.4 반드시 지킬 것
- **정화 전투 중엔 액션전투용 하단 스탯바(LV/HP18K/ATK/DEF/GOLD)를 완전히 숨긴다** (문제#4 해결)
- 화면이 커져도 괜찮음 — 설명이 자세한 게 우선
