## 0. 한 줄

> **배가 60일 뒤에 온다. 그동안 신비의 섬에서 아이들을 구하고, 살아서 배를 타야 한다.**
> 실패하면 구한 아이들을 **전부 잃는다.**

## 1. 두 섬 【확정】

| 섬 | 이름 | 역할 |
|---|---|---|
| **집** | 무지개섬 (로비) | 기본 능력 성장 · 기록 · 가족 |
| **모험지** | 신비의 섬 | 60일 여정 · 구조 · 정화 · 효과 장물 |

기존 4구역(하수도·항만·폐자재·중심부)은 없어지지 않고 **한 섬 안의 지역 네 곳**이 된다. 관문은 섬 안쪽으로 들어가는 문.

> 【작업 중】 `area_config.csv`의 구역 ID를 섬 좌표계로 개편하는 중.

## 2. 외출 = 한 판 【확정】

```
무지개섬 ──배──▶ 신비의 섬 ── 60일 ──▶ 배가 온다 ──▶ 무지개섬
                    │
                    └─ 실패 ──▶ 구조한 아이 전부 상실
```

| 항목 | 확정 |
|---|---|
| 한 판의 길이 | **60일** |
| 왜 60일인가 | **배가 60일 뒤에 온다** (픽션이 제한을 설명) |
| 중간 귀환 | **불가.** 배가 없으므로 나갈 방법이 없다 |
| 톤 | **가혹하게 · 긴장감 있게** (지시자 명시) |

> 진행은 노드 기반(`38` 규칙2)이고, 60일은 **제한 시간**으로만 작동한다. 날짜가 구역을 밀지 않는다.

### 2-1. 로비는 「귀환 후」의 공간이다 【확정】

`33` §5의 **소프트 로비**(🏝️로 언제든 섬)는 **폐기**한다. 60일 중 로비 접근은 없다.

지시자 확정: *"이게 로비에 돌아와서 하는 일들이야"* — 단말기·정찰 정산·성장은 **판이 끝난 뒤** 하는 일이다.

| 공간 | 동사 | 없는 것 |
|---|---|---|
| **신비의 섬** (60일) | 구조한다 · 정화한다 · 싸운다 | 읽기 · 정리 · 성장 |
| **무지개섬** (귀환 후) | 읽는다 · 정리한다 · 성장시킨다 | 위험 · 상실 |

두 섬이 서로의 동사를 갖지 않는다. 그래서 경계가 흐려지지 않는다.

> 초판에서 「들여다보기 ↔ 귀환 버튼 분리」를 제안했으나 **철회**한다. 경계를 흐리기만 한다.

### 2-2. 로비 기능은 이미 만들어져 있다 【현황 · 2026-08-08 실측】

귀환 후 할 일의 그릇은 대부분 완성 상태다. 플레이스홀더가 아니라 실제로 데이터를 읽어 그린다.

| 단말기 앱 | 내용 |
|---|---|
| 📖 스크랩 | Tigon 기억조각 tm_01~08 · 조각마다 Piper·Nashui·Olmas 반응 |
| 🐾 도감 | **캐릭터 파일** — 이름을 누르면 `hint_text`가 사연으로 펼쳐진다. 영구/동행/기록 구분 |
| 📋 일지 | 구조 성공 + 이 구역에서 만날 수 있는 아이 + 다른 구역 대기 |
| 🗺️ 지도 | 구역별 진행 + **색 회복 게이지** |

**도감이 Cozy Grove식 애착의 창구**다. 이 프로젝트에서 완성도가 가장 높은 부분이므로, 시스템 개편 시 깨지 않도록 주의한다.

## 3. 능력은 두 층이다 【확정】

| 층 | 이름 | 획득 | 귀환 시 |
|---|---|---|---|
| **일시** | **정기 · 효과 장물** | 신비의 섬에서 **줍는다** | **전부 소멸** |
| **영구** | **기본 능력** | 성장 아이템으로 로비에서 키운다 | **유지** |

### 3-1. 용어 개편 — 스킬 → 정기 【확정】

| 지금 | 바꿀 것 |
|---|---|
| 스킬을 **학습**한다 (`learnSkill` · `learnedSkills[]`) | 정기를 **줍는다** |
| 학습하면 런 내내 영구 | **일시적** — 지속 기간은 §7 미결 |
| 판타지 어휘(신화 스킬·프리즘 등) | 섬에 흩어진 **효과 장물** 톤 (`20` 용어집 방향과 합침) |

시나리오 톤: *"신비의 섬에는 여러 효과 장물이 흩어져 있고, 주우면 일시적으로 능력이 좋아진다."*

### 3-2. 성장 루프

```
신비의 섬에서 성장 아이템 획득
        │ 살아서 귀환
        ▼
무지개섬에서 기본 능력 성장 (영구)
        │ 다시 외출
        ▼
더 깊이 갈 수 있다
```

> **기본 능력이 무엇인지는 미정** (지시자 명시). §7 미결.

## 4. 실패 = 구조한 아이 전부 상실 【확정】

| 항목 | 확정 |
|---|---|
| 잃는 것 | **그 판에서 구조한 반려동물 전부** |
| 성장 아이템 | 처리 미정 → §7 |
| 재시작 | 로그라이크 — 기본 능력만 갖고 다시 외출 |

### 4-1. 왜 이게 두 게임을 화해시키나

```
아이를 구한다  →  파티 슬롯에서 전투력이 된다  →  더 깊이 갈 수 있다
                                              →  잃을 것도 커진다
```

`partyStatBonuses()`가 이미 그 구조다 — 아이가 HP·ATK를 준다. 슬롯도 구역마다 2→3→4→5로 늘어난다.

그래서 **「구조를 피하는 게 최적」이 되는 사고가 안 난다.** 안 구하면 약해서 못 버틴다.

그리고 로그라이크의 긴장(잃는다)과 Cozy Grove의 애착(소중하다)이 같은 축에 놓인다 — **아이가 소모품이라서가 아니라, 잃을 수 있어서 소중해진다.**

### 4-2. 구현 완료 【2026-08-08】

초판 시점에는 **실패라는 개념이 아예 없었다** — 전투에 지면 카드 한 장 띄우고 그대로 다음 날로 넘어갔고, HP 0에서도 진행됐다. 60일은 통과 의례였다.

현재는 구현됨:

| 경로 | 결과 |
|---|---|
| 전투 패배(부활 없음) | `showRunFailScreen()` — **아이·로스터·도감 전부 비움** · 「쓰러졌다」 |
| 60일 도달 | `showVoyageEndScreen()` — 「배가 왔다」 · 아이 생환 · 최종 보스 여부로 문구 분기 |

구현·검증 상세는 [`41`](./41_섬여정_갈래설계.md) §6.

## 5. 아이는 세 층으로 쓴다 【확정】

| 층 | 인원 | 역할 |
|---|---|---|
| **전투 슬롯** | 2~5 (구역별) | 직접 싸운다 · HP·ATK 기여 |
| **펫 슬롯** | **2** | **능력을 부여한다** |
| **정찰조** | 나머지 | **신비의 섬 안을 정찰**해 자원을 가져온다 |

### 5-1. 파견 → 정찰 개편 【확정】

배가 없으므로 아이를 집에 보낼 수 없다. 파견의 무대를 옮긴다.

| | 지금 | 바꿀 것 |
|---|---|---|
| 무대 | 무지개섬에서 일한다 | **신비의 섬 안을 정찰한다** |
| 코드 영향 | — | `island_task_config.csv` **문구만** 교체. 태그 매칭 로직(`runIslandDispatch`)은 그대로 |

### 5-2. 펫 슬롯 재료 부족 【현존】

`party_member_config.csv` 구조 동물 20마리가 **전부 스탯 덩어리**다.

```
20마리 전부  FLAT_HP 또는 FLAT_ATK — 숫자만 다르고 하는 일이 같다
```

진짜 능력을 가진 건 셋뿐이다.

| | 능력 | 타입 |
|---|---|---|
| 뭉치 | 정화 체력 +15 | FLAT_HP |
| **하늘이** | **3턴마다 체력 15% 회복** | PERIODIC_HEAL |
| 열두 | 체력 +5000 (보스 보상) | FLAT_HP |

즉 「펫처럼 능력 부여」의 재료가 **하늘이 하나**뿐이다. → §7 미결

## 6. 전투의 자리 【확정】

`38` 규칙3의 체인에서 **3걸음째(해결)가 전투 자리**다.

```
1일  오염 발견        2일  조사 → 갈림길
3일  전투  ← 여기      4일  돌아와서 정화
```

**정화를 위해 싸운다.** 전투 전리품이 정화의 열쇠가 된다.

### 6-1. 전투 노드 부족 【현존】

| | 지금 | 필요 |
|---|---|---|
| 구역당 전투 노드 | **2개** (일반 1 + 관문 1) | 체인 해결 자리 + 관문 = **6개** |
| 전체 | 8개 | **24개** — 16개 추가 저작 |

전투가 지금은 구역 **끝에만 몰려 있다**(12~13일째). 늘리면 **4일마다 한 번**의 리듬이 된다.

### 6-2. 구조(RESCUE)가 지도에 없다 【현존】

`area_npc_config.csv` 50노드에 **RESCUE 타입이 0개**다. 구조는 매일 확률 스폰(`rollIsRescue`)으로만 발생한다.

`38` 규칙2(사건은 노드에 붙는다)를 따르면 **구조도 노드여야** 한다. 그래야 「가다가 만나서 설득한다」가 지도 위에 자리를 갖는다.

## 7. 미결 (결정 대기)

밸런스·수치는 지시자 방침에 따라 **전부 후순위**. 아래는 **시스템 골격**만.

| # | 항목 | 왜 필요 |
|---|---|---|
| 1 | **기본 능력이 무엇인가** | 로비 성장의 대상. 이게 없으면 성장 루프가 안 닫힌다 |
| 2 | **정기 지속 기간** | 다음 전투 1회 / 그 지역 / 몇 걸음 — 자원 관리 게임이 되는지가 갈린다 |
| 3 | **실패 판정 조건** | HP 0? 특정 노드 실패? 지금 실패 개념 자체가 없다 |
| 4 | **실패 시 성장 아이템** | 전부 잃나 / 챙겨 나오나 — 재도전 의욕이 갈린다 |
| 5 | **로비 「모험」의 처분** | 지난 구역 자동 파밍(`33` §2-1b)인데, 배가 없으면 섬에 갈 수 없다. 파견과 같은 종류의 설정 충돌 |
| 6 | **펫 슬롯 자격** | 특별한 아이만 / 20마리 아무나 (후자는 능력 20개 저작) |
| 7 | **정찰 중 상실** | 정찰 보낸 아이를 잃을 수 있나 (가혹함 +1) |
| 8 | **성장 아이템 종류** | 1종 / 여러 종 |
