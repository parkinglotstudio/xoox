## 1. 리뉴얼 후 — 메인 화면 (①채팅 패널 + ②탐방뷰 동시 반영)

`25_UI연출_리뉴얼_기획서.md` §3·§4를 합친 최종 화면. 순서상 ①번(채팅 패널)만 먼저 내놔도 되지만, 최종 그림을 먼저 보여준다.

```
┌───────────────────────┬─────────┐
│ ⚔8 ─ 🌀15 ─ ⚔23 ─ 👑30 ─ ⚔38   │ (좁아짐) │ ← 타임라인 유지, 폭만 축소
├───────────────────────┤ ───────┤
│                       │ Piper 🐕‍🦺│
│                       │ 냄새가   │
│    [탐방 뷰]            │ 난다... │
│  정적 배경 + 캐릭터        ├─────────┤
│  탭한 곳로 이동           │ 나레이션 │ ← 채팅 패널
│  (Cozy Grove 벤치마킹)    │ 텍스트  │   (오른쪽 소형,
│                       ├─────────┤    말풍선 형태,
│   🐾(탭하면 이벤트)       │ 전투 로그│    실제 채팅방처럼)
│                       │ ...     │
│                       │ (스크롤) │
├───────────────────────┴─────────┤
│ LV1  HP███████░░ 18K/18K  ATK 3.2K DEF 900 │ ← 스탯바(하단으로 이동, 압축)
├─────────────────────────────────┤
│ 💎대박 0/7   [ 스킬 선택 ]   🎡중박 0/12   │ ← 도크 유지
└─────────────────────────────────┘
```

**레이아웃 노트**
- 왼쪽(≈65~70%): 탐방 뷰 — 정적 배경 이미지, 캐릭터가 탭한 좌표로 걸어감(CSS transition)
- 오른쪽(≈30~35%): 채팅 패널 — 세로로 좁고 긴 말풍선 스택. 코멘터리는 화자 아이콘+말풍선, 나레이션은 구분되는 카드 스타일 유지
- 탐방 뷰 안의 🐾 아이콘 = 탭 가능 지점(이벤트/구조 조우/펫 발견) — §26-3에서 상세
- 스탯바는 상단에서 하단(도크 위)으로 이동해 탐방 뷰 공간을 최대한 확보 — 대안: 상단 유지도 가능, 결정 필요(§4 결정사항 참고)

## 2. 채팅 패널 상세 (①, 단독으로도 먼저 출시 가능)

```
┌─────────┐
│ 🦉 Olmas │
│ 신호가   │
│ 잡혔다.  │
│ 하수도   │
│ 지구.    │
└─────────┘
      ┌─────────┐
      │ 1일차    │  ← 시스템/구분 카드(화자 없음)는 중앙 정렬
      └─────────┘
┌─────────┐
│ 🐕‍🦺 Piper│
│ 냄새가   │
│ 난다.    │
│ 가까워.  │
└─────────┘
              ┌─────────┐
              │ ⚔ 전투   │  ← 전투 로그는 오른쪽 정렬 +
              │ 245 피해 │    다른 배경색(화자 없는 시스템성 로그)
              └─────────┘
```

- 화자 있는 카드(코멘터리) = 왼쪽 정렬 + 캐릭터 아이콘, 실제 메신저 말풍선처럼
- 시스템/전투 로그 = 오른쪽 정렬 또는 중앙, 옅은 배경으로 구분
- 자동 스크롤 하단 고정(기존 로직 재사용)

## 3. 탐방 뷰 상세 (②)

```
┌───────────────────────────┐
│                           │
│     🌳       🌳            │
│                           │
│         🚶(플레이어, 탭한 곳으로 이동) │
│                           │
│              🐾 ← 탭하면:         │
│                 "구조 조우 발견!"    │
│                 또는 "이벤트 발생"   │
│    🏠(무지개섬 파견 결과 아이콘,       │
│       23번 문서 연동 시)             │
│                           │
└───────────────────────────┘
```

- 배경: 스테이지/구역별 정적 이미지 1장(예: "하수도 지구")
- 캐릭터: 탭 지점으로 걸어가는 애니메이션(이동 스프라이트 필요 — `25` §4-4 리소스 공백)
- 🐾 아이콘: 탭 가능한 이벤트 지점 — **상시 노출 vs 접근 시 등장** 결정 필요(`25` §9-5)
- 진행도 시각화(Cozy Grove 벤치마킹): 구조 성공/파견 완료된 구역은 배경이 컬러풀해지는 연출(무지개섬 파견 §23과 연동 시)

- 상세 펼침: `scenario_text` + `reactor`/`reaction_text`를 카드 형태로
- 진입 경로: 1차는 별도 아이콘 버튼(예: 탐방 뷰 상단), 폰 UI(§5) 완성 후엔 그 안의 앱 하나로 편입

## 5. 폰 UI (④, 최종 단계)

```
┌─────────────────────┐
│   ╭───────────╮     │
│   │  📶 🔋      │     │ ← 상태바(장식)
│   │             │     │
│   │  📖    🐾    │     │ ← 앱 아이콘 그리드
│   │ 스크랩북  도감  │     │    (Coffee Talk의 폰 UI +
│   │             │     │     Alba의 지도/도감/할일 분리 벤치마킹)
│   │  📋    🗺️    │     │
│   │ 구조일지  지도  │     │
│   │             │     │
│   ╰───────────╯     │
└─────────────────────┘
```

앱별 내용(눌렀을 때):

| 앱 | 내용 | 데이터 소스 |
|---|---|---|
| 📖 스크랩북 | §4와 동일(Tigon 기억조각) | `tigon_memory_config.csv` |
| 🐾 도감 | 구조한 펫 목록 — **스탯표가 아니라 캐릭터 파일**(Arknights 벤치마킹) | `party_member_config.csv`, `rescue_animal_config.csv` |
| 📋 구조일지 | 구조 성공/실패 이력, 재조우 대기 목록 | `rescue_animal_config.csv`의 `reencounter_chance` 등 |
| 🗺️ 지도 | 스테이지 진행 현황, 무지개섬 파견 상태(23번 문서) | `stage_map_config.csv`, 23번 문서 신규 상태 |

- 진입: 탐방 뷰 상단 또는 하단 도크에 폰 아이콘 하나 추가
- 이 화면이 완성되면 §4(스크랩북)의 단독 진입 버튼은 폰 안 아이콘으로 흡수

## 6. 화면 간 흐름 요약

```
[메인: 탐방 뷰 + 채팅 패널]
   │
   ├─ 🐾 탭 → 구조 조우 / 이벤트 (기존 로직)
   ├─ 폰 아이콘 탭 → [폰 UI] → 스크랩북 / 도감 / 구조일지 / 지도
   └─ 도크(대박/중박/스킬) → 기존 미니게임 진입(15번 문서 그대로)
```

## 7. 결정 필요 (와이어프레임 확정 전)

1. 스탯바 위치 — 상단 유지 vs 하단 이동(§1 레이아웃 노트)
2. 탐방 뷰 : 채팅 패널 화면 비율(65:35 제안, 확정 아님)
3. 🐾 이벤트 아이콘 상시 노출 여부
4. 폰 UI 진입 아이콘의 상시 위치(탐방 뷰 상단 고정 vs 도크 통합)
5. 스크랩북 단독 버튼을 폰 UI 완성 전까지 임시로 어디에 둘지
