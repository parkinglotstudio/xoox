## 1. 한 줄

**따뜻한데 낡은 사이버 구조대** — 코지 구조 이야기 × 소프트 사이버 펫.

로비(무지개섬)로 이 톤을 먼저 고정한다. 여정·전투 UI는 로비 톤에 맞춰 후속.

---

## 2. 프레임 · 레이어

- **셸:** 이미 가로(landscape) 확정. 로비도 가로 씬으로 구성.
- **분리 원칙:** 배경 / 배 / 방랑자 / 메뉴 핫스팟은 **서로 다른 PNG·DOM**. 배경에 구우지 않는다.
- **메인:** 집(오두막). 그 주변에 집 메뉴.
- **외출(본편):** 왼쪽 **배** → 뒤쪽 **떠 있는 아일랜드**. 배를 타는 것 = 게임 진행(여정).
- **파견 ≠ 배:** 파견은 **집에 남은 아이들** 보고·배치. 배와 시각·인터랙션을 겹치지 않음.

| 메뉴 | 역할 | 비주얼 자리 |
|---|---|---|
| **외출** | 본편 진행 (여정) | **배만** |
| **파견** | 집에 남은 아이들 | 집 앞 상자/보고판 (배 금지) |
| **기록** | 단말기 | 작업대 |
| **협동** | 함께 갈 아이들 (구 파티) | 현관·펫 |
| **모험** | 지난 구역 자동 | **일단 보류** · 자리만 |

```
[lobby_bg] 집·부두·먼섬 (배·주인공 없음)
  + [lobby_boat] 부두 왼쪽 — 클릭=외출=본편 (이후 bob/sail 애니)
  + [핫스팟] 기록·파견·협동 (+모험 자리 보류)
  + [lobby_actor] 전경 idle (크게)
  + (보조) 하단 외출 간판 — 동일 onDepart
```

컨셉 시안: `data/ui/lobby/lobby_layout_concept_landscape.png`  
(구 세로 시안 `lobby_layout_concept.png`는 참고용)

## 3. 비주얼 규칙

| 축 | 확정 |
|---|---|
| 집 | 부두 · 오두막 · 등불 · 노을/청록 바다 · 먼 떠섬 |
| 캐릭 | 두꺼운 라인 · 플랫 셀 · 2등신/SD · **로비에서 비중 크게** |
| 배 | **별도 레이어** · 투명 PNG · 애니 훅 예약(`--boat-bob` / sail 클래스) |
| 발광 | 눈·코어 **점만** (네온 범벅 금지) |
| 색 | 살구 노을 + 청록 + 따뜻한 나무금 |
| UI | 환경 소품 핫스팟 + CSS 라벨 · 하단 4칸 그리드는 과도기 |
| 애니 | **지금은 안 함.** 배·캐릭 애니는 이후 `docs/art/sprites` 툴 파이프 |

피함: 보라 네온 일색 · 리얼 메카 · 스탯표 도감감 · 쿨한 액션 포장.

## 4. 로비 에셋 (SSoT 경로)

Vite `publicDir: data` → URL `/ui/lobby/...` · 배치는 `/ui/layout/lobby_layout.json`

| 파일 | 용도 |
|---|---|
| `data/ui/layout/lobby_layout.json` | **위치 SSoT** (16:9 · **하단 기준** y) |
| `layout-editor.html` | 마우스 드래그 위치 에디터 · 저장 |
| `lobby_bg.png` | 집·섬 배경 (**배 없음**) |
| `lobby_boat.png` | 배 레이어(투명) · 외출 |
| `lobby_actor_idle.png` | 방랑자 idle |
| `lobby_title_sign.png` | 무지개섬 푯말 |
| `lobby_sign_*.png` | 외출/파견/기록/협동/모험 표지판 |

에디터: `npm run dev:layout` → http://localhost:5173/layout-editor.html  
저장: `POST /__layout_save` → `data/ui/layout/lobby_layout.json`

좌표: `x_pct` = 중심(왼쪽 기준), `y_bottom_pct` = 하단(아래 기준), `w_pct` = 폭.

## 5. 작업 원칙 (이번 단계)

1. **레이어 분리** — 배경에 배·캐릭·버튼을 굽지 않음  
2. **외출 = 배 = 본편** — 파견은 집 보고, 배와 겹치지 않음  
3. **파티 → 협동** · **모험은 보류**  
4. **애니는 보류** — 배 DOM만 분리해 두고 bob/sail은 나중  
5. 메뉴는 집 주변 핫스팟으로 이전 중(하단 그리드는 당분간 유지)
