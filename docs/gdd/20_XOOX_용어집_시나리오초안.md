# 20. XOOX 용어집 & 시나리오 초안 (검토용 — 아직 데이터 미반영)

> 목적: 플레이 중 나오는 스킬·지역·몬스터·분기 이벤트 명칭이 XOOX 세계관과 겉돌지 않게 통일한다.
> 이 문서는 **제안**이다. 확정 전까지 CSV는 건드리지 않는다(오프닝 텍스트 1건 + 카드 CSS 버그만 이미 수정 완료).

## 0. 세계관 한 줄 규칙

- 무기·검술·기사·오크·악마·메두사 같은 **인간 판타지 어휘 금지**.
- 적은 두 갈래로 완전히 분리한다:
  - **구조 조우 대상**(뭉치·하늘이 등 반려동물) — 이미 정합됨, 손 안 댐.
  - **액션 전투 상대** — 반려동물이 아니라 **인간이 남긴 오염·산업 잔재**(폐기물·독성 슬러지·고장난 경비 로봇 등). 절대 강아지/고양이 형태로 만들지 않는다(구조 대상과 혼동 방지).
- 장소는 "영지"가 아니라 **구역**(에피소드 지역) 또는 그 안의 **거점**.
- 정화·구조·공감 축 용어는 원본 통일안 유지: **Purify(정화) / Empathy(공감) / Heal(치유) / Courage(용기)**.

## 4. Day 이벤트·잡담 텍스트(daily_roll_pool) — 방향만

대장간/숲의 기사/애벌레 공주/나그네와 모닥불 등은 전부 "버려진 인간 도시의 흔적" 톤으로 교체 예정(예: "버려진 정비소에서 부품을 주웠다", "지나가던 다른 승무원이 사료를 나눠줬다"). 분량이 많아(수십 건) 이번 문서에선 **패턴만** 제시하고, 확정되면 일괄 적용.
