# DEAD GRID

한국어 복셀 좀비 아포칼립스 탄막 서바이벌. PC 키보드·마우스를 중심으로 하며 모바일 가상 스틱을 지원한다. TypeScript + Vite + React Three Fiber로 로컬에서 실행되는 단일 스테이지 게임이다.

플레이어의 목표는 도시에서 생존하고 5분 간격의 보스 6명을 처치하는 것이다. 30분에 최종 보스가 등장하며, 모든 보스 처치 이후에만 완료된다. 이동, 마우스 방향 조준, 이동 방향 Space 회피·클릭 방향 우클릭 회피, 충격파와 장비 선택이 핵심 결정이다. 무기는 자동 발사된다. 모바일은 이동 방향을 조준한다.

생존자 세 명은 서로 다른 실제 시작 무기와 특성을 갖는다. 생존 시작을 누르면 중앙 선택 화면에서 카드를 고르고 상세 설명·일러스트를 확인한 뒤 출격한다. 공격 장비는 9종 중 최대 6종이며 각각 6단계와 진화를 제공한다. 패시브는 11종이고 다중 투사체만 희귀 고정·3단계이다. 일반 패시브는 5단계와 일반·고급·희귀 등급을 갖는다.

건물과 차량은 충돌·피해·파괴를 제공한다. 그 외 소품과 맵 봉쇄선은 불멸의 장애물이다. 안개는 미방문·기억·현재 시야를 구분한다. 배우 외곽선은 가린 외부 경계에만 표시된다. 연구와 완료 기록은 브라우저에 저장되고 기존 연구 데이터가 이전된다. 서버와 API 키는 필요 없다.

생존자 이야기는 게임을 위해 작성한 허구이며 일러스트는 ImageGen 원본이다. 이미지 시안은 기존 분위기의 참고이고 실제 전투는 R3F 지오메트리이다. 실기기 장시간 GPU 성능과 사람의 난이도 체감은 아직 별도 측정하지 않았다.

화염병·화염방사기의 확장 범위 패시브는 반경·분사각을 늘리며 확장 사거리와 함께 적용된다. 무기는 강화 단계마다 피해 ×1.30·공격 주기 ×0.94이며, 카드에 실제 증가 수치를 표시한다. 강화 선택지는 전체 유효 후보에서 중복 없이 무작위로 최대 3장을 뽑으며, 보유 무기나 패시브를 특정 칸에 강제 배치하지 않는다.

화염병은 포물선 투사체가 실제 충돌한 뒤 화염 지대를 생성하며 비행 중 접촉 피해는 없다. 냉각 펄스는 별도의 작은 내부 링 없이 피해 탄환을 표시한다. 생존자 복셀 모델은 기존 일러스트의 주황 정찰병·청록 공병·크림 의무병 색과 개별 머리·장비를 따르며 기존 인스턴스 렌더러를 공유한다.

## 생존자 구조 · 1.7.1

맵 탐색 목표로 부상 생존자를 구조한다. 첫 45초 이후 100~150초 간격의 무작위 신호, 동시에 치료 대상 한 명. 초기 체력 50%, 방치 60초 사망, 3m 이내 장애물 없는 접근으로 초당 최대체력 1.6667% 치료(50→100%에 30초, 출혈 속도는 유지), 100% 구출. 환자 범위·체력·초록 십자가와 시야 밖 미니맵 방향 안내를 제공한다. 보급상자 한 개를 남기고 도로를 따라 탈출하며, 누적 구출 수는 즉시 브라우저에 저장하여 PC·모바일 메뉴와 결과에 표시한다. 30분 및 여섯 보스 클리어 조건은 유지된다.

## 적 탄막 조정 · 1.7.2

스피터·보스 산성탄의 충돌 반경은 0.18m이며 렌더링 크기도 이전보다 40% 작다. 원거리 발사 간격은 이전의 2배(스피터 7.2초, 일반 보스 5.6초, 체력 절반 이하 3.7초). 돌진형 보스는 기존 돌진 간격을 유지하고 두 번 중 한 번만 탄막을 발사한다. 투사체 수·색·속도·피해·수명은 유지한다.
