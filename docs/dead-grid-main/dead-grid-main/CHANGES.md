# 1.4 · 마우스 조준, 신규 장비와 생존자 선택

- 좌상단 게임 프로필을 복셀 아바타 대신 선택한 생존자의 일러스트 얼굴 확대로 변경했습니다. 세 생존자별 위치를 조정하고 모바일에서도 표시하며 320px 화면에서 시간 HUD와 겹치지 않도록 배치했습니다.

- 방향성 자동 공격은 마우스의 지면 위치를 조준합니다. 이동과 조준은 독립적이며 모바일은 이동 방향을 사용합니다. 전방위·연쇄 무기는 기존 동작을 유지합니다.
- 카타나·저격총·화염방사기 및 각각의 6단계 강화와 진화를 추가했습니다. 카타나는 전방 베기 궤적, 저격총은 엄폐에 막히는 긴 조준선과 고피해 탄환, 화염은 짧고 넓은 다중 타격 원뿔을 표시합니다. 최대 장착 무기는 6종입니다.
- 화염 타격 기본 간격은 0.2초(강화 후 최소 0.1초), 연소 피해 간격은 0.5초입니다. 최대 8중첩이며 각 중첩은 타격 시점부터 3.2초 뒤 만료됩니다. 새 타격이 기존 중첩의 지속시간을 갱신하지 않습니다. 건물·차량에만 지형 피해·연소가 적용되고 불멸 소품 뒤 적은 타격하지 않습니다. 일시정지 시 연소 시간도 정지합니다.
- 경험치 보너스·사거리·추가 투사체 패시브를 추가했습니다. 추가 투사체는 항상 희귀이며 단계당 정확히 1발, 최대 3단계입니다. 사거리와 경험치는 등급에 따라 증가량이 달라집니다.
- 기지 연구를 7종으로 확장하고 첫 가격을 8~12 자원으로 내렸습니다. Q·Space 쿨다운, 피해, 경험치, 획득 반경, 이동 속도 연구를 추가했습니다. 기존 생존 프로토콜 단계는 저장 형식을 이전해 보존합니다.
- 하단 생존자 패널을 제거했습니다. 생존 시작 → 중앙 생존자 선택 → 이름이 표시된 출격 버튼의 흐름입니다. PC는 왼쪽 카드 그리드·오른쪽 일러스트와 상세 정보, 모바일은 세로 상세 정보와 고정 출격 버튼을 제공합니다. 일러스트는 ImageGen으로 생성하고 정확한 프롬프트를 보존했습니다.

# 1.3 · 관통 패시브, 희귀도와 자석 회수

추가 피드백의 다섯 항목을 반영했습니다.

- **관통:** 피스톨·산탄·냉기 및 진화 탄환의 기본 관통 확률을 0%로 변경했습니다. 관통 탄두 패시브는 일반 +10%p / 고급 +12.5%p / 희귀 +15%p씩 증가합니다. 최대 5단계, 상한 75%. 적 명중마다 독립 판정하며 지형은 항상 탄환을 막습니다. 빠른 탄환도 선분상의 가까운 적부터 판정합니다.
- **소품:** 건물과 차량만 피해·파괴 대상입니다. 도로 차단물과 드럼통은 파괴되지 않고 이동·회피·탄환을 막는 충돌 형상을 유지합니다. 차량 화재·12초 후 소각은 그대로입니다.
- **패시브 희귀도:** 일반(흰색) 70%, 고급(초록색) 25%, 희귀(파란색) 5%. 카드의 등급명·제목·아이콘·상단선에 적용했습니다. 효과는 각각 1 / 1.25 / 1.5배이며 강화 단계와 무기 진화 조건은 별도로 유지됩니다. 설명은 실제 증가량, 관통은 증가 후 총 확률도 표시합니다.
- **맵 경계:** 사방의 130m 영역을 연속 콘크리트 봉쇄선과 경계 철책으로 표시했습니다. 안쪽 면이 이동 한계와 일치하며 파괴되지 않습니다. 플레이어·회피·탄환이 경계를 통과하지 못합니다.
- **자석:** 적 처치 시 0.6% 확률로 드랍하며 최소 75초 간격, 동시에 바닥에 2개까지 제한합니다. 240초 고정 출현은 제거했습니다. 습득 시 이미 바닥에 있던 경험치만 벽을 넘어 가속하며 흡수됩니다. 초기 8m/s, 가속 40m/s², 최대 60m/s. 이후 드랍된 구슬은 다음 자석 전까지 일반 획득 규칙을 따릅니다. 회수 중 레벨업·일시정지는 이동을 정지시키고 재개 후 이어집니다.

# 1.2 · 부드러운 시야와 30분 작전

이번 플레이 피드백의 여섯 항목을 반영했습니다.

- **안개:** 표시값을 매 프레임 지수 보간하고 3×3 공간 필터를 적용했습니다. 등장 시정수 0.18초, 사라짐 0.38초입니다. 미방문 지역은 검정, 기억한 지역은 어둡게 남고 적은 현재 시야 밖에서 숨깁니다. 미니맵도 색 전환을 보간합니다.
- **외곽선:** 복셀별 엣지를 제거했습니다. 배우 전체의 ID 마스크에서 외부 실루엣을 찾고 장면 깊이와 비교해 가린 경계에만 1.5 CSS px 선을 합성합니다. 같은 캐릭터 내부의 큐브 경계와 보이는 부분에는 선이 없습니다.
- **산탄 표현:** 노란 피스톨 탄환(0.34×0.7m)과 작은 분홍빛 산탄(0.1×0.19m)을 구분합니다. 피해 수치는 그대로입니다.
- **UI:** 데스크톱 체력 16px, 능력 상태 18px, 시간 60px. 강화 설명 16px. 모바일 강화 제목 22px / 설명 16px, 체력 14px / 시간 40px로 키웠습니다. 메뉴·HUD·오버레이·짧은 가로 화면 배치도 조정했습니다.
- **차량·소품:** 차량 9대, 차단물 4개, 드럼통 6개에 공통 회전 충돌 형상과 내구도를 적용했습니다. 이동·회피·빠른 탄환은 진행 선분의 첫 충돌에서 멈춥니다. 차량 내구도 380, 차단물 440, 드럼통 120. 차량은 파괴 후 12초간 화재·접촉 피해를 유지하고 소각되면 검은 재만 남으며 통로가 열립니다.
- **30분 작전:** 분 단위 편성을 30분까지 늘렸습니다. 보스는 05:00 / 10:00 / 15:00 / 20:00 / 25:00 / 30:00에 한 번씩 출현합니다. 마지막 보스가 살아 있으면 시간 제한 없이 전투가 계속됩니다. 여섯 보스를 모두 처치하면 완료됩니다.

| 출현  | 보스          | 표준 체력 | 특징                     |
| ----- | ------------- | --------: | ------------------------ |
| 05:00 | 검역소 도살자 |    10,000 | 방사 탄환                |
| 10:00 | 감염 군주     |    28,000 | 회전 산성탄              |
| 15:00 | 철갑 파괴자   |    52,000 | 돌진·엄폐 파괴           |
| 20:00 | 포자 여왕     |    85,000 | 다중 오염 지대           |
| 25:00 | 군체 폭군     |   115,000 | 교차 탄막·소환           |
| 30:00 | 페이션트 제로 |   160,000 | 나선 탄막·돌진·연속 폭격 |

보급은 계속 120초당 1회로 제한하며, 30분에는 15회입니다. 사망·선택·일시정지 등으로 전투가 멈추면 작전 시간도 멈춥니다.

## 구현 근거

[Three.js OutlinePass](https://threejs.org/docs/pages/OutlinePass.html)의 화면 마스크와 가림/비가림 구분, [DepthTexture](https://threejs.org/docs/pages/DepthTexture.html)의 깊이 비교 원리를 참고했습니다. 실제 구현은 인스턴싱된 모든 배우를 구분하기 위해 배우별 ID를 사용하는 자체 프래그먼트 셰이더입니다. 같은 배우의 인접 복셀은 같은 ID이므로 내부 엣지가 추출되지 않습니다. 시야 밖 배우는 마스크에도 넣지 않습니다.
