시야와 공격 엄폐는 구분합니다. 낮은 차량·차단물 뒤 적은 보일 수 있지만 해당 무기의 공격 경로는 막힙니다. 차량의 불타는 잔해는 계속 엄폐로 작동하고 소각 후에는 공격 경로가 열립니다.

## 전체 무기 확인

서비스 피스톨, 산탄총, 회전 톱날, 화염병, 테슬라 코일, 냉각 펄스, 카타나, 저격총, 화염방사기 **9종 모두**를 검사했습니다.

- 각 무기 신규 획득과 1→6단계 강화 카드 선택이 실제 장비에 반영되고, 각 단계와 진화에서 실제 적 HP를 감소시키는지 확인했습니다.
- 6칸이 찬 상태에서 미장착 무기의 진화가 뜨거나 잘못된 진화 카드를 선택할 수 없는지 무기별로 확인했습니다. 미장착 진화 버그는 1.6의 공통 조건 수정으로 전체 무기에 차단되어 있습니다.
- 장착 6단계 + 대응 패시브 3단계 조건과 이미 진화한 무기의 중복 진화 방지를 확인했습니다.
- 피스톨·산탄·저격·냉기 탄환은 진화와 최대 관통 확률을 적용해도 차량·불멸 차단물을 통과하지 않는지 확인했습니다.
- 테슬라의 초기 표적·연쇄, 톱날의 엄폐, 화염병의 엄폐·회전 차량·원형 반경, 큰 보스의 공간 격자 경계, 장식 이펙트 포화를 재현하는 회귀를 추가했습니다.
- 기존 마우스 조준, 저격탄 사거리 끝 이동, 화염 주기·연소 스택·개별 만료, 범위와 사거리 패시브, 30분 일정·최종 보스 승리 조건도 전체 회귀로 검사했습니다.

새 테스트는 `src/weapons.test.ts`에 있습니다. **추가 18개, 전체 77개 테스트와 TypeScript 검사·배포 빌드 통과.** 검증은 엔진 재현 테스트와 무적 1,805초 일정 검사이며 모든 조합의 사람 30분 플레이를 의미하지 않습니다. 기존 성장 수치·보스 체력·진화 조건은 유지했습니다.
