## 0. 한 줄

> **레이아웃(느낌) → 구역(숲·들·꽃·물…) → 정화후 그림 → 정화전 그림 → 타일/3D 바닥 → 지평선 원경 한 장 → 승인분만 프로젝트.**  
> 미니맵 리소스 축 = **정화전 1 + 정화후 1** (같은 외곽·같은 구역).  
> 인게임 바닥 = **타일 스플랫** (9칸 컨셉 PNG는 참고·미니맵용).  
> 인게임 먼 풍경 = **지평선 원통 한 장** (산+구름). 스카이박스를 따로 명작으로 그리지 않음. SSoT: GDD [`46`](../../gdd/46_여정3D_원경_맵컨셉.md).

## 2. 그동안 실패 / 헷갈림 (반드시 피함)

1. **한 섹터를 섬 전체처럼** 그림 (네잎클로버·미니맵 통짜 섬)  
2. **네온 목업 UI**(범례·나침반)를 지형으로 추출  
3. **코너를 바다로 비워** 클로버 실루엣  
4. **레이아웃·구역 전에** 인상파/네온 “완성 그림”을 프로젝트에 쌓음  
5. **구역 배치 단계 생략** → 바로 after 그림  
6. **land=면** 가정 vs 사용자 **land=외곽선** 불일치  
7. **결정 전 산출물을 `C:\xoox\data`에 카피**  
8. 마을·부두를 시나리오/톤과 안 맞게 넣음  
9. 박스(마인크래프트)와 타일 디테일을 동시에 섞어 설명  

### 강제 규칙

- **생성물(시안 PNG 등):** `C:\수스이미지 생성\` (하위 `map_pipeline/` 권장)에만.  
- **프로젝트 카피:** 지시자가 **승인·반영**한 뒤에만.  
- **마스크 툴 저장**(`map_mask_tool/masks|master`)은 작업 데이터로 허용. 아트 시안과 구분.

## 3. 산출물 정의

### A. 마스크 (툴, 프로젝트 작업 데이터 OK)

| 레이어 | 의미 |
|---|---|
| `land` | 섬 **면** (미니맵 실루엣 포함) |
| `walk` | **작업 구역** — 인게임 타일 작업 범위 (id만 호환용 `walk`) |
| `walk` 밖 ∩ land | 인게임 비표시 · 미니맵만 · 숲/산으로 채움 |
| `forest` `flower` `pond` `lake` `rock` `debris` `blight` … | **구역** (Phase 1+) |

### B. 미니맵·맵 아트 (생성 폴더 → 승인 후 프로젝트)

| 파일 역할 | 내용 |
|---|---|
| **정화후** | 아름다운 섬. 톤 후보: 인상주의 |
| **정화전** | 같은 구도 + 오염. 톤 후보1: 네온. 후보2: 미정 |

### C. 타일 (Phase 4)

구역에 대응하는 **들·풀·꽃·물·바위** 등 타일/스탬프 → 3D 플레인+프롭.

### D. 인게임 3D 원경 (Phase 원경 · 정화전 확정)

탑뷰 섹터 PNG에 산을 구워 넣지 않는다. 플레이어가 맵에서 보는 먼 풍경은 **지평선 원통 한 장**.

| 파일 | 내용 |
|---|---|
| `horizon_mountains_polluted.png` | 산+대기+먹구름 **한 장** · 2:1 · 좌우 seamless · 아래=보카시 |
| `sky_polluted.png` | 같은 장 상단 샘플 (FOV 72에서 거의 안 보임) |
| 정화후 `*_purified` | **같은 실루엣.** 아직 이 루프 미적용 |

규칙·실패 기록·엔진 수치: GDD [`46`](../../gdd/46_여정3D_원경_맵컨셉.md). 시안 정본: `docs/art/sky_concepts/horizon_polluted_lobby_v16.png`.

## 4. 단계 (순서 고정)

### Phase 0 — 레이아웃 다듬기 【진행됨 · 필요 시 재터치】

**목표:** 섬 면 + **작업 구역(타일)** 십자가.  
**산출:** 마스크 (`island_master`).  
**메모:** 선→면 채움(규칙 B) 적용. 완성 “고정”은 아님 — 사용자 저장본이 SSoT.

---

### Phase 1 — 구역 배치 【진행됨】

**목표:** 숲·들·꽃·물·바위·오염 위치.  
**산출:** 마스터/섹터 마스크. 규칙 SSoT: `island-zone-placement.md`.

---

### Phase 2 — 정화후 시안 【반영됨 · 퀄 피드백 가능】

**목표:** 아름다운 섬 이미지.  
**한 일:** v4 톤 → v5 **연속 1장** → land 마스크 제약 → 9크롭.  
**프로젝트:** `data/ui/journey/sector_iXX_after.png` · overview.  
**주의:** 9장은 **컨셉**. 인게임 최종 바닥 ≠ 이 PNG 통짜.

---

### Phase 3 — 정화전 시안 【후보 반영 · 톤 미확정】

**목표:** 같은 외곽·구역 + 오염 톤.  
**반영:** 물빛 베일 → `sector_iXX_before.png`.  
**미선택:** 네온(후보1) vs 베일(후보3). 선택 후 자산 정리.

---

### Phase 4 — 타일 / 3D 바닥 【진행 중】

**목표:** 구역 → 타일·프롭 · 인게임 일치.  
**한 일:** floor 타일 확장 · `islandFloorSplat` · 맵배치 정화후(타일).  
**남음:** 스플랫 퀄 · 캐시 수정 검증 · `IslandTerrain` 정렬 · 프롭.

---

### Phase 원경 — 지평선 한 장 【정화전 확정 · 2026-08-28】

**목표:** 인게임 3인칭에서 지평선 너머가 「있다」고 읽히되 화면을 가리지 않음.  
**확정:** 정화전 v16 + 원통 높이 `charH*18` + 보카시가 지면 y=0. 지시자 「딱 좋음」.  
**작화:** 하늘/산 분리 금지. 한 장을 원통에. 2:1은 **keep-bottom**.  
**금지:** 원통을 `charH*12`(점) / `charH*26`(거대 산)으로 되돌리기 · 카메라만 올려 하늘 줄이기.  
**남음:** 정화후 원경(같은 구도, 색만 연하게).  
상세: GDD [`46`](../../gdd/46_여정3D_원경_맵컨셉.md).
