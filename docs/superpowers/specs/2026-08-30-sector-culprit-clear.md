# 섹터 원흉 — 대화 통과 후 오염 제거

> 상태: **구현 중 · 실패 세기 테스트 2칸** · 2026-08-30  
> 범위: 들판 `area_i21`(쉬움) → 중앙 `area_i11`(어려움). 다른 칸은 같은 규칙, 정체·조건·대사만 교체.  
> 관련: [`36`](../../gdd/36_정화_촉매_지역정화.md) · [`22`](../../gdd/22_TIGON_기억조각.md) Memory Battle · [`2026-08-17-purify-prep-loop.md`](./2026-08-17-purify-prep-loop.md)

## 한 줄

**원흉은 HP가 아니다. 방랑자가 준비하고, 대화로 열고, 정화제로 물질을 걷어야 그 칸이 완벽하게 정화된다.**

대왕 구슬 3타는 폐기한다. 턴 VS로 되돌리지 않는다. 방랑자에게 피해를 주지 않는다.

---

## 0. 고정 규칙 (전 맵 공통)

1. **증상 ≠ 원인.** 얼룩·벌레는 증상. 원흉이 원인.
2. **클리어 순서 고정.** 대화 통과 → 그다음 오염 물질 제거. 뒤집지 않는다. 대화 없이 물질을 지울 수 없다.
3. **원흉은 펫이 아니다.** 개·고양이 형태로 만들지 않는다. 오염이 말을 배운 핵이다.
4. **대화는 준비 없이는 통과할 수 없다.** 조건은 맵마다 2~4개, **이름 있는 행위**다. 아이템 100개 같은 숙제 게이지는 쓰지 않는다.
5. **완벽한 정화** = 대화 통과 + 물질 제거 + 그 칸 색 3단(하늘 포함). 구슬만 치면 칸이 끝나지 않는다.
6. **실패는 원흉 본편만 다시.** 구한 아이·기억·걷은 얼룩은 남긴다. 60일 본편 실패(아이 전부 상실, GDD `39`)와 섞지 않는다.
7. **다가가기 / 지나친다만으로 본편을 돌리지 않는다.** 지나침 = 이 칸을 나중에. 기로는 “지금 원흉 / 이 조건을 채운다 / 저 조건을 채운다”.
8. 데이터는 CSV/JSON SSoT. 원흉 대사·조건을 코드에 박지 않는다.

60일 Tigon 결전(기억 전투 = 대화 선택으로 정화)과 **같은 동사**다. 들판은 그 연습판.

## 1. 들판 원흉 정체

| | 초판 |
|---|---|
| 칸 | `area_i21` 들판 · 첫 원 |
| 내부 id | `culprit_i21_thirst` |
| 표시 이름 | **기다리는 목마름** |
| 옛 이름 | 대왕 — **폐기** |
| 모습 | 큰 침출 핵. 안쪽에 선착장 불빛만 어른거림. 개가 아님 |
| 목소리 | 선착장에서 기다리던 잔상 |

배가 떠난 뒤, 들판의 탁한 물이 **기다리던 것들**을 붙잡고 굳은 핵.  
마시던 아이들·짐승이 못 돌아가는 이유.

이미 있는 조각과 맞춘다.

- 기억: *탁한 들판이 걷히자 선착장에서 기다리던 목소리가… 여기 두고 간 것들을 잊지 마.*
- 정화 목적: *이 물이 맑아지면 여기서 물을 마시던 것들이 돌아온다.*

## 2. 방랑자 행동 — 두 층

플레이어가 **고르고 걷는다.** 스크립트가 대왕까지 자동으로 밀지 않는다.

### 2-1. 준비 (원 안)

HUD에 조건 세 개. 안 채워진 채 원흉에게 가면 대화에서 떨어진다.

| 조건 id | HUD 짧은 이름 | 방랑자가 하는 일 | 대화에서 쓰는 것 |
|---|---|---|---|
| `stain` | 침출 | 원 안 얼룩을 정화 | 땅이 숨 쉰다고 말할 수 있음 |
| `life` | 아이 | 이 원에 웅크린 아이 하나 구조 | 누구를 붙잡고 있었는지 답이 있음 |
| `memory` | 기다림 | 선착장 기억 조각 (`mem_i21_loop`) | 원흉이 누구를 기다리는지 앎 |

지나침은 실패가 아니다. 노드는 남는다.

초판 아이: 루프에 이미 있는 들판 아이(뭉치/`a_dog_shy` 계열). 새 캐릭터를 이 스펙에서 만들지 않는다.

### 2-2. 원흉 본편 (항상 이 순서)

```
다가간다
  → 대화 3마디 (아래)
    → 통과하면 오염 물질을 정화제로 걷는다 (자동 연출, 피해 없음)
      → 땅 3단 + 하늘 = 이 칸 완벽한 정화
    → 실패하면 물질은 안 지워짐. 원흉만 다시. 조건은 유지
```

물질 제거는 **사냥이 아니다.** 대화에서 “보낸다”가 열린 뒤에만, 흡착 정화제로 핵을 걷는다. 연출은 지금 3단 색·하늘 물결을 재사용해도 된다.

## 3. 들판 대화 3마디

원흉 첫 줄: *아직 안 왔어. 물을 남겨 뒀다.*

| 마디 | 묻는 것 | 통과 (준비됨) | 실패 (준비 없음) |
|---|---|---|---|
| 1 | 누구를 기다리냐 | “두고 간 것들. 배는 이미 떠났다.” | 입을 닫음 |
| 2 | 누구를 붙잡고 있냐 | “이 아이는 네 물이 아니야.” | “아직 목이 마르다.” |
| 3 | 보내 줄 거냐 | **보낸다** → 핵이 풀림 → 물질 제거 | 붙잡는다 / 때린다 → 실패 |

정화는 보냄이지 사냥이 아니다. 3마디에서 공격·구슬 타격 선택지는 통과가 아니다.

선택지 문구·실패 한 줄은 CSV. 위 표가 의미의 정본이다.

---

## 4. HUD

원 안에 있을 때 **원흉 조건**을 보여 준다. 쇼핑 리스트·100개 카운터가 아니다.

- 세 칸: 침출 / 아이 / 기다림. 채우면 켜짐.
- 원흉 쪽: 3/3이면 “대화할 수 있다”. 모자라면 “아직 목이 마르다” 수준의 짧은 힌트.
- 하단 필러: 판정·실패·통과가 주연. 대사는 짧게.

맵마다 라벨만 바꾼다. 들판 초판은 위 세 이름.

## 5. 실패

| | 들판 `area_i21` (쉬움) | 중앙 `area_i11` (테스트 · 세게) |
|---|---|---|
| `fail_kind` | `talk_retry` | `circle_reset` |
| 대화 실패 | 그 마디만 다시. 조건 유지 | 원 전체 리셋. 칸은 정화되지 않음. 색 0 |
| 물질 제거 중 | 방랑자 HP 감소 없음 | 동일 |
| 지역 전체 와이프 | 하지 않음 | **이 칸만** 원 리셋 (테스트용). 60일 런·아이 상실과 섞지 않음 |
| 60일 런 실패 | 이 시스템과 별개 (`39`) | 동일 |

정화 지역은 테스트용으로 **2칸**만 연다. `s1_purify_step` → `s11_purify_step`.

### 5-1. 테스트 두 판

| | 첫 판 들판 | 둘째 판 중앙 |
|---|---|---|
| 원흉 | 기다리는 목마름 | 메마른 우물 |
| 조건 | 침출 1개 | 침출 · 아이 · 우물 |
| 대화 | 1마디 (보낸다 / 붙잡는다) | 3마디 |
| 루프 | 도착 → 얼룩 → 1차색 → 원흉 → 3차색 | 도착 → 얼룩 → 1차 → 억제 → 침입(아이) → 2차 → 기억 → 원흉 → 3차 |
| 실패 맛보기 | `붙잡는다` → 같은 질문 다시 | 틀린 답 또는 아이 지나침 → 원 처음부터 |

## 8. 지시자가 아직 고를 수 있는 것

초판은 위 내용으로 **이미 박아 둔다.** 아래만 지시자 취향이다. 안 고르면 초판 값이 유지된다.

| # | 무엇을 | 초판 값 | 안 골라도 |
|---|---|---|---|
| 1 | 표시 이름 | 기다리는 목마름 | 이 이름 사용 |
| 2 | 실패를 더 세게 | 들판=`talk_retry` · 중앙=`circle_reset` (테스트) | 유지 |
| 3 | 들판 아이 누구 | 기존 루프 아이 | 유지 |
| 4 | 구현을 언제 | 테스트 2칸 세팅됨 | — |

다른 칸의 원흉 정체는 **그 칸 작업 때** 고른다. 지금 고를 필요 없다.
