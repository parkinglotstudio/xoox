## 0. 한 줄

> **섬 전체(≈1 km)를 타일·마스크로 먼저 채운다 → 3×3으로 자른다 → 육지 십자 5칸만 탐방.**  
> 퀄 목표는 `sector_i21_after`급 디테일을 **타일 조합**으로 근접.  
> 오염 = 같은 구도 + 어두운/탁한 톤. 정화 = after가 드러남.

---

## 1. 공간 (확정 이해)

```
1 2 3     이동: 2·4·5·6·8  (= i01·i10·i11·i12·i21)
4 5 6     막힘: 1·3·7·9    (= i00·i02·i20·i22) — **바다 구멍이 아님**
7 8 9       → 산·절벽·숲으로 이어진 육지. 보행만 불가.
```

- **9칸 = 하나의 통짜 섬 실루엣** (네잎클로버/십자 바다 금지).  
- `i21`은 남쪽 **한 섹터**.  
- 거주(집·부두)는 당분간 넣지 않는다.

## 3. 타일 어휘 (SSoT 후보)

마스크/타일 id — 집·부두·village **제외**:

| id | 역할 |
|---|---|
| `sea` | 바다 (코너·가장자리) |
| `land` | 들/기본 육지 |
| `path` | 흙길 |
| `forest` | 숲 |
| `flower` | 야생 꽃밭 |
| `pond` | 웅덩이 |
| `lake` | 호수(큰 물) |
| `rock` | 해안·바위 |
| `debris` | 오염 잔해(정화 전 강조) |
| `blight` | 탁한 오염 코어(정화 타깃) |

상세 스탬프(꽃 한 송이, 돌 한 덩이)는 이후 `tileset/` PNG.  
1차는 **구역 마스크**만으로도 “가득 찬” 읽기를 만든다.

## 4. 제작 순서 (과정)

### Phase A — 섬 마스터 (전체 1장 스케일)

1. **섬 실루엣** 1장 (1 km 개요, 9칸 경계 가이드)  
2. 마스터에 타일 레이어로 들/숲/꽃/물/바위/길을 **이어지게** 칠함  
3. 육지 5칸이 요소로 **빽빽**한지 검수 (바다 4칸은 sea만)

검증: `island_overview` 위에서 십자가 하나의 섬으로 읽힘.

### Phase B — 9분할

4. 마스터를 3×3 크롭 → `masks/iXX.mask.json` (또는 타일 그리드)  
5. 섹터 경계에서 레이어가 **끊기지 않는지** 확인

### Phase C — after / before

6. **after**: 마스크 → 인상파/페인트/타일 스탬프 합성 (톤 목표: i21_after급)  
7. **before**: 동일 구도 + 오염 틴트·debris/blight 강조 (필터+오버레이, 구도 재생성 금지)

### Phase D — 3D 연동

8. 섹터 after/before → 기존 플레인 스플랫/바닥  
9. forest/flower/rock 마스크 → 스캐터 프롭 (나무·꽃·돌)  
10. (보류) 해안 rock만 낮은 메시 타협

### Phase E — 시나리오 정합 (아트 후)

11. 노드·존은 유지. 집/부두 **아트**만 비운 상태와 문구 정리 여부는 별도 결정

## 5. 폴더

```
data/map_mask_tool/
  refs/           톤 레퍼런스 · 실루엣
  master/         섬 전체 마스크·개요 (신규)
  masks/          섹터별 {iXX}.mask.json
  tileset/        타일 스탬프 PNG (신규, Phase C)
  exports/        after/before 미리보기
```

툴: 기존 `npm run dev:mapmask`를 **마스터(전체) ↔ 섹터** 전환 가능하게 확장.

## 7. 1단계 구현 후보 (승인 후)

1. `docs` 이 스펙 확정  
2. `master/` + 3×3 가이드 오버레이  
3. 타일 레이어 목록을 툴/types에 반영 (village/dock 비활성)  
4. 마스터에 land→forest→flower→pond/lake→rock→path 초안  
5. i21 등 5칸으로 크롭해 마스크 재생성  

검증: 마스터 한 장에서 섬·십자·자연 밀도가 읽히면 통과.
