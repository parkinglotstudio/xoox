### 외출 UI 핵심

| 축 | 선택 |
|---|---|
| 구분 | **완만한 시안 라인 아치** + 아치 아래 **불투명 필**(맵 구멍 차단) · 3D는 아치 뒤까지 연장 |

| 상단 | 파티/지역/미니맵/나침반 — 아치와 같은 **시안 라인** 크롬 |
