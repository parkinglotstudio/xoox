## 1. 마스크 의미

| 레이어 | 의미 |
|---|---|
| `land` | 섬 **면** (외곽선 후 면 채움 · 규칙 B). 미니맵 실루엣 포함 |
| `walk` | **작업 구역** — 인게임 타일 작업 범위 (저장 id 호환용) |
| `walk` 밖 ∩ `land` 안 | 인게임 **비표시** · **미니맵만**. 주로 숲/산 |
| `path` | **길** — 필수. 길만 다닐 수 있는 건 아님. 산과 겹침 금지 |
| `flower` | **들판** (+ 꽃밭). 열린 초지 · 숲 안 공터/물가도 가능 |
| `forest` | **숲** — **크게** |
| `rock` | **산·바위** — 길과 구분·이격 |
| `lake` `pond` | 호수·웅덩이 |
| `debris` `blight` | 잔해·오염 |

**아님:** `walk` = 갈 수 있는 지역 전부.

### 실이동 (작업 구역 안)

| | |
|---|---|
| 기본 | 작업 구역의 **숲(`forest`)·산(`rock`)·깊은 물** = **못 감** (타일 막힘) |
| 예외 | **`path`가 숲·산 안으로 들어가면** 그 길과, 길이 이어 주는 **안쪽 열린 곳**(공터·들·호수 기슭)은 **갈 수 있음** |
| 들판 | `flower` 들판·열린 땅은 기본적으로 갈 수 있음 (막힘 레이어가 덮이면 제외) |

한 줄: **숲/산 = 벽이되, 길이 뚫으면 그 안의 “방”까지 갈 수 있다.**

## 2. 지형 규칙 (현실성 우선)

### 2.1 기본

| 지형 | 레이어 | 현실 규칙 |
|---|---|---|
| 들판 | `flower` | 열린 초지. 꽃밭·잔해 등 들판다운 것만 |
| 숲 | `forest` | **면적 크게**. 덩어리·띠 |
| 산 | `rock` | 능선·절벽·해안 바위. **`path`와 겹침 금지** |
| 길 | `path` | 동선. 간선 + 필요 시 지선 |
| 물 | `lake` `pond` | 저지·숲 안·들판 가장자리 |

겹침 우선: `path` > 수역 > `rock` > `forest` > `flower`.

### 2.2 중첩 (큰 지형 안의 작은 풍경)

자연처럼 **큰 지형 안에 작은 지형**이 들어갈 수 있다.

| 큰 지형 | 안에 올 수 있는 것 |
|---|---|
| **큰 숲** | 작은 들판(공터), 꽃밭, 호수/웅덩이, 숲길 |
| **들판** | 꽃밭, 가장자리 수풀, 웅덩이, 길 |
| **산** | 기슭 수풀(소량). 큰 들·큰 호수는 능선보다 **기슭·고개** |

피함: 산 능선 한가운데 큰 들판, 호수가 길을 삼킴(길은 호수 **기슭에 도착·우회**).

### 2.3 필수 비네트 (1곳)

**큰 숲 속 호수 + 그 호수까지 가는 길** — 섬에 **하나**.

- 권장 위치: **i01** 큰 숲 내부
- 호수는 숲 **안** (바다 가장자리 아님)
- `path`가 i11 쪽에서 숲으로 들어와 호수 기슭에 **닿고 끝**
- 호수 둘레 얇은 들/꽃(물가) OK

### 2.4 길 네트워크

- 간선: i21→i11→i01, i10↔i11↔i12
- 지선: 숲→호수 비네트 1
- 산과 버퍼. 숲은 길이 통과·스침 OK
