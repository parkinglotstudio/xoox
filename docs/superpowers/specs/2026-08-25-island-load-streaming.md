## 0. 한 줄

> **외출 전엔 3D 지형을 만들지 않는다. 남쪽 들판(`area_i21`, `is_spawn`)만 준비되면 걷고, 나머지 육지 칸은 뒤에서 올린다.**  
> 부두·거주 아트는 현재 컨셉이 아니다. i21 = 스폰·들판.

---

## 1. 하지 않는 것

- 부두/공방/창고 존 id 개명 (콘텐츠 정리, 별도)
- 스플랫 프리베이크 (Phase 2)
- 5칸을 다시 한꺼번에 찍기

---

## 2. 동작

| 시점 | 하는 일 |
|---|---|
| 부트·로비 | CSV + 2D 탐방만. `Journey3D` / `IslandTerrain` 없음 |
| 외출 | WebGL 생성 → 들판(i21) 스플랫 → 걷기 |
| 이후 | BFS: i21 → i11 → i01·i10·i12. 칸 이동 시 그 칸 `ensureLand` |
| 정화 | 셰이더 틴트만. 5칸 재스플랫 없음 |
| 하늘 | 현재 무드 1세트 → 반대 무드는 뒤 |
| 시트 | idle+walk 먼저, 조준·투척은 뒤 |

바닥 `OUT` = **2048** (발밑이 뭉개지면 스폰 칸만 3072로 되돌림).

---

## 3. 검증

1. `npm run dev` → 인트로 스킵 → 로비가 맵 생성과 안 싸움
2. 외출 → 들판에서 수 초 안에 걷기
3. 북으로 이동 → 중앙이 늦게 떠도 입장 자체는 막히지 않음
4. 정화 후 5칸 재생성으로 멈추지 않음
