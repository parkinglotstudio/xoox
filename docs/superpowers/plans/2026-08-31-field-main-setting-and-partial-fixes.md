## ⚠ UNATTENDED RULES (최우선)

1. **사용자에게 묻지 않는다.** (채팅 승인·의도 확인 스킵)
2. 충돌 시 우선순위: **본 문서 고정 결정 > GDD 49 확정표 > 기존 코드 패턴**
3. UI를 크게 뒤집지 않는다. 로비 버튼·숫자·하늘·거리는 OK. 새 화면/새 루프 엔진 금지.
4. 매 Part 시작 전 `backups/backup_YYYYMMDD_HHMMSS/` 에 터치 파일 복사.
5. Part 끝날 때마다 `npm run build` (실패 시 고치고 재실행, 사용자에게 넘기지 않음).
6. 완료 후 GDD 49 §13 + 본 문서 맨 아래 **실행 로그**에 한 일 요약.
7. zip/커밋/푸시는 **하지 않음** (사용자가 나중에). 코드·JSON·문서만.
8. **세팅 후 에이전트가 직접 플레이테스트** (브라우저/로컬). 흐름 끊김·크래시·막힘 있으면 **스스로 고치고** 재검증.
9. **플레이 시간** 측정. 들판 1클리어 목표 체감 **8–15분** (바로 가기 기준). **20분↑**이면 수·HP·대기 시간을 줄여 재조정.
