## 1. 지시자 요청 요약

- 이 그림 형태(메카 독 SD)를 기준으로 **필요한 동작 컨셉**을 잡을 것
- 다른 게임들이 **동물 전투를 코믹하게** 그리는 방식을 참고할 것 — "코믹"이 핵심 요구사항

## 2. 코믹 연출 레퍼런스 (조사 요약)

카피바라고 원작 자체가 좋은 근거다 — 그 게임 펫들도 "복싱 글러브 낀 선인장", "웃는 먹구름"처럼 대놓고 코믹하게 디자인돼 있다(Pocket Gamer 리뷰 기준). 모바일 치비 전투 연출에서 공통적으로 쓰이는 과장 기법:

1. **예비동작 과장(Anticipation)** — 공격 전 몸을 크게 움츠렸다 튕겨나감 (실제 힘보다 준비 동작을 과장)
2. **타격 프리즈 + 임팩트 심볼** — 맞는 순간 잠깐 정지 + 별/땀방울/느낌표 등 만화 기호 오버레이
3. **멍한 리액션** — 피격 시 눈이 나선/X자로 풀리거나 머리 위에 별이 빙글빙글
4. **탄성 있는 이동** — 리얼한 보폭 대신 눌렸다 늘어나며 통통 튀는 스쿼시&스트레치
5. **승리=과잉 기쁨 / 패배=과잉 처짐** — 정형화된 치비 과장 표현

**breed_01만의 변형 포인트:** 이 캐릭터는 감정을 얼굴이 아니라 **발광(눈·귀·코어·꼬리)의 색·밝기·점멸**로도 표현할 수 있고, 관절이 마디로 나뉜 메카 구조라 "관절이 스프링처럼 튕기는" 과장이 로봇이라서 자연스럽게 정당화된다. 타격 시 나사가 튕겼다 다시 딸깍 붙는다든가, 다운 시 눈빛이 배터리 나가듯 깜빡이며 어두워지는 식의 **로봇 기믹형 코믹**을 다른 캐릭터와의 차별점으로 삼는다.

## 3. 단계별 동작 계획

`04_ANIMATION.md` §1의 로드맵(1차 Idle 루프 → 후속 시그니처 숏 → 클래스별 액션 모음 → 게임 유닛 대기/선택 모션)을 그대로 따른다. **1차는 전투 콤보 금지**(공통 규칙) — 아래 §3-2는 후속 단계로 미리 컨셉만 잡아두는 것.

### 3-1. 1차 — Idle 루프 (지금 바로 제작 대상)

`04_ANIMATION.md` §2 공통 레이어 + §3 Full Frame Mecha 규칙 적용:

| 레이어 | breed_01 적용 |
|---|---|
| Emission Breath | 가슴 코어 밝기가 1.5초 주기로 서서히 펄스 (숨쉬기 대체) |
| Micro Tic | 웨이브 귀가 미세하게 파형처럼 흔들림 (안테나처럼) |
| Secondary Tail | 분절 꼬리가 지연 흔들림(몸이 멈춘 뒤에도 꼬리는 한 박자 늦게 따라옴) |
| Signature Beat | 루프당 1회, 귀 주파수 패턴이 훅 바뀌었다가 원상복귀 — "귀로 신호를 잡는" 느낌 |
| Full Frame 전용(§3) | 관절 회전의 기계감 강조, 코어 패널 점등이 몸 전체보다 살짝 늦게 따라옴(모듈 독립 동작) |

**금지 재확인(공통 규칙):** 격한 카메라 쉐이크, 긴 전투 콤보, 배경 파티클 과다, 발광 3색 동시 점멸 — 1차엔 안 함.

### 3-2. 후속 — 시그니처 숏 (1~2초)

- **합류/버프 지급 순간용**: 꼬리를 확 세우고 통통 튐 + 가슴 코어 반짝 — 지금 게임의 "동료 버프 흡수" 연출(`flyAbsorb`)에 얹기 좋은 길이

### 3-3. 후속 — 클래스별 액션 모음 (파트너/펫 역할 기준, 코믹 포인트 포함)

XOOX에서 이 캐릭터의 역할은 "플레이어용 파트너/펫"이므로, 직접 전투하는 플레이어보다 **보조 개입** 성격의 동작으로 설계한다.

| 슬롯 | 코믹 컨셉 |
|---|---|
| move | 짧은 다리로 종종걸음, 몸통이 좌우로 통통 튕기며 이동 (탄성 강조) |
| attack(보조 개입) | 예비동작으로 몸을 확 움츠림 → 앞다리가 스프링처럼 튕겨나가며 짧게 돌진 → 착지 순간 임팩트 스타 |
| hit | 몸 전체가 눌렸다 튕기고, 눈이 잠깐 나선/X자로 바뀌며, 나사 한두 개가 튕겼다 도로 딸깍 붙음 |
| win | 제자리에서 방방 뛰기 + 꼬리가 프로펠러처럼 회전 + 눈·코어가 반짝반짝 |
| lose | 배터리 방전되듯 눈빛이 서서히 어두워지며 주저앉음 (과장되게, 유머러스한 톤 유지 — 슬프지 않게) |
| hop(보드/이동 점프) | 스프링 압축 → 발사 느낌으로 크게 튀어오름 |

### 3-4. 후속 — 게임 유닛 대기/선택 모션

로스터 선택 화면 등에 쓸 정지 포즈 1~2컷 — 이 단계는 실제 UI 화면이 결정된 뒤에 구체화.

## 4. XOOX 연동 관련 메모 (중요 — 실제 코드 상태 기준)

이 문서는 **컨셉/기획 단계**이고, 실제 게임 코드(`engine.ts`/`main.ts`)엔 아직 아무 것도 연결하지 않는다. 참고로 지금 XOOX의 파트너 펫은 이미지가 아니라 **코드로 그린 네온 실루엣**(`petHeadMarkup()` in `main.ts`)으로만 표시되고 있어서, 이 캐릭터를 실제로 화면에 등장시키려면:

1. (최소) 실루엣 시스템의 색상·귀 모양 파라미터만 이 캐릭터에 맞게 지정 — 코드/아트 작업 거의 없음, 디테일은 다 사라짐
2. (완전) 위 §3에서 잡은 이미지/스프라이트를 실제로 렌더링하는 코드를 새로 추가 — 이건 엔진에 손대는 일이라 **사전에 지시자 확인 필요**

어느 쪽으로 갈지는 아직 미정. 실제로 스프라이트화할 때는 이식된 스프라이트 툴([`docs/art/sprites/_guide/README.md`](../../../art/sprites/_guide/README.md), [`docs/gdd/21_ART_STAGE_TOOL_이식.md`](../../../gdd/21_ART_STAGE_TOOL_이식.md))을 그대로 쓰면 된다.
