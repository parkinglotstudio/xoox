# CYBER BREEDS — 애니메이션 기획

## 1. 목표 포맷 (1차)

**도감형 Idle 루프** (2~4초, 무한 반복)
- 과한 액션보다 “살아 있는 기계 펫”
- 키비주얼과 동일 각도 유지 가능하면 좋음
- 흑배경 유지

후속:
- 시그니처 숏 (1~2초)
- 클래스별 액션 모음
- 게임 유닛 대기/선택 모션

---

## 2. 공통 Idle 구조

모든 캐릭 공통 레이어:

1. **Emission Breath** — 눈/코어 밝기 펄스 (1.2~2.0초 주기)
2. **Micro Tic** — 귀·안테나·핀 미세 틱
3. **Secondary Tail** — 꼬리 지연 흔들림
4. **Signature Beat** — 루프당 1회 시그니처 행동
5. (옵션) **Organic Soft** — 털/처진 피부 미세 흔들림

금지(1차):
- 카메라 격한 쉐이크
- 긴 전투 콤보
- 배경 파티클 과다
- 발광 3색 동시 점멸

---

## 3. 타입별 연출 규칙

### Partial Cyborg
- 호흡(가슴) + 보철 서보 미세 클릭
- 스캐너눈 가로/세로 슬릿 이동

### Hybrid Armor
- 무게 이동(좌우 미세)
- 패널/코어 점등
- 털과 금속의 모션 대비

### Full Frame Mecha
- 관절 회전의 기계감
- 모듈(등팩/집게) 독립 동작
- 귀 주파수/패널 패턴 변화

### Mobility Special
- 휠: 제자리 피벗, 미세 구름
- 플러그꼬리: 꿈틀 → 접속 준비 포즈
- 구름 캐릭은 다리 걷기보다 슬라이드

### Masked Identity
- 렌즈 조리개/포커스
- 호흡기 미세 증기(과하지 않게)
- HUD 점멸은 포인트만

### Weaponized Pet
- 충전 → 짧은 위협 포즈 → idle 복귀
- 무기를 루프 주인공으로 두지 말 것

## 5. 파일럿 추천 (1차 제작)

애니 변환 난이도·가독성·시그니처 명확도 기준:

1. **Babaloo** — 휠 이동, 귀여움, Style A
2. **Lumos** — 스캔 연출, Partial의 교과서
3. **Gizmo** 또는 **3NOFILTER** — 하이브리드/풀메카 대표

대안 세트:
- Cute 세트: Bolinha / Paco / Babaloo
- Street 세트: Flux / Perseu / Sabujo
