# CYBER BREEDS — 톤 · 그림체 · 작화 규칙

## 1. 공통 비주얼 문법 (절대 규칙)

1. **배경**: 순흑 `#000000`. 그라데이션/환경 금지(키비주얼 기준).
2. **아웃라인**: 진한 검정(또는 아주 어두운 브라운). 두께 변화 있음.
3. **셰이딩**: 플랫~셀셰이딩. 부드러운 포토리얼 그라데이션 금지.
4. **텍스처**: 점묘(stipple), 해칭, 스크래치, 미세 노이즈로 마모감.
5. **대비**: 유기체(털/피부) vs 기계(판금/케이블/볼트).
6. **발광**: 눈·코어·꼬리·발끝 중 1~2색이 “생명색”.
7. **품종 우선**: 멀리서도 개/고양이 품종이 보여야 함.
8. **단독 초상**: UI, 로고, 배경소품 없이 캐릭터만.

## 2. 스타일 서브타입

### Style A — Clean Comic Cel (메인 / 애니 기준)
- 면색 중심, 해칭 적당, 읽기 쉬움
- 대표: 3NOFILTER, Babaloo, Bolinha, Cluella
- 용도: 도감 루프 애니, 메인 키비주얼

### Style B — Gritty Ink / Zine
- 스크래치·점묘·거친 해칭 강함
- 대표: Tengolegon, Lumos, Perseu, Lanus
- 용도: Survivor / Punk 라인

### Style C — Neon Fashion / Synth
- 고채도 핑크·퍼플·시안, 패션·스트릿
- 대표: Flux, Soka, Sabujo, Vrum, Tobby
- 용도: Neon Street 라인

### Style D — Tactical Concept
- 채도 낮고 기능미, 설계도/유닛 느낌
- 대표: Loby, Vekin, Aaros, King
- 용도: Tactical Heavy 라인

**운영 원칙**: A를 메인 기준으로 고정하고, B/C/D는 라인 차별화로 유지.

## 4. 색 언어

### 발광색 = 상태/성격
- **Red**: 경계·위협·전투
- **Cyan / Mint**: 가동·에너지·스캔
- **Yellow**: 친근·활성·시야
- **Pink / Magenta**: 개성·펑크·스트릿
- **Purple**: 쿨·하이엔드·야간

### 바디 팔레트 군
1. Warm Brass — 황동/머스타드
2. Cool Steel — 블루그레이
3. Neon Street — 핑크퍼플
4. Organic Muted — 베이지/올리브 + 포인트 발광
5. Pastel Soft — 민트/피치

규칙:
- 발광 메인 1색 + 보조 최대 1색
- 팔레트는 3~5색으로 제한
- 검정 배경에서 네온이 떠야 함

## 5. “이 풍”에서 피해야 할 것

- 사실적 毛皮/금속 렌더(포토리얼)
- 흰/회색 스튜디오 배경
- 카드·프레임·텍스트 오버레이(키비주얼 단계)
- 발광색 3개 이상 남발
- 품종 실루엣을 지우는 과도한 변형
- 매끈한 공장 새제품 느낌(마모/볼트/스크래치 없음)
- 과한 글로우 블룸으로 형태 뭉개기

## 6. 디테일 어휘 (반복되는 부품 언어)

- 원형 조인트 / 포트
- 노출 케이블·호스
- 볼트·리벳·패널 라인
- 스파이크 / 핀 / 안테나
- 헤드셋·바이저·고글
- 코어 패널(가슴·등)
- 분절 꼬리 / 플러그 꼬리 / 에너지 팁
- 기계 발굽·클로·부츠·휠
- 테이프·스크래치·칩핑(중고감)
