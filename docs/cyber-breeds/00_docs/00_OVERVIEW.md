# CYBER BREEDS — 시리즈 총괄

> 품종 DNA를 유지한 채, 개조·증강·메카화한 개/고양이 캐릭터 도감  
> 한 줄 정의: **Breed Portrait × Cyber Augment × Character Unit**

작성: 단서  
용도: 컨셉 고정 / 스타일 학습 / 애니메이션 기획의 기준 문서

---

## 1. 시리즈 핵심

진짜 개·고양이 **품종의 실루엣·성격·무늬**는 남기고,  
몸을 개조/교체/증강해서 **애완동물 + 장비 + 캐릭터**를 동시에 갖게 만든다.

공통 포맷:
- 순흑(pure black) 배경
- 캐릭터 단독 전신/준전신
- 코믹·컨셉아트형 라인
- 네온 발광 = “가동/생명” 신호
- 품종 실루엣이 먼저 읽혀야 함

세계관 톤:
- High-tech / Low-life (첨단이지만 새것 같지 않음)
- Companion first (완전 무기보다 반려체)
- Modular body (부품이 분리되어 보임)
- Emission soul (눈·코어·꼬리 끝 발광)
- Breed DNA (품종이 정체성 출발점)
