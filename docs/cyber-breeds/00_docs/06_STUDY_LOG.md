## Study 01 — Companion Mecha Shepherd/Shiba

파일: `study_01_companion_mecha_shepherd.png`  
목표 라인: LINE 3 Companion Mecha / Style A  
레퍼런스 문법: 3NOFILTER, Babaloo

결과:
- 흑배경·셀셰이딩·민트 발광·원형 조인트 잘 맞음
- 친근 풀메카 톤 재현 성공
- 품종은 시바/셰퍼드 중간으로 읽힘 (의도: 시바)

자가채점: **9/10**
- 품종 가독 1.5 / 흑배경 1 / 셀·라인 2 / 유기vs기계 1.5 / 시그니처 1 / 발광 1 / 마모 1

학습 포인트:
- Companion Mecha는 **큰 무동공 발광눈 + 코어 + 주파수 귀**가 공식
- 머스타드/올리브/피치 팔레트가 레퍼런스와 매우 잘 맞음

## Study 02 — Hacker Cat

파일: `study_02_hacker_cat.png`  
목표 라인: LINE 5 Special Mobility + Hacker / Style A~B  
레퍼런스 문법: 해커캣, Gizmo(대비용)

결과:
- 플러그꼬리·헤드폰·빨간눈·라임 패널 시그니처 명확
- 스크래치/점묘 중고감 양호
- 원본과 가까워질 위험 있음 → 이후엔 품종/파츠 조합을 더 멀리

자가채점: **8.5/10**

학습 포인트:
- 해커형의 필수 3종 세트 = **헤드셋 + 발광눈 + 플러그/케이블꼬리**
- 시안 본체 + 차콜 베스트 + 레드/라임 포인트가 안정 팔레트

## Study 03 — Neon Street Corgi

파일: `study_03_neon_street_hybrid.png`  
목표 라인: LINE 2 Neon Street / Style C  
레퍼런스 문법: Flux, Perseu, Sabujo

결과:
- 핑크/라벤더/노랑 네온 스트릿 팔레트 성공
- 크림 목털 vs 아머 대비 좋음
- 코기 실루엣(짧은 다리·목털) 유지됨
- 발광이 눈+노란발+스파이크로 약간 많음(절제 여지)

자가채점: **8.5/10**

학습 포인트:
- Neon Street는 **유기 잔존(목털/코)을 남겨야** 패션 하이브리드가 됨
- 노랑은 “전원/발/스파이크” 중 역할 분배 필요

## Study 06 — Mobility Wheel Compact (의도: Fold Cat / 결과: Pug-like)

파일: `study_06_mobility_wheel_cat.png`  
목표 라인: LINE 5 Special Mobility / Style A  
레퍼런스 문법: Babaloo, Bolinha, 해커캣

결과:
- 휠 이동기관이 실루엣에서 읽힘 → Mobility 학습 성공
- 틸/민트 + 네이비 털깃 조합 좋음
- 센서눈·그릴 주둥이 문법 안정
- **실패 포인트:** Scottish Fold보다 Pug/Compact Dog으로 읽힘  
  (레퍼런스 Babaloo 흡인이 강했음)

자가채점: **7.5/10** (문법 좋음, 품종 의도 이탈)

학습 포인트:
- Mobility 학습 시 레퍼런스 종과 **다른 종**을 강하게 명시해야 함
- 고양이 휠타입은 귀·주둥이·실루엣을 더 캣쪽으로 과장할 필요
- 그래도 “휠=시그니처” 공식 자체는 유효

1. 흑배경 + 두꺼운 라인 + 플랫색

## Study 07 — Soft Mecha Fluff Cat (Maine Coon)

파일: `study_07_soft_mecha_fluff_cat.png`  
목표 라인: LINE 4 Tactical Heavy × Soft Mecha / Style A~D  
레퍼런스 문법: Gizmo, Bolinha

결과:
- 폭신 갈기 vs 브론즈 무장 대비가 핵심이라 성공
- 시안 바이알·고글슬릿·블레이드풋·테이프 꼬리까지 공식 재현
- 고양이 라인 보강에 가장 유용한 학습작
- 대포팔 무게감이 실루엣에서 읽힘

자가채점: **9/10**

학습 포인트:
- Soft Mecha는 **털 면적을 크게** 남겨야 무장이 더 세게 보인다
- 테이프/밴딩 같은 “임시 수리” 디테일이 Survivor와 Soft를 연결함
