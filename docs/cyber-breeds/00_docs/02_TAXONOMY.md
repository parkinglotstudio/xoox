# CYBER BREEDS — 종류별 분류 체계

시리즈를 확장·애니화할 때 쓰는 **공식 분류축**.

---

## Axis A — 개조 타입 (최우선)

### Type 1 — Partial Cyborg
유기체 비중 높음. 눈/다리/꼬리만 기계.
예: Lumos, Lanus, Loby, Darth

### Type 2 — Hybrid Armor
살아 있는 몸 + 중장갑/무장.
예: Gizmo, Flux, Aaros, King, Vekin, Perseu, Liang

### Type 3 — Full Frame Mecha
거의 로봇. 품종은 실루엣/디테일로만.
예: 3NOFILTER, Soka, Paco, Babaloo

### Type 4 — Mobility Special
휠/플러그/특수 이동기관이 정체성.
예: Babaloo, Bolinha(뒷바퀴), 해커캣(플러그꼬리)

### Type 5 — Masked Identity
얼굴 가림/교체가 아이덴티티.
예: Sabujo, Darth, Vekin, Yank

### Type 6 — Weaponized Pet
무기·위험 파츠가 시그니처.
예: Gizmo(대포팔), Tobby(주사기꼬리), Perseu(스파이크)

## Axis D — 품종 그룹

### Hound / Long Form
길거나 처진 실루엣. 마스크·바이저·슬림아머.
Afghan, Bloodhound, Pinscher

### Guard / Power
사각형·중량감. 흉갑·중각 부츠·코어.
Bulldog, Pitbull, Shepherd

### Compact / Toy
작은 몸 + 강한 시그니처 1개.
Pug, Chihuahua, Chow, Poodle, Shih Tzu

### Fluff Contrast
털 많을수록 기계가 더 세게 보임.
Norwegian Forest Cat, Afghan, Chow, Crested mane

### Pattern Breed
무늬 보존이 핵심.
Dalmatian

## 신규 캐릭 생성 공식

1. 품종 실루엣 확정
2. 역할 클래스 1개만
3. 시그니처 파츠 1개
4. 발광색 메인 1 (+보조 1)
5. 유기체 잔존 비율 선택
6. 톤 코드 1개
7. 제품 라인 배치
8. 흑배경 단독 키비주얼 확정
