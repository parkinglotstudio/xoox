지금은 **구현하지 말고**, 아래 범위·애니·산출·합격 기준을 담은 **계획서**를 먼저 써서 등록한다.

## 이번 지시에서 아스트라가 할 일 = 계획서만

파일로 남길 것:

`docs/reports/YYYYMMDD_작업계획_블록고양이펫_Astra.md`

계획서에 **반드시** 넣을 목차:

1. **목표·비목표** — 펫 범위 / 하지 않을 것  
2. **참조·에셋 경로** — 시안·기존 유닛랩·유사 펫/크리처가 있으면 인용  
3. **메시·머티리얼 계획** — Blender 5.2, 폴더 제안(`scripts/unit_lab_cat/` 등), GLB 경로 제안  
4. **리깅** — 본 목록(머리·턱·사지·꼬리 체인), 스케일(방랑자 대비 펫 크기)  
5. **애니메이션 클립 (이 4종만 — 더 만들지 말 것)**  

| 클립 ID (제안) | 설명 | 비고 |
|----------------|------|------|
| `walk` / `move` | 이동 | 블록 고양이 걸음. 기존 시안 «걷기» 기준 |
| `idle_sit` | 대기 앉기 | 시안 «앉기». 기본 대기 후보 |
| `idle_look` | 두리번 idle | 앉거나 서서 고개·귀·꼬리로 좌우 살핌. 루프 |
| `attack_laser` | 눈 레이저 공격 | 펫 수준. 양쪽(또는 한쪽) 눈에서 짧은 빔. 과장된 보스기 금지 |

6. **연출 스펙 (레이저)** — 길이·색(네온 빨강 계열)·지속·쿨감·히트 이펙트는 **펫 수준**으로 수치·연출 초안  
7. **툴/등록** — unit-lab 또는 펫 슬롯에 어떻게 붙일지 제안 (기존 A/D 덮지 않음)  
8. **작업 단계·예상 산출물·합격 기준·리스크**  
9. **상태판 문구** — 시작/끝 한 줄 예시
