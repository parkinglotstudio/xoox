## 시안 D 때 논의한 부분 — 전부 재적용 (체크리스트)

아래는 D 보고서·B2 논의에서 나온 **합격 조건**이다. A에도 그대로 적용한다. (머리색만 네이비+민트 줄로 바뀜.)

### 얼굴·눈
- [ ] 눈이 막연한 동그라미가 아니라 **원본 눈**에 가깝게: 수평 윗눈꺼풀, 계단형 외곽, 바깥 흰자, 원본 눈동자 색·십자 반사광(크기 과하지 않게)
- [ ] 원본에 있는 **눈썹**(옅은/짙은 층) 위치에 맞게 넣기 — 빠지면 불합격
- [ ] 얼굴이 앞으로 튀어나와 눈·입이 떠 보이지 않게: 얼굴을 **앞머리 안쪽**으로 두고, 눈·입은 얕은 홈/정합된 면에 배치
- [ ] 볼터치는 떠 있는 판이 아니라 **피부 정점/면 색**으로

### 앞머리·머리 실루엣
- [ ] 앞머리 가르마·덩어리·민트 끝(A는 **민트 가로 줄**)을 **원본에서 측정한 윤곽**으로 재구성
- [ ] 머리통이 작고 아래만 큰 **종형 금지**. 정수리·머리통을 넓고 둥글게. 가닥은 머리통 폭 **안쪽 근처**에서 내려오고 **끝만** 말림 (B2/지시3·DISCUSSION 합의)
- [ ] 정면 네모 평판 얼굴 금지: 가운데(눈·입)만 평평, **볼·턱 윤곽 둥글게**, **턱선 분명히**
- [ ] 아래 얼굴 좌우가 평평하면: 아래 볼을 단계적으로 뒤로 접어 음영
- [ ] **모자/베레 금지**. 아호게는 작은 장식일 뿐 머리통을 세로로 늘리지 않음

### 턱·목·옷깃 (D04 핵심)
- [ ] 턱과 목이 분리되어 보이지 않게: 턱 아래 **접히는 음영 면** + 별도 목 메시로 얼굴 안쪽·스카프 안까지 연결
- [ ] 스카프 중앙 윗선을 내려 **짧은 목이 보이게**
- [ ] **밝은(아이보리) 옷깃**을 원본처럼 짧고 넓고 두껍게 — 작으면 폭·높이·두께·겹침 확대 (D04와 동일 취지)
- [ ] 주황 케이프렛이 몸에 붙은 조끼처럼 작지 않게, 어깨 밖으로 퍼지게 (샘플/원본 비율)

### 의상 디테일
