## 핵심

### 바주카·대기 보정

- 바주카 길이 0.528m → 0.696m(+31.8%). 큐브의 가로·세로 크기와 손잡이 위치는 유지한다.
- 가슴 기준 거치 원점을 `(0.10, 0.70, 1.10)`에서 `(-0.05, 0.36, 0.65)`로 옮겼다. Blender 좌표에서 Z가 높이이며, 거치 방향은 `(0.67, 0.36, 0.65)`다.
- 머리 위쪽에 세우던 위치에서 등 쪽으로 낮추고 대각선으로 기울였다. 총 윗부분은 머리카락 바깥에, 아래쪽은 등에 가까워지도록 조정했다.
- 대기·쌍권총·이동·새 인사 동작에도 같은 등 거치가 적용된다. 바주카 발도·납도의 시작/끝도 같은 위치를 사용한다.
- 대기는 6초 반복. 두 번의 호흡, 약 18mm 범위의 좌우 중심 이동, 작은 머리·팔·끝머리 움직임을 더하고 발은 고정했다.

### 추가 동작

| 클립 | 시간 | 표현 |
|---|---:|---|
| `blink` | 1.8초 | 짧게 눈 감고 다시 뜨기. 대기에는 약 1.27초·4.61초에 자동 깜박임 |
| `squint` | 2.4초 | 양눈을 `> <` 형태로 찡그림. 초록 눈썹도 살짝 안쪽으로 내려감 |
| `bow` | 2.8초 | 상체와 고개를 숙였다가 돌아오는 인사 |
| `wave` | 3.2초 | 오른팔을 들어 옆으로 세 번 작게 흔들고 내림 |
| `victory` | 3.2초 | 살짝 움츠림 → 두 번 폴짝 → 무릎을 굽혀 착지 → 원래 자세 |

- 새 동작은 툴에서 반복 미리보기한다. 기존 무기 발도/납도의 1회 재생 처리는 유지했다.
- 얼굴 기본형은 그대로 두고 눈/얼굴 표면/감은 눈 표시의 두 모프(Blink, Squint)를 애니메이션에 기록했다. 런타임에서 얼굴을 새로 샘플링하지 않는다.
- 1차 확대 확인에서 찡그린 눈 위에 감은 눈 선이 남는 문제가 보여, 독립적인 모프 기준점을 지정하고 최종 GLB에서 제거했다.
- 팔과 함께 움직이는 기존 의상 가중치와 동작별 끝머리 흔들림을 사용한다.

## 검증

- Blender GLB 내보내기 완료. 최종 **91,770 삼각형 / 11 메시 / 48 본 / 끝머리 25 본 / 10,240,516 bytes**.
- D07 대비 표정용 삼각형은 20개 증가했다. 모프와 클립 증가로 파일과 그리기 단위가 늘었으며, 이번 결과를 모바일 성능 보장으로 해석하지 않는다.
- 두 툴에서 18개 클립을 읽고 새 동작 버튼을 직접 눌렀다. 페이지 오류 0건.
- 각 클립에 얼굴 모프 트랙 3개가 GLB 안에 포함된다.
- 대기 0~6초의 61개 자세 비교: 루프 양끝 본 행렬 최대 차이 `2.59e-07`, 발 행렬 변화 `1.59e-07`. 작은 부동소수 오차 수준.
- 승리 97개 자세에서 이륙 구간이 **2회**, 최대 발 높이 증가 **0.175m**. 마지막 자세가 바닥으로 돌아옴을 확인했다.
- 정면·측면·얼굴 확대에서 눈 감김/찡그림, 인사 기울기, 손 흔들기, 점프, 낮아진 등 거치를 확인했다.
- 변경된 두 TypeScript 진입점의 `tsc --noEmit` 검사 통과.
- 다른 작업의 Vite 자동 갱신이 첫 검증을 중단하여, 검증용 Chrome에서만 자동 갱신 연결을 막고 재검증했다.
