# 작업 보고서 — 정화 후 원경 재제작 및 맵 적용

2026-09-26 · 완료: 어두웠던 정화 후 산 배경을 블록 맵 바닥 팔레트에 맞춰 새로 그리고, i21·i11 맵 미리보기에 저부하 원경으로 적용했다.

## 바꾼 파일

- `data/art/sky/horizon_purified_map_v1.png` — 밝은 민트 산·파스텔 구름 원경, 1774×887 PNG(약 1.56MB).
- `src/tools/unitLabTool/MapLab.ts` — 맵 뷰어에 원경 원통 1개, 이음 보정, 카메라 추종, 리소스 해제를 추가.
- `src/tools/unitLabTool/main.ts` — i21·i11 공통 배경 연결, 먼 안개색 조정, `?mapBackdrop=0` 비교 스위치 추가.
- `docs/status/WORKLIST.md` — BG-OPT-02 결과 기록.
- `docs/status/BOARD.md` — Codex 완료 상태와 이 보고서 경로 기록.
- `docs/reports/20260926_작업보고서_정화후원경_재제작및맵적용.md` — 이 보고서.

## 하지 않은 일

- 본편 `src/stage/*`와 기존 원경 파일은 변경하지 않았다. 현재 연결은 유닛 랩의 블록 맵 미리보기다.
- 블렌더 맵의 바닥·바다 메시 및 재질은 변경하지 않았다. 목표 기기 GPU 메모리와 실제 게임 FPS도 측정하지 않았다.

## 지시자가 보면 되는 핵심

1. 시안 i21·i11의 밝은 민트 지면과 정화 후 파스텔 하늘을 기준으로 새 배경을 제작했다. 어두운 청록 산 대신 낮은 민트 블록 산을 사용했다.
2. i21·i11과 D·몬스터 12마리 조합을 브라우저에서 확인했다. 원경 추가분은 그리기 호출 **1개**, 삼각형 **96개**이며, PNG의 RGBA8+mipmap 추정 GPU 비용은 약 **8.0MiB**다. `npx tsc -p tsconfig.json --noEmit --incremental false --pretty false` 통과, 브라우저 콘솔 오류 없음.
3. **남은 시각 문제:** i21 선착장 시점에서 먼 바다에 진한 수평 띠와 청록색 표식이 보인다. 이는 새 산 그림 아래의 기존 맵/바다 표시 경계로, 바다 재질·맵 끝 처리에서 해결해야 한다. i11 교차로에서는 바닥과 원경 연결이 자연스럽다.

## 제작 방식과 확인 위치

- 시안 `concepts_v2/03_i21_clean.png`, `04_i11_clean.png`의 팔레트를 참조해 이미지 생성 도구로 새 비트맵을 그렸다. 요청 요지: 밝은 민트·청록 블록 지형, 연한 하늘, 낮은 원경 능선, 파스텔 구름, 바닥과 연결되는 옅은 안개. 기존 어두운 산 이미지는 배치 참고로만 사용했다.
- 브라우저: `http://localhost:5179/unit-lab-tool.html?variant=D&mapActors=1` (i21), `?variant=D&mapSector=i11&mapActors=1` (i11). 왼쪽의 맵 버튼을 선택한다.
- 원통은 안쪽 면 `MeshBasicMaterial`, 그림자 없음, 깊이 쓰기 없음, 카메라 xz 추종이며 i21·i11에 각각 중복 생성하지 않는다. 좌우 이음은 텍스처 로드 시 가장자리 약 4.5%를 혼합한다.
