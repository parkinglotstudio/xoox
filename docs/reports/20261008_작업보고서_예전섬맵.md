# 작업 보고서 — 예전 섬 맵 빼기

1. 예전 9칸 섬 맵을 게임 화면과 툴 허브에서 뺐다. 외출 바닥은 숲이다.
2. 바꾼 파일
   - `src/main.ts` — 섬 미니맵을 다시 켜지 않음. 외출 셔터가 열리기 전에 숲을 켠다. 숲을 꺼도 섬 바닥은 숨긴 채로 둔다.
   - `src/explore.ts` — 섬 미니맵 도킹·인트로를 띄우지 않음.
   - `src/style.css` — 숨김이 미니맵 선반 스타일보다 우선하게 함.
   - `src/stage/world3d/JourneyStage3D.ts` — 섬 바닥과 옛 산 실루엣을 그리지 않음.
   - `src/tools/toolsCatalog.ts`, `src/tools/toolsHub.ts` — 맵 배치·맵 마스크·맵·이동 프로토를 허브와 상단 바에서 뺌.
3. 하지 않은 일
   - 숲 150×300m 바닥, 숲 플레이, 오브젝트 툴은 그대로 둠.
   - `sector-editor.html`, `map-mask-tool.html`, `map-proto.html` 파일은 지우지 않음. 허브에만 안 나온다.
4. 지시자가 보면 되는 핵심
   - 외출하면 구석의 옛 섬 지도가 없고, 바닥은 숲이다.
   - 게임 상단과 툴 허브에서 「맵」 버튼이 빠졌다.
   - 확인: `tsc -b` 통과. 브라우저에서 툴 허브와 외출(무기 고르기)까지 봄.
5. 다음 지시 전에 막힌 질문. 없으면 `없음`
   - 없음
