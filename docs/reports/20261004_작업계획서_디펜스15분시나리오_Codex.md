# 작업 계획서 — 15분 디펜스 시나리오

작성: Codex · 2026-10-04

## 승인과 목표

사용자 「짜서 해봐…이번에 작업 하고 작업 보고서 남겨」 승인으로 숲 방어 관찰 툴을 보정한다. 캐릭터 없이 기존 포탑 5개, 방어물 4개, 본진 1개를 사용한다. 원본 맵·GLB·유닛 랩 카탈로그는 보존한다.

## 한 판

| 구간 | 등장 | 방어 흐름 |
|---|---|---|
| 0~3분 | 슬라임·버섯·동물 등 소형 9종 | 대부분 포탑에서 처치. 연속 발사와 피격을 익히는 구간 |
| 3~6분 | 가시·유령 등 9종 | 연발과 폭발로 여러 적 처리 |
| 6~9분 | 전사·장갑 등 9종 | 관통·대포 역할 드러남 |
| 9~12분 | 대형 등 9종 | 적의 수·체력 상승, 북쪽 전선 압박 |
| 12~15분 | 드래곤·버섯왕·진화종 등 마지막 9종 | 남은 시설이 분산된 적을 방어 |

타워·기지 모드는 900초, 웨이브 모드는 180초×5회와 10초 휴식×4회로 940초. 45종을 단계별 순환 등장시켜 누락을 막는다. 시간에 따른 시설 HP 차감은 없고 적의 실제 공격만 피해를 준다.

## 수정 방법

- 포탑: 총 3연발, 투척 2연발+범위 피해, 대포 3연발+범위 피해, 발리스타 2연발+관통, 투석기 2연발+범위 피해. 이미 날아가는 탄의 피해를 고려해 표적 재선정.
- 적: 45종 각각 체력·속도·공격력·공격 간격·방어력·진입 방향을 지정한다. 좌·중·우 진입에 종류별 독립 오프셋 스플라인을 배치하고 2~3종 혼합 무리를 번갈아 생성한다. 시설별 독립 공격 자리·대기 자리, 실제 위치 간 충돌 간격 유지. 한 점 집결 금지.
- 모델: `units_free.json`의 `enemy_monster` 45종 dense 샘플 → 기존 `voxelizeCrisp` → `buildGreedy`. 유형별 한 번 생성하고 메시 공유. 매 프레임 재복셀화 금지.
- 연출: 연발 총구 섬광·큰 탄두·궤적·피격·폭발. 몬스터 정적 복셀 메시에는 이동·공격·사망 보조 동작을 적용한다. 원본 전용 골격 클립 45종을 새로 만들었다고 간주하지 않는다.
- 설정: `data/tools/unit_lab/defense_balance.json`에 단계·무기·HP 값, `data/tools/unit_lab/defense_monsters.json`에 45종 개별 설정을 모은다. 무리 생성 간격은 단계의 기존 단일 생성 간격×2.4로 두어 2~3종 동시 등장으로 전체 난도가 급증하지 않게 한다.

## 검증과 보고

실제 숲 내비게이션으로 세 모드 전체 시간 시뮬레이션. 45종 등장, 초반 높은 처치율, 15분 본진 생존, 적 위치 간격, 연발·범위·관통 타격, 시설 실제 피해, 죽은 적 배열 정리 확인. 타입 검사 및 툴 빌드. 브라우저 접근이 이전에 거부되어 UI 캡처는 허용이 돌아오기 전까지 수행할 수 없다. CLI 결과와 모델 검증 자료를 보고서에 분리해 기록한다.
