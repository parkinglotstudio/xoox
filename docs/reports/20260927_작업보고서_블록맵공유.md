# 작업 보고서 — 블록맵공유

자동 사냥 툴이 블록 맵 공통 목록의 GLB·정화 전후 원경·배치를 그대로 불러오게 연결했다.

## 바꾼 파일

- `src/tools/forwardWave/view3d.ts`, `forward-wave-tool.html` — `loadBlockMap()`으로 i21 정화 후 맵을 캐릭터 아래에 얹고, 「맵 다시 불러오기」를 넣음
- `src/maps/blockMap/BlockMap.ts`, `BlockMapView.ts` — 서 있는 자리·원경 크기·블록 크기·안개 거리를 목록에서 읽음. 사람 모델은 사냥 툴에서 빼기
- `data/maps/block/manifest.json` — 현재 `20260927-r5`에 자리·원경 크기·안개 거리 추가. 같은 내용을 `releases/20260927-r5/manifest.json`에 보관
- `src/tools/unitLabTool/main.ts` — 안개 거리를 목록 값으로
- `src/tools/unitLabTool/MapLab.ts` — 옛 로더를 공통 로더로 바꿈
- `src/tools/purifyRaidTool/main.ts`, `src/sectorEditor.ts` — 원경 주소를 같은 목록에서

## 하지 않은 일

- GLB·원경 PNG 복사 없음. 본편 여정 하늘은 그대로
- 블록 고양이 툴은 합치지 않음
- 직선 탄환, 테스트 정지 버튼은 이번 범위 밖

## 지시자가 보면 되는 것

1. http://localhost:5179/forward-wave-tool.html 상단에 `i21 정화 후 · 20260927-r5`. 블록 들판·선착장 위에 캐릭터가 있다.
2. 「맵 다시 불러오기」는 `data/maps/block/manifest.json`을 다시 읽는다. 유닛 랩도 같은 개정이다.
3. 이전 맵은 `data/maps/block/releases/20260927-r4/`에 남아 있다.
