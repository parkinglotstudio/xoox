# 작업 보고서 — 유닛랩 블록

작성: Claude

## 한 줄

점구름을 접고, 무료 모델 69개를 정육면체 블록으로 쌓는 방식으로 바꿨다. 유닛 랩은 왼쪽 원본 · 오른쪽 블록 나란히 보기이고, 블록 크기는 상황별로 조절한다.

## 바꾼 파일

- `src/tools/unitLabTool/VoxelCloud.ts` — 새 파일. 표면 샘플 → 블록 칸 쌓기(크기 바꿀 때마다 다시 쌓음), 블록 연출(솟기·모이기·흩어지기·피격·정화·설치)을 셰이더로. 유닛당 그리기 1번(인스턴싱)
- `src/tools/unitLabTool/main.ts` · `unit-lab-tool.html` — 다시 씀. 나란히(원본·블록) / 블록만 / 원본만, 블록 크기 프리셋(클로즈업 40칸 · 기본 22칸 · 무리 10칸) + 칸 수 슬라이더 + 채움(틈) 슬라이더, 무리 테스트는 무리 칸 수 따로
- `data/tools/unit_lab/units_free/*.dense.bin` — 유닛마다 표면 샘플 3만 개(위치+색, 합계 18MB)
- `data/tools/unit_lab/units_free.json` — 샘플 크기 정보 추가
- 원본: `C:\수스이미지 생성\2026-09-24-unit-lab\build_free.py` — `dense_export` 추가

## 하지 않은 일

- 점구름(`GpuCloud.ts`)과 제가 만든 네모 블록 8종은 툴 목록에서 뺐다. 파일은 남겨 둠.
- 블록 안쪽 면 지우기(가려진 면 제거) 같은 최적화는 아직 안 했다.
- 본편 연결 없음.

## 핵심

- 블록은 점구름과 달리 눈·귀가 살아 있다. 고양이 클로즈업 2.6cm 블록 5,691개, 기본 4.8cm 1,845개.
- 부하(초록 블롭, 이 PC): 무리 10칸(블록 394개) 120마리 10.4ms · 400마리 19.7ms / 기본 22칸(1,925개) 120마리 17.4ms · 400마리 46.7ms. 같은 400마리를 원본 메시 인스턴싱으로 그리면 7.3ms.
- 멀리 있는 무리는 큰 블록, 가까운 유닛만 작은 블록으로 가야 한다(프리셋이 그 구분).
