# 작업 보고서 — 유닛랩 레고색

작성: Claude

## 한 줄

유닛 랩 툴에 레고식 원색 스타일을 넣고 기본으로 바꿨다. 기존 사이버 색은 선택지로 남겼다.

## 바꾼 파일

- `data/tools/unit_lab/palette_lego.json` — 새 레고 팔레트(빨강·노랑·파랑·초록·흰·검정). 한 부품 = 한 색, 점 밝기 흔들림 낮춤, 점 크기 0.1
- `data/tools/unit_lab/palette_cyber.json` — 기존 `palette.json`을 이름만 바꿔 보관 (`palette.json`은 없앰)
- `src/tools/unitLabTool/GpuCloud.ts` — 부위 4개(머리 zone 3 추가), 밝기 균일도(`toneMix`), 점 또렷함(`crisp`)
- `src/tools/unitLabTool/main.ts` · `unit-lab-tool.html` — 오른쪽 위 「색 스타일」 선택(레고 / 사이버), 스타일별 기본 점 크기
- `data/tools/unit_lab/units/*` — 방랑자 기준에 머리 부위를 넣어 다시 뽑음
- 원본: `C:\수스이미지 생성\2026-09-24-unit-lab\build_units.py` — 방랑자 다리 = 테두리 부위, 머리 = 새 부위 3

## 하지 않은 일

- 모양(블록 형태)은 바꾸지 않았다. 레고 돌기(스터드)도 넣지 않았다. 색만.
- 본편 색·art/11 팔레트는 건드리지 않았다. 툴 전용.

## 핵심

- 기본 = 레고. 적 무리 빨강 · 빠른 노랑 · 단단 파랑 · 원흉 검정, 정화되면 흰색.
- 총 블록 빨강+흰 윗면, 던지기 블록 노랑+파랑 윗면, 설치 칸 초록 판+흰 테두리. 꺼진 상태는 회색.
- 방랑자 기준은 파란 다리·빨간 몸·노란 머리 (크기 비교용).
