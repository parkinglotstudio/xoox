# 작업 계획서 — 방어 진지와 공격 역할

작성: Codex · 2026-10-04

사용자의 후속 지시로 DEF15-02를 보정한다. 직격 한 발 처치, 투석기·폭탄은 지점 범위 공격, 직격은 빠른 연사·범위형은 느린 공속, 트랩 능력 구분과 실제 방어 배치를 구현한다.

## 구성

- 전방: 감속·속박·가시·폭발 트랩. 중앙 통로를 남기는 좌우 방책.
- 전선: 좌측 연사 포탑과 우측 폭탄 투척.
- 후방: 범위 대포·곡사 투석기·예비 관통 포탑. 보급 천막·탄약 창고.
- 원본 숲 좌표·모델·내비게이션 파일은 보존하며 툴 전용 배치와 동적 충돌 복사본으로 구현한다.

## 공격·동작

- 직격: 연사와 빠른 탄속, 방어율까지 적용해 45종을 첫 직접 명중에 처치하는 기본값.
- 범위: 준비 → 발사 → 고정 지점 낙하 → 반경 피해 → 재장전. 공중에서 표적을 추적하지 않으며 중심/가장자리 피해 차등.
- 투석기: 원본 합친 GLB에는 애니가 없어 기존 Kenney 몸통/받침/팔 부품을 재조립. 컵의 실제 위치에서 탄이 출발하도록 팔 축과 발사점을 검사.
- 총·대포·발리스타: 받침 조준과 부품 반동·복귀. 폭탄 투척: 짧은 준비 후 팔 던지기.
- 감속은 이동 속도, 속박은 이동 정지, 가시는 반복 피해, 지뢰는 폭발과 긴 재사용 시간으로 구별.
- 툴에서 시설/트랩 선택, 능력 설명과 수치 편집, 기본값 복원, 변경 적용 후 다시 시작 기능.

## 검증

45종×직격형 첫 타격 처치, 지점 폭발의 반경/빗나감/비추적, 트랩 4종 효과와 재사용, 부품 조준축/팔/발사점, 배치 충돌과 15분 생존·적 잔류 수를 확인한다. 브라우저 접근이 이전에 거부된 상태라 UI 캡처는 수행할 수 없으며 형상·동작 증거는 오프라인 검사/렌더로 표시한다.
