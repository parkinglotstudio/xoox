## 핵심

- 쏘기 = 기관총 루프(0.27초에 반동 2번, 끝없이 반복). 쏘며 걷기 = 걷기 다리 + 조준 팔(한 걸음에 반동 4번).
- 던지기 1.1초 = 들어 올림 → 놓음(0.45, 폭탄이 이 컷에 손에서 사라짐) → 따라가기 → 다음 폭탄 쥐기. 던지며 걷기는 같은 팔 + 걷기 다리.
- 소품은 모든 동작에 채널이 있어, 동작을 바꿔도 총·폭탄이 남지 않는다.

## 수정 — 팔·다리 방향이 반대였던 것

- 지적: 팔 동작이 정면 기준 반대.
- 원인: 아래를 향한 뼈(팔·다리)는 X+가 캐릭터 **뒤**(+Y)로 돌고, 오른팔 Z-가 **안쪽**인데 반대로 가정했다. Blender에서 뼈를 돌려 손끝 좌표로 실측해 확인(`wanderer/_axis.py`).
- 고침: `build_wanderer.py` `key_pose`에서 팔 윗부분·다리의 X·Z 부호를, 팔뚝은 Z만 맞춘다. 몸통은 실측상 X+ = 앞으로 숙임이라 그대로. 뛰기 숙임 부호도 바로잡음.
- 검증(`wanderer/_verify.py`): 쏘기 오른손 y -0.47(몸 앞)·어깨 높이 / 뛰기 머리가 엉덩이보다 앞 / 뒤로 찬 다리의 발목이 무릎 뒤 / 던지기 놓는 순간 손이 앞·위.
