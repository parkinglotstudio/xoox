# 작업 보고서 — 방랑자 B2 (샘플 시안대로)

작성: Claude

## 한 줄

사용자가 준 샘플 시안(블록 치비, 크림→민트 긴 머리)을 보고 B안을 B2로 새로 만들었다.
- 머리 격자를 16칸 → 24칸(한 칸 3cm)으로 촘촘하게 했다.
- 얼굴은 샘플 그대로의 픽셀 눈이고, 머리카락은 7단 그라데이션이다. 몸은 더 옹골차게 했다.

유닛 랩 「B2 샘플 시안」으로 본다. 기존 A·B·입체눈은 그대로 둔다.

## 바꾼 파일

- `C:\수스이미지 생성\2026-09-24-unit-lab\wanderer\head_b2.py` (새로 만듦)
  - **얼굴 픽셀 24×22.** 눈 8×8:
    - 짙은 윗속눈썹 + 바깥 꼬리
    - 위 짙은 갈색 / 아래 호박 홍채, 동공 홈
    - 흰 십자 반짝임, 바깥 흰자
  - 연한 눈썹, 볼터치 3×2, 벌린 입(짙은 빨강 + 분홍 혀)
  - **표정 5종:** 기본 · 웃음(^^) · 깜빡임 · 결의 · 놀람. 판을 8배 키워 픽셀 그대로 붙인다.
  - **머리카락:**
    - 정수리~허리까지 한 덩어리(물결 머리결)
    - 앞머리 판 + 10가닥(눈 윗선 위에서 끝나고 눈 사이 두 가닥만 내려옴)
    - 물결 옆머리 3겹(앞 가닥은 얼굴 가장자리를 감쌈)
    - 꺾인 아호게, 초록 잎 + 주황 꽃 핀
  - **그라데이션:** 면 높이로 7단(크림 → 민트 → 청록)을 나눈다. 가닥마다 경계를 엇갈리게 해 가로 줄무늬가 아니라 머리결처럼 보인다. 앞머리는 끝이 더 일찍 민트.

  - 무릎 위까지 오는 뒤 망토 + 흰 단
  - 배낭 없음(긴 머리가 등을 덮는 샘플대로)
  - 몸 폭 1.35배
- `wanderer\capture_b2.py` (새로 만듦) — 유닛 랩을 헤드리스로 띄워 B2 블록을 앞·3/4·뒤로 찍고 샘플과 나란히 붙인다

## 하지 않은 일 / 아직 다른 점

- 툴 조명(ACES·환경광)에서 크림 머리와 피부가 샘플보다 연하게 보인다. 색은 두 번 진하게 했다.
- 머리 윤곽이 샘플보다 곧다. 샘플은 옆머리 끝이 바깥으로 더 말려 삐쳐 나간다.
- 앞 어깨 망토(케이프렛)가 샘플보다 작다.
- 본편 교체 없음.
