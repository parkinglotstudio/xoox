# 작업 보고서 — 방랑자 입체 눈 (A·B)

작성: Claude

## 한 줄

A·B 블록 머리의 얼굴을 상용 치비 수준으로 다시 만들었다.
- 눈: 블렌더 입체(눈알 판 + 각막 + 윗속눈썹 테 + 눈꺼풀)
- 얼굴 판: 고해상도(512×480) 그림
- 움직임: 자동 깜빡임, 웃는 눈(^^), 결의(눈꺼풀 30%)

기존 A·B는 그대로 두고 「A 입체눈 / B 입체눈」으로 따로 비교할 수 있다.

## 바꾼 파일

- `C:\수스이미지 생성\2026-09-24-unit-lab\wanderer\` (전부 새로 만듦. 기존 A/B 스크립트는 옵션만 추가)
  - `eye_shape.py`: 눈 윤곽 공용 정의. 텍스처와 입체가 같은 모양을 쓴다. 폭 3.4칸 × 높이 4.2칸, 바깥 눈꼬리가 올라간다.
  - `paint_face.py`: 코드로 그리는 텍스처 (`face_hd/`). 4배로 그린 뒤 줄여서 선이 매끈하다.
    - 눈알: 흰자, 홍채 그라데이션(위 짙게, 아래 밝게), 홍채 결·테두리, 동공, 아래 반사광, 반짝임 3개, 아래 속눈썹. 빛은 두 눈 모두 보는 사람 기준 왼쪽 위.
    - 얼굴 판: 볼터치(부드러운 타원 + 사선 3개), 입(기본 곡선 / 웃음 D자 + 혀 / 결의 / 놀람 o)
    - 눈 색: A = 청록(머리 줄·스카프와 이어짐), B = 호박색(크림 머리와 따뜻한 대비)
  - `eyes_3d.py`: 블렌더 입체 눈
    - 눈알 판: 얼굴 면에서 1.2mm 앞, 살짝 스스로 빛남
    - 각막: 7.5mm 솟은 볼록 막
    - 윗속눈썹 테: 9.5mm 두께 띠 + 바깥 날개. 모양 키 `blink` = 감은 눈 선
    - 눈꺼풀: 피부 판. 모양 키 `blink` = 눈을 덮음
    - 얼굴 판을 고해상도 그림으로 바꿈
  - `render_face.py`: 머리 클로즈업을 표정별로 앞·3/4·옆에서 렌더
  - `build_wanderer_ab.py`, `body_front_ab.py`: `eyes3d` 옵션을 추가했고, 출력은 `wanderer_A_eye.glb` / `wanderer_B_eye.glb`
    - 실행: `blender -b -P build_wanderer_ab.py -- out_ab A eyes3d`
- `data/tools/unit_lab/character/wanderer_A_eye.glb`, `wanderer_B_eye.glb` (새로 만듦)
- `src/tools/unitLabTool/CharacterLab.ts`
  - 입체 눈(`eye3d_*`)은 블록으로 쌓지 않는다. 블록 머리 앞면(얼굴 판보다 반 칸 앞)에 옮겨 붙인다.
  - 고해상도 얼굴 판이면 픽셀을 블록으로 찍지 않고 판을 그대로 켠다.
  - 각막은 색 없이 반사만 더하는 재질로 바꾼다.
  - 자동 깜빡임: 2~5초마다 0.16초, 가끔 두 번 연달아
  - 표정별 눈꺼풀: 웃음 1, 결의 0.3
- `src/tools/unitLabTool/main.ts`, `unit-lab-tool.html` — 「A 입체눈 / B 입체눈」 버튼과 이름

## 하지 않은 일

- 시선 이동(눈동자가 적을 봄): 홍채를 판에서 분리해야 한다. 다음 단계.
- 놀람 표정: 입만 다르고 눈은 기본과 같다.
- 현재(카툰 머리) 버전과 본편 교체(A/B 선택 전)는 하지 않았다.
- 유료 리소스: 조사만 하고 사지 않았다(사용자 결정: B가 부족할 때만).

## 핵심

- 예전 얼굴(16×15칸)은 눈이 2×3칸이라 홍채·반짝임을 넣을 자리가 없었다.
- 지금은 머리는 블록, 눈은 입체 부품, 볼·입은 고해상도 판이다. 블록 크기와 상관없이 얼굴이 늘 선명하다.
- 공간감의 출처
  - 속눈썹 테가 눈알보다 8mm 앞에 있어 눈이 파여 보인다.
  - 각막 볼록 막이 실제 조명 반짝임을 받는다. 캐릭터가 돌면 반짝임도 움직인다.
- 깜빡임과 웃는 눈은 같은 모양 키로 동작한다. 속눈썹이 내려와 ^ 선이 되고, 눈꺼풀이 눈을 덮는다.
- 부하: 눈 부품 8개가 늘어난다. 툴에서 두 캐릭터(원본+블록)를 같이 띄우면 삼각형 약 12.8만이다.
