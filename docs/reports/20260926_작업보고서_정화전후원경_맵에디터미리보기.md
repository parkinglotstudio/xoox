# 작업 보고서 — 정화 전후 원경 맵 에디터 미리보기

2026-09-26 · 완료: 정화 전 블록 산 원경을 새로 그리고, 맵 배치 에디터의 기존 정화 전·정화 후 보기 전환에 두 원경 미리보기를 연결했다.

## 바꾼 파일

- `data/art/sky/horizon_polluted_map_v1.png` — 정화 전 보라색 블록 산·먹구름 원경 1774×887 PNG, 약 1.62MB.
- `sector-editor.html` — 오른쪽 패널의 접을 수 있는 원경 미리보기 카드.
- `src/sectorEditor.ts` — 기존 보기 선택값에 맞춰 정화 전·후 원경 이미지와 설명을 교체.
- `docs/status/WORKLIST.md` — BG-OPT-03 결과 기록.
- `docs/status/BOARD.md` — Codex 완료 상태와 보고서 경로 기록.
- `docs/reports/20260926_작업보고서_정화전후원경_맵에디터미리보기.md` — 이 보고서.

## 하지 않은 일

- 에디터의 지도·모바일 미리보기는 위에서 보는 2D 배치 화면이므로 원경을 지면 위에 합성하지 않았다. 오른쪽 카드에서 원경 그림을 확인한다.
- 본편 `src/stage/*`, 기존 정화 전·후 배경 파일, 섬 바닥 재질은 변경하지 않았다. 정화 전 3D 맵은 아직 없으므로 지면과 원경의 실제 3D 이음은 검증하지 못했다.

## 지시자가 보면 되는 핵심

1. 정화 전 그림은 정화 후와 같은 산·구름 배치를 유지하면서, 시안의 검보라 블록 지면과 보랏빛 오염 흔적에 맞춰 채색했다. 기존 청록빛 사실적 첨탑은 사용하지 않았다.
2. `sector-editor.html`의 오른쪽 **원경** 카드에서 ‘보기: 정화전/정화후’를 바꾸면 각각 `horizon_polluted_map_v1.png`와 `horizon_purified_map_v1.png`가 표시된다. 그림을 누르면 원본 크기로 열린다. 원본 컨셉 보기에서는 이 카드의 그림을 숨긴다.
3. 브라우저에서 두 상태 모두 이미지 1774px 로드와 전환을 확인했다. TypeScript 검사 통과, 브라우저 콘솔 오류 없음. 에디터의 현재 정화 전 지면은 회색 필터, 정화 후 지면은 기존 타일색이라 새 원경 팔레트와 완전히 같지는 않다.

## 제작 방식

- 이미지 생성 도구의 기본 내장 모드 사용. 참조: 새 정화 후 원경(구도), `concepts_v2/02_before_after.png`(정화 전 색·블록 형태), 기존 오염 원경(분위기만).
- 최종 생성 지시 요지: 2:1 게임용 360도 원경, 정화 후와 같은 능선·구름 배치, 어두운 자두색/보라색 낮은 블록 산, 각진 먹구름, 옅은 보랏빛 오염, 하단의 어두운 보라 안개. 사실적 첨탑·물·문자·로고·검정 뭉개짐은 제외.
