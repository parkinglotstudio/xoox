# i21·i11 바닥색 재검토

2026-09-26

## 판단

첨부한 시안과 기존 근접 렌더를 비교하면, i21의 기존 바닥은 시안의 연두색보다 회청색에 가깝고 채도가 낮다. 근접해도 재질의 기본색이 바뀌지 않으므로, 기존 파일만으로는 시안의 가까운 잔디색이 나타나지 않는다. 거리 안개는 가까운 쪽에서 약해지는 것이 자연스럽지만, 현재 파일의 기본 팔레트 자체가 달랐다.

i11의 바닥은 시안처럼 밝은 민트 계열이다. 비교 영역의 밝기 중앙값은 시안보다 높지 않았으나 채도가 조금 낮고, 지형 굴곡·주변 언덕·그림자가 빠져 넓은 면이 평평하고 하얗게 느껴진다. i11을 일괄적으로 어둡게 하면 시안 색과 더 멀어지므로 이번에는 팔레트를 유지했다.

## 이번 수정

- i21 민트 바닥을 더 녹색인 `#98DCA5`로 조정하고, 짙고 옅은 톤과 잔디색도 함께 수정했다.
- i21 북쪽 18m는 i11의 민트색으로 서서히 전환되도록 지형 윗면 색을 조정했다. 두 섹터의 실제 연결 장면에서 추가 확인이 필요하다.
- 길을 조금 더 따뜻한 모래색으로 바꾸고, 큰 사각형 바닥 덮개를 작은 저대비 조각으로 바꿨다.
- 풀 13,000→5,000개, 꽃 1,200→850개로 조정하고 규칙적인 분포를 해제했다.

## 확인

- 새 Blender 근접 렌더에서 i21 앞쪽 지면이 시안의 녹색 방향으로 이동했다. 선택한 앞쪽 잔디 영역의 HSV 중앙값은 시안 약 (0.329, 0.304, 0.922), 이전 렌더 (0.394, 0.147, 0.878), 새 렌더 (0.331, 0.282, 0.867)이다. 서로 다른 구도·조명 사진의 영역 비교이므로 정확한 색 보증 수치는 아니다.
- 새 GLB는 6,476,280바이트. 풀·꽃 개체 5,582개를 GPU 인스턴싱 청크 334개로 묶었다.
- 유닛 랩에서 D와 Mushnub 12마리 동시 로드 확인. 맵 통계 948,324 삼각형, 풀·꽃 인스턴스 6,002개. 검증 시점 화면 통계 약 486,328 삼각형·133 그리기 호출.
- 전체 TypeScript 빌드는 맵 외부의 `src/tools/forwardWave/view3d.ts:482`에서 기존/동시 작업 중인 `side` 변수 사용 순서 오류(TS2448, TS2454)로 중단됐다. 맵 로딩은 브라우저에서 확인했다.
- 유닛 랩의 FPS 표시는 이 환경의 캐릭터 화면에서도 낮았으므로 실제 게임 성능 판단에 사용하지 않는다.

## 남은 시각 작업

시안의 지형 굴곡, 먼 언덕, 나무 그림자, 공통 하늘·대기 효과는 아직 구현 수준이 낮다. 특히 i11은 팔레트보다 공간의 깊이와 명암을 먼저 보강해야 한다. i21+i11 연결 장면에서 색 전환과 경계를 확인해야 한다.
