# 작업 보고서 — 툴 리소스 정리

1. 숲 툴을 허브에 붙이고, 점구름 전용 툴을 지웠다. 오브젝트 툴에 예전 연출과 숲 오브젝트를 모았다. 본편에서는 2D 스프라이트 캐릭터와 점구름 펫을 빼 두고, 포탑 자리는 정화 구슬로 표시한다.

   - `package.json`
   - `forest-play-tool.html`
   - `object-tool.html`
   - `src/tools/objectTool/main.ts`
   - `src/main.ts`
   - `src/lobby.ts`
   - `src/stage/world3d/fx/ThrowBurstFx.ts`

3. 하지 않은 일
   - 맵, 몬스터, 방랑자 애니 툴 페이지, 그 외 예전 리소스는 지우지 않았다.
   - 점구름 오염 효과 자체는 지우지 않았다.
   - 커밋은 하지 않았다.
4. 지시자가 보면 되는 핵심
   - 툴 허브 http://localhost:5173/tools.html 맨 위가 숲이다. 오브젝트 툴은 http://localhost:5173/object-tool.html 이고 161개를 보여 준다.
   - 오브젝트 툴에서 정화 구슬, 바닥 복셀, 점구름 오염 얼룩, 루온 모델을 눌러 확인했다.
   - 게임은 새로고침하면 된다. 포탑 자리는 수정 대신 정화 구슬이다.
