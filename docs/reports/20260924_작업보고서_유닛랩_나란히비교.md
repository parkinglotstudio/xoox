# 작업 보고서 — 유닛랩 나란히비교

작성: Claude

## 한 줄

유닛 랩에서 원본 메시와 점구름을 나란히 놓고 비교할 수 있게 했다. 점구름에 명암을 넣었고, 메시 vs 점구름 부하를 쟀다.

## 바꾼 파일

- `unit-lab-tool.html` — 보기: 나란히 비교(기본) / 원본 메시만 / 점구름만 / 겹쳐 보기. 화면 위 「원본 메시 · 점구름」 표시. 방랑자 기준은 기본 꺼짐
- `src/tools/unitLabTool/main.ts` — 나란히 배치, 유닛 크기에 맞춘 카메라 자동 맞춤, 조명 보강
- `src/tools/unitLabTool/GpuCloud.ts` — 점마다 면 방향(법선)으로 명암. 빛 받는 면 밝게, 반대편 어둡게
- `data/tools/unit_lab/units_free/*` · `units_free.json` — 법선을 넣어 69개 다시 뽑음
- 원본: `C:\수스이미지 생성\2026-09-24-unit-lab\build_free.py` — 법선(`nrm`) 내보내기

## 하지 않은 일

- 「평소 메시 → 연출 때만 점구름」 전환은 아직 안 만들었다.
- 본편 연결 없음.

## 핵심

- 부하(초록 블롭, 이 PC): 메시 인스턴싱 120마리 4.9ms / 400마리 7.3ms. 점구름 1600점 120마리 13.1ms / 400마리 32.2ms. **메시가 더 가볍다.**
- 점구름은 반투명 점이 겹쳐 칠해져 무겁고, 1600점으로는 눈·무늬 같은 작은 부분이 사라진다.
- 모델 삼각형 수: 슬라임 1,030 · 블롭 1,520 · 고양이 1,772 · 드래곤 4,562 · 터렛 620.

## 막힌 질문

- 메시 기본 + 연출 순간만 점구름으로 갈지.
