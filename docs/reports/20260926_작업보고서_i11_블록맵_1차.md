# XOOX 블록 맵 i11 중앙 교차로 — 진행 보고

2026-09-26

## 제작

- i21과 같은 30cm 블록 지형 파이프라인으로 i11 110m 중앙 섹터를 Blender에서 제작했다. 중앙 십자길, 작은 집 3채(분홍·파랑·빨강 지붕), 나무 무리, 바위, 꽃, 듬성한 잔디를 배치했다.
- i21 북쪽 길 중심과 i11 남쪽 길 중심은 x=60.371m로 맞췄다. 서쪽 계단 지형 높이도 경계 첫 행에서 동일하게 계산한다. 30cm 격자 367칸이 실제로는 110.1m이므로, 섹터 합성 시 간격은 110.1m로 놓고 110m 명세와의 0.1m 차이를 해결해야 한다.
- 근접 렌더에서 잔디가 규칙적인 열로 빽빽하게 보이는 문제를 확인해 방출 수를 11,500개에서 1,900개로 줄이고 균일 배치를 해제했다. 꽃은 400개로 줄였다. 바닥 덮개의 큰 색 사각형은 작은 저대비 조각 5,000개를 합친 단일 메시로 교체했다.

## 게임용 구조 확인

- 최종 GLB 3,356,244바이트. 풀·꽃 개체 1,863개를 `EXT_mesh_gpu_instancing`의 20m 단위 210개 청크로 묶었다. 전체 GLB 노드는 755개다.
- 유닛 랩 `?variant=D&mapSector=i11&mapActors=1`에서 D 캐릭터와 Mushnub 12마리 동시 로드 확인. 맵 통계 423,128 삼각형, 풀·꽃 인스턴스 2,399개. 검증 시점 화면 통계 약 276,338 삼각형과 119 그리기 호출.
- TypeScript `npx tsc -b --pretty false` 통과. 브라우저 로드 및 맵 카메라 UI 문구 확인.
- 유닛 랩 브라우저는 이전 캐릭터 장면에서도 1~2 FPS를 표시했다. 이 수치로 실제 게임 프레임 성능을 판정하지 않는다. 본편의 연속 2섹터 로드, 전투 이펙트, 충돌, 저사양 기기 측정은 아직 필요하다.

## 남은 작업

- i21+i11을 실제 월드 좌표로 연결해 지형·길·풀 경계가 보이는지 확인하고 110m 명세/110.1m 격자 차이를 정리한다.
- 시안의 먼 계단식 언덕과 하늘 분위기는 주변 섹터 및 공통 배경으로 구성해야 한다. 현재 i11 단독 렌더에서는 수평선이 비어 보인다.
- 본편 카메라와 플랫폼별 GPU 예산을 정한 뒤 가시 청크 거리, 지면 덮개 밀도, 몬스터 수를 함께 측정한다.
