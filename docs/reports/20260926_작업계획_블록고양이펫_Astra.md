## 1. 목표·비목표

### 목표

정답 이미지 **`docs/directives/assets/20260926_mecha_cat/03_block_poses.png`**의 고양이를 Blender 5.2에서 제작할 계획을 확정한다. 큰 머리와 짧은 다리를 가진 네발 고양이의 실루엣, 블록 형태, 메카 페인트를 함께 유지한다. A/D와 함께 놓았을 때 펫 크기로 읽혀야 한다.

계획할 동작은 **`walk`, `idle_sit`, `idle_look`, `attack_laser`의 4개**다. 눈 레이저는 짧고 작은 보조 공격 연출이다. 최초 구현 목표는 독립 미리보기에서 외형·리깅·4클립을 확인하는 것이다.

### 비목표 및 현재 경계

- 이번 작업에서 GLB, `.blend`, 제작 스크립트, 런타임 코드를 만들지 않는다.
- A/D 모델·제작 스크립트, 맵, 본편 전투, Cursor/Claude 작업을 변경하지 않는다.
- 별도 달리기·점프·비행·콤보·총쏘기 클립을 추가하지 않는다. 시안 가운데의 ‘일어서기’는 서 있는 기준 자세이며, 다섯 번째 클립이 아니다.
- 사실적인 털, 부드러운 고양이 메시, 파이론 형태의 다리, 플러그나 케이블 꼬리를 사용하지 않는다.
- 새 공격력·성장·펫 획득·필러 시나리오를 확정하지 않는다. 커밋·푸시는 작업 단계에 포함하지 않는다.

Blender 5.2에서 블록을 직접 설계하고, 겹쳐 가려진 면은 제거한다. 연결 부위별로 메시를 병합하고 스킨을 붙인다. 런타임에서 고해상도 점구름을 다시 복셀화하거나 모든 큐브를 독립 Object3D로 만들지 않는다.

- 기준 셀: **2cm 초안**. 로고·눈 테두리 같은 필요한 부분만 1cm 보조 격자. 실제 비율 비교 후 확정한다.
- 머리·조끼·발·꼬리 큐브는 모양이 찌그러지지 않도록 각 부품에 단일 본 가중치를 우선 적용한다.
- 어깨·골반·목 연결부는 가려지는 작은 블록을 두어 회전 틈을 메운다. 연결부 때문에 외형이 이중으로 깜빡이지 않도록 동일 평면 중첩을 제거한다.
- 팔이 조끼를 관통했던 방랑자 문제를 반복하지 않도록 어깨판은 해당 앞다리 상단 본을 따르고, 조끼는 가슴 본을 따른다. 앉기·걷기 극점에서 둘 사이를 확인한다.
- 로고와 마모는 텍스처에 넣고, 헤드셋 테두리·주둥이·발가락 경계처럼 그림자와 실루엣에 영향을 주는 요소만 형태로 만든다.

## 4. 리깅과 크기

### 상대 크기 초안

방랑자의 발바닥부터 정수리까지를 H로 측정하고, 무기·머리 꼬리는 측정에서 제외한다. 고양이는 서 있는 자세의 귀끝 높이 **0.40H**, 어깨 높이 **0.25H**, 코에서 엉덩이까지 **0.48H**, 꼬리 길이 **0.30H**를 시작값으로 한다. 예를 들어 H=1.8m로 놓으면 각각 0.72 / 0.45 / 0.864 / 0.54m다. 이는 비율 설계용 예시이며 현재 방랑자 높이의 실측 결과가 아니다.

머리·다리·몸통의 비율은 정답 시안을 우선한다. 펫이 작아져 눈·로고가 사라지면 이 디테일의 대비를 보정하고, 주인공만큼 몸 전체를 키우지 않는다. 옆에 A/D를 배치한 비교 화면으로 확정한다.

### 본 구성: 29개 + 눈 FX 기준점 2개

| 계층 | 본 이름 제안 | 수 |
|---|---|---:|
| 기준/몸 | `root`, `pelvis`, `spine`, `chest` | 4 |
| 목/얼굴 | `neck`, `head`, `jaw` | 3 |
| 귀 | `ear.L`, `ear.R` | 2 |
| 앞다리 | `front_upper.L/R`, `front_lower.L/R`, `front_paw.L/R` | 6 |
| 뒷다리 | `hind_upper.L/R`, `hind_lower.L/R`, `hind_paw.L/R` | 6 |
| 꼬리 | `tail.01`~`tail.08` | 8 |

- `root → pelvis → spine → chest → neck → head`의 계층. 앞다리는 가슴, 뒷다리와 꼬리는 골반 아래에 둔다.
- 헤드셋은 head, 어깨 보라 포인트는 각 앞다리 상단, 등 핀은 몸통, 턱은 jaw를 따른다.
- 눈 안쪽 발사점 `eye_socket.L/R`는 head 아래의 별도 변형 없는 기준 노드로 내보낸다. 애니메이션 클립을 추가하지 않는다.
- 발은 Blender 제작 단계에서 접지 목표를 사용하고 결과를 본 키로 굽는다. 웹에 Blender 제약 조건이 그대로 전달될 것이라고 가정하지 않는다.
- 원점은 바닥 중앙, 루트 스케일은 1. GLB의 Y-up과 전방 축을 독립 툴에서 검증한다. 방랑자에서 사용했던 부호 반전을 고양이에 무조건 복사하지 않는다.
- 큐브 체인은 각 본에 붙이고 끝으로 갈수록 약간 늦게 움직인다. 기본 대기의 꼬리 끝 이동은 약 1~2cm로 제한한다.

## 5. 애니메이션: 정확히 4개

| ID | 시간 초안 | 재생 | 포즈와 타이밍 |
|---|---:|---|---|
| `walk` | 1.0초 | 루프 | 시안 오른쪽 걷기. 네 발의 착지 시점을 분산해 달리기처럼 동시에 뜨지 않게 함. 등 높이 변화 0.8~1.2cm, 꼬리 끝 좌우 2~3cm 이내 |
| `idle_sit` | 4.0초 | 루프 | 시안 왼쪽 앉기. 앞발은 바닥 고정, 뒷다리는 옆으로 접고 꼬리를 바닥 쪽에 둠. 가슴 호흡 3~5mm, 머리 1~2도, 귀 끝 2~3도 |
| `idle_look` | 5.0초 | 루프 | 같은 앉은 자세에서 정면→왼쪽→정면→오른쪽→정면. 머리 좌우 약 12도, 귀는 머리와 동시에 기계적으로 돌지 않게 지연. 꼬리 뿌리는 고정하고 끝만 1~2cm |
| `attack_laser` | 0.70초 | 1회 | 서 있는 지지 자세. 0~0.18초 고개 조준, 0.18~0.30초 짧은 양눈 빔, 0.30~0.45초 머리 1~2도 반동, 0.45~0.70초 회복 |

30fps로 제작·확인하고 루프 처음과 끝의 위치뿐 아니라 속도 변화도 맞춘다. 걷기는 제자리 이동 클립으로 만들고 루트 전진을 굽지 않는다. 툴의 이동 속도와 발 보폭을 맞춰 발 미끄러짐을 확인한다.

### 클립을 늘리지 않는 전환

- 기본 대기는 `idle_sit`. `idle_look`은 같은 앉기 기준으로 시작·종료한다.
- 앉기↔서기 전환은 0.3~0.4초의 포즈 보간으로 먼저 검증한다. 발 접지가 어색하면 런타임 전환 보정으로 해결하고, 허락 없이 다섯 번째 ‘일어서기’ 클립을 만들지 않는다.
- 공격을 앉기에서 시작할 때는 먼저 서 있는 공격 시작 포즈로 전환한 후 0.70초 클립을 재생한다. 전환 중 레이저는 나오지 않는다.
- 멈춤·느린 재생·클립 전환에 FX가 따라야 한다. 타이머만으로 눈 빔을 따로 발사하지 않는다.

## 6. 눈 레이저 연출 스펙

다음 수치는 **미리보기용 초안**이다. 본편의 공격력·사거리·쿨타임 규칙으로 확정한 값이 아니다.

| 항목 | 초안 |
|---|---|
| 발사 | 양쪽 눈에서 동일한 표적을 향해 1회. 각 눈의 월드 위치를 시작점으로 사용 |
| 최대 길이 | 2.2m. 툴 표적 또는 차폐면까지의 거리로 줄임 |
| 빔 중심 | 연한 빨강 `#FFD2D6`, 두께 0.012m |
| 빔 외곽 | 네온 빨강 `#FF3653`, 두께 0.035m. 얇은 사각 단면 |
| 예고 | 0.08~0.18초 눈 밝기 소폭 상승. 외형이 하얗게 사라지지 않게 제한 |
| 본 발사 | 클립 0.18~0.30초, 0.12초 유지 |
| 반복 간격 | 자동 미리보기에서 공격 시작 사이 최소 3.0초. 쿨감·성장 시스템은 만들지 않음 |
| 착탄 | 3~5cm 빨간 사각 빛 1개 + 0.8~1.5cm 블록 입자 최대 6개, 0.15~0.22초 소멸 |
| 바닥/화면 반응 | 카메라 흔들림 없음, 새 그림자 라이트 없음, 커다란 폭발 없음 |
| 동시 비용 | 1마리당 빔 2줄, 착탄 묶음 1개. 메시 풀 공유 |
| 게임 판정 | 동일 공격 1회로 취급하는 제안. 양눈 때문에 대미지가 두 번 들어가는 방식으로 연결하지 않음 |

시선과 빔이 일치하도록 머리 조준 범위 안에서 먼저 포즈를 정한 후 눈 기준점을 갱신한다. 머리 밖에서 빔이 시작되거나 눈 반대 방향으로 나가는 문제를 정면·측면·후면에서 검사한다. 후면에서는 눈을 관통해 보이도록 하지 않고, 얼굴 앞의 빔과 착탄이 보이는지를 확인한다.

**본편 규칙 차이:** 52 문서는 펫 기본 기관총을 적고 있으며 새 BCAT 지시는 눈 레이저를 지정한다. 이번 자산 계획은 BCAT의 레이저를 따른다. 실제 게임에 연결할 때 ‘기존 기본 공격의 외형 변경’인지 ‘새 펫 전용 공격’인지 별도 결정하고, 현재 게임 표나 필러를 변경하지 않는다.

## 7. 툴과 등록 제안

1. 독립 `block-cat-tool.html`에서 정답 이미지와 제작 모델을 나란히 보여준다. 초기에는 이 독립 진입점으로 검수한다.
2. 애니 버튼은 4개만 노출한다. 정면·3/4·측면·후면, 일시정지, 0.5/1/1.5배 재생, 접지선, 눈 발사점 보기를 제공할 계획이다.
3. A/D 크기 비교용 모델은 읽기 전용으로 불러온다. 동일 노출과 카메라에서 비교한다.
4. 승인 후 유닛랩에는 **펫 → 블록 고양이** 항목을 별도로 등록하는 최소 연결만 제안한다. A/D 시안 목록과 GLB 주소는 유지하고, 등록 시 공유 진입 파일의 최신 변경을 확인한다.
5. 펫 전용 `PetView`에서 로딩·믹서·클립·꼬리·레이저 수명을 관리한다. 기존 `CharacterView`를 그대로 호출하면 방랑자 얼굴/총구 가정이 따라오므로 직접 재사용하지 않는다.
6. 기존 `units_free.json`의 `q_cat`은 무료 모델 비교 항목으로 남긴다. 새 고양이는 `pet_block_cat`이라는 별도 ID를 제안한다. 기존 점구름 펫 목록에도 자동 치환하지 않는다.
7. 테스트용 표적과 레이저는 툴 안에서만 작동한다. 실제 동행 AI·타겟 검색·전투 판정 연결은 별도 본편 작업이다.

## 8. 단계·산출·합격 기준·리스크

### 단계와 산출

| 단계 | 할 일 | 산출 / 통과 기준 |
|---|---|---|
| 0 — 이번 작업 | 시안·소스 확인, 계획 작성, 상태 기록 | 이 계획서와 Codex 작업 보고. 모델·코드 생성 없음 |
| 1 — 별도 착수 지시 후 | 머리·몸통·4다리·꼬리의 블록 외형 | 앉기/서기/걷기 정지 포즈 비교판. 큰 비율을 먼저 검수 |
| 2 | 색·헤드셋 로고·관절·작은 마모 | 같은 조명으로 정면·3/4·측면·후면, 얼굴/헤드셋 확대판 |
| 3 | 독립 네발 리그와 정확히 4클립 | `.blend`, 4클립 GLB, 본·메시·재질·용량 측정 기록 |
| 4 | 독립 툴·눈 기준점·레이저 | 정지/감속/루프/클립 전환 검사, 네 방향 공격 캡처 |
| 5 | 사용자 확인된 외형을 유닛랩 펫 항목으로 연결 | A/D 동작 확인, 펫 1/3마리 비용 비교, 최종 보고와 영상 |

위 단계는 구현 승인 이후의 순서다. 계획 작성 완료를 GLB 제작 승인으로 취급하지 않는다. 기능 구현 중에도 시안에서 크게 벗어나는 결정은 비교판에 표시한다.

### 합격 기준

- 정답은 `03_block_poses.png`. 일반 고양이의 네발·앉은 실루엣, 사각 빨간 눈/세로 동공, 헤드셋 로고, 조끼와 라임 포인트, 퍼플 관절, 큐브 꼬리가 보인다.
- 이미지와 3/4 시점/크기를 맞춰 머리 폭, 귀끝, 주둥이, 가슴, 발, 꼬리 끝의 위치를 겹쳐 확인한다. 시점 오차와 형태 오차를 구분하고 다르게 만든 부분은 보고에 표시한다.
- 눈과 입은 얼굴에 붙고, 목·관절에는 검은 틈이 없으며, 조끼가 앞다리를 관통하지 않는다. 후면의 미확정 형태는 별도 캡처로 남긴다.
- GLB 애니메이션 이름 목록은 `walk`, `idle_sit`, `idle_look`, `attack_laser`와 정확히 일치한다. 레이저 FX나 전환용 별도 클립을 몰래 추가하지 않는다.
- 루프 3회 연속 재생에서 튀는 프레임이 없어야 한다. 앞발 접지·뒷다리 접힘·꼬리 체인 연결을 0.5배로 확인한다.
- 레이저 시작점은 눈 기준점과 일치하고, 전환/정지/로딩 해제 시 잔류하지 않는다. 양눈 착탄은 하나의 공격 이벤트에 연결할 수 있어야 한다.
- 성능은 측정 기기·해상도·브라우저·노출된 모델 수와 함께 기록한다. 평균 FPS만으로 합격을 주장하지 않고 프레임 시간·draw call·삼각형·로드 시간을 함께 남긴다.
- 기존 A/D 파일·이미지·맵·타 에이전트 소스 보존 여부를 확인한다. 스크린샷은 비교판과 4클립의 대표 장면, 영상은 루프와 공격 타이밍을 남긴다.
