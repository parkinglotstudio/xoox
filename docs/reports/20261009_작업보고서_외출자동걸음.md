# 작업 보고서 — 외출자동걸음

1. 영상에서 본 순서는 새 게임이 아니라 지금 외출(`playTenMinutePillars`)과 같다. 싸우는 중 「전진」「후퇴」를 빼고, 무리가 시작되면 스스로 앞으로 한 걸음 걷게 했다.
2. 바꾼 파일
   - `src/main.ts`
   - `docs/gdd/58_층연출_챕터와시스템.md`
   - `docs/gdd/11_CHANGELOG.md`
3. 하지 않은 일: 금화, 뽑기, 스틱, 새 건물, 적 모양 교체는 안 했다. 페이지를 넘어가는 「이동」은 그대로다.
4. 로비에서 외출 → 권총 → 정화 진지 → 가운데 → 투석까지 눌렀다. 싸움 버튼은 연사·사선·관통뿐이었다. 연사를 고르니 「성장했다」가 떴다. 한 걸음은 약 0.8초라, 화면을 잡기 전에 끝나 걸음 자체는 정지 화면에 안 남았다.
5. 없음
