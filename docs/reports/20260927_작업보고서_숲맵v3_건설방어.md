# 작업 보고서 — 숲맵 v3 건설·방어

150×300m 전진형 숲맵을 Blender에서 다시 제작하고, 넓어진 평지와 5쌍의 건설 부지·건물 공격 시뮬레이션을 맵 툴에 적용했다. 구현과 자동 검증 완료, 실제 브라우저 화면 확인은 보안 정책 차단으로 미완료다.

## 지시자가 보면 되는 핵심

- 정화 후를 기본으로 정화 전후 맵, 건설 부지 10곳, 포탑·유닛 건물 임시 모델을 적용했다.
- 10개 건물 설치 후 전진 경로, 몬스터 공격·파괴·재탐색, 포탑 사격 검증 및 TypeScript 검사를 통과했다.
- Blender 렌더를 보관했다. 툴 화면 스크린샷과 실제 FPS는 미확보이며, 이 보고 이후 그룻봇 지시를 기다린다.

## 완료한 작업

### 지형·미술

- 150×300m, 위로 전진하는 연속 평지. 양쪽 숲 경계를 독립적으로 흔들어 원형 배치를 피했다.
- 시작·끝 수축 구간을 제외한 평지 폭 37.5~59.5m. 이동 가능 면적 13,231.5㎡.
- 바닥은 노랑을 띤 초록, 숲 바닥은 진한 초록으로 조정했다. 수직 잔디를 빽빽하게 세우는 대신 바닥 색상 변화와 가장자리 꽃·양치식물을 사용했다.
- 나무 수관 변형, 바위, 쓰러진 나무, 그루터기, 버섯, 흰색·분홍·노랑 꽃을 배치했다.
- 건설 부지에는 장식을 비워 두고 모서리 표식을 배치했다. 캐릭터와 몬스터가 다니는 중앙을 넓게 확보했다.
- 정화 전후 Blender 원본과 GLB, 전체 렌더 2장 및 정화 후 근접 렌더 1장을 생성했다.
- 시안의 색상 방향을 반영했지만 시안과 동일한 최종 미술 품질을 달성했다고 판단하지 않는다. 중앙 지면의 밀도와 화면 내 명암은 실제 플레이 카메라에서 추가 미술 검수가 필요하다.

### 건설·전투 프로토타입

| 부지 | 중심 X / 북쪽 Y(m) | 배치 의도 |
|---|---|---|
| 1 | 56.5 / 46 | 출발 방어, 왼쪽 |
| 2 | 76.5 / 98 | 오른쪽 굴곡 |
| 3 | 73 / 150 | 중간 방어, 왼쪽 |
| 4 | 84 / 203 | 긴 진입 구간, 오른쪽 |
| 5 | 66.5 / 255 | 마지막 공터, 왼쪽 |

- 각 부지에서 포탑은 Y+7, 유닛 건물은 Y−7에 배치한다.
- 포탑 예약 면적 8×8m / 충돌 6×6m. 유닛 건물 예약 10×10m / 충돌 8×8m.
- Blender 포탑 모델 및 유닛 건물 임시 기초·골조 모델을 제공한다. 유닛 건물 최종 디자인은 미정이다.
- 건설 시 몬스터 출현, 설치된 건물을 향한 경로 탐색, 근접 공격, HP 감소, 파괴 후 충돌 해제, 다른 건물 재탐색을 구현했다.
- 포탑 사거리 28m, HP 220, 유닛 건물 HP 180. 몬스터 HP 42, 이동 속도 3.6m/s, 공격 8/초. 포탑 피해 9/0.85초. 모두 기능 검증용 임시 수치다.
- 기존 ForestNavigation.ts를 유지하며 건물 점유 마스크를 덧씌운다. 캐릭터·몬스터가 점유한 곳에는 건설하지 못한다.
- 툴에 부지 선택, 건설, HP, 몬스터 추가, 전투 일시 정지, 전체 건설/초기화, 마스크와 경로 표시를 추가했다.

### 조명·부하 대응

- 정화 후 따뜻한 햇빛과 하늘/지면 환경광 설정을 공통 manifest에 기록했다. 런타임은 sRGB, NoToneMapping을 사용한다.
- GPU 인스턴싱, 30m 프랍 청크, 근거리 지면 장식 표시, DPR 1.5 상한, 2048 그림자 및 필요 시 그림자 갱신을 사용한다.
- 정화 후 GLB 5,688,920 bytes, 전체 인스턴스 환산 1,674,724 triangles / 395 nodes. 정화 전 5,595,244 bytes, 962,920 triangles / 395 nodes. node 수는 실제 draw call 측정값이 아니다.
- 전체 씬 기준 수목 2,735, 관목 3,936, 바위 1,110, 꽃 2,561, 양치식물 188, 버섯 31, 그루터기 26.
- 전체 씬은 여전히 비용이 있으므로 모바일 성능이나 FPS는 보장하지 않는다. 실제 카메라에서 GPU/CPU 측정이 남아 있다.

## 바꾼 파일·다른 툴에서 사용하는 방법

프로젝트 기준 경로:

- `src/tools/forestMap/main.ts`, `forest-map-tool.html`: v3 툴 UI와 씬 연결.
- `src/maps/forest150/ForestDefense.ts`: 동적 점유와 방어 전투.
- `scripts/forest150/build_forest.py`: Blender 제작 스크립트.
- `scripts/forest150/validate-v3.cjs`: 이동·건설·전투 검증.
- `data/maps/forest150/manifest.json`: 공통 최신 버전 진입점, revision `forest150x300-v3`.
- `data/maps/forest150/releases/v3/`: 정화 전후·건물 GLB, navigation/construction JSON, 마스크, 렌더, 통계, 검증 결과.
- `art-source/forest150/v3/`: 정화 전후 및 건물 Blender 원본 4개.

다른 툴은 GLB 경로를 고정하지 말고 `/maps/forest150/manifest.json`을 읽어 states/navigation/construction/buildings/lighting을 연결한다. 실제 크기는 widthMeters=150, lengthMeters=300을 사용한다. 기존 호환 필드 sizeMeters=150만으로 정사각형을 가정하지 않는다. navigation/construction 좌표는 동쪽 X·북쪽 Y, Three 좌표 변환은 `(X, 높이, -Y)`다. 다른 툴의 자동 새로고침 기능까지 구현한 것은 아니다.

확인 주소: http://localhost:5179/forest-map-tool.html

기존 `purify-raid-tool.html`의 본 게임 전투로 이 기능을 통합한 것은 아니다.

## 하지 않은 일·다음 확인

- 브라우저 정책이 localhost 툴 접근을 차단해 실제 화면 확인 및 새 툴 스크린샷을 확보하지 못했다. 우회 접근하지 않았다.
- 실제 FPS/메모리/그림자 비용, UI 설치·정화 전환은 후속 실행 확인이 필요하다.
- 유닛 생산, 유닛 건물 최종 디자인, 적끼리 회피, 최종 밸런스, 본 게임 통합은 범위 밖이다.
- 미술은 시안과 픽셀 단위 동일하지 않다. 최신 렌더를 기준으로 그룻봇의 검수 지시를 기다린다.
