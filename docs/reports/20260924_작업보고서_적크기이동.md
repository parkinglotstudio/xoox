# 작업 보고서 — 적 크기와 이동

작성: Cursor

## 한 줄

적을 캐릭터와 비슷한 크기로 앞쪽에 두고, 웨이브 중에는 걸어 다니며 쏘기·걷기 애니를 쓰게 했다.

## 바꾼 파일

- `src/tools/forwardWave/view3d.ts` — 적 배율 0.5, 시선 앞 3m 안에 펼침. 이동 중이면 walk / walk_shoot, 서 있으면 shoot / idle
- `src/tools/forwardWave/main.ts` — 웨이브 중 진지 앞을 돌아다님
- `docs/reports/20260924_작업보고서_적크기이동.md` — 이 보고서

## 하지 않은 일

- 점구름은 쓰지 않았다.
- 본편 전투는 연결하지 않았다.

## 핵심

- 샘플 영상처럼 적은 캐릭터만 하고, 탑 옆 앞에 보인다.
- 주소 `http://localhost:5173/forward-wave-tool.html`
- 만든 애니 중 걷기·쏘기·걸으며 쏘기를 상태에 맞춰 재생한다.
