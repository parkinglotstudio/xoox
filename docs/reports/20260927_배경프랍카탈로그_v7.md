# 숲맵 v7 배경 프랍 카탈로그

총 43종, 정화 전후 86개 GLB. 카탈로그 툴: http://localhost:5179/forest-prop-tool.html

## 다른 담당자의 사용 방법

- 공통 manifest의 `catalog` URL을 읽고 `items[].variants.purified/polluted`에서 선택한다.
- GLB는 미터 단위, Three.js Y 위쪽, 피벗은 바닥 중심이다. boundsMeters는 Blender 기준 X폭·Y깊이·Z높이이다.
- 모든 등록 에셋은 독립 모델이다. 이번 작업에서 카탈로그 프랍을 맵에 추가 배치하지 않았다.
- 유물 시설 15종은 v6의 크기별 실제 변형을 각각 추출했다. 이전 버전 10종은 보존용이며 일부 정화 전후 원형이 같을 수 있다.
- 실제 배치 시 이동 마스크·건설 슬롯 점유 검사와 충돌 처리 책임은 배치 도구에 있다. 카탈로그 자체가 이동 허가를 주지 않는다.
