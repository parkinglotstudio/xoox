## 만든 것

- **크기 (사람 1.5m 기준)**

  | 요소 | 크기 |
  |---|---|
  | 지형 블록 | 30cm |
  | 턱 | 30~60cm |
  | 나무 | 약 3.4m |
  | 작은 집 | 3.6×3.0m · 벽 2.1m |
  | 선착장 | 폭 2m · 길이 12m |
  | 길 | 폭 약 2.4m |
  | 풀 덤불 | 10~35cm |
  | 꽃 | 20~30cm |

- **지형:** 섹터를 30cm 격자(367×367칸)로 나눠 높이·표면을 정한다. 같은 줄의 같은 칸끼리 한 면으로 합쳐서 **지형 면이 6천여 개**뿐이다.
  - 블록 한 칸의 결(밝기 흔들림 · 넓은 얼룩 · 칸 모서리 음영)은 재질이 월드 좌표로 그린다. 게임 셰이더로 옮길 수 있다.
- **배치:**
  - 남쪽 굽이진 해안, 동쪽 만
  - 선착장에서 북쪽으로 굽이진 모래 길
  - 굽이진 경계의 낮은 턱 2단, 서쪽 고원
  - 연못
  - 나무 숲 7무리 + 홀로 선 나무
  - 해안 바위 + 들판 바위
  - 북동쪽 작은 빨간 지붕 집
  - 떠다니는 시안 반짝이
  - 먼 북쪽 계단식 파스텔 언덕, 구름
- **풀·꽃:** 파티클 인스턴스(풀 2.2만 · 꽃 3천). 1.5m 칸마다 노이즈 밀도를 줘서 덤불로 뭉친다.
- **색:** v2 팔레트 그대로.
  - 민트 `#B8E0D6`, 모래 `#E9DFC7`
  - 얕은 물 `#A8E6E8` → 깊은 바다 `#4D9DB3` (해안 거리 그라데이션)
  - 나무 `#A67C52`, 빨간 지붕 `#B2443A`
  - 반짝이 `#0FBEC7`
  - 렌더된 민트 실측 `#bddcc8`
- **조명:**
  - 카메라에 보이는 하늘은 연파랑 → 지평선 크림 그라데이션.
  - 물체를 비추는 빛은 중립 따뜻한 환경광 + 남서쪽 해.

## 해결한 문제 (실측)

- 월드 볼륨 안개 → 110m 스케일에서 빛을 전부 먹어 검게 렌더됨 → 제거
- AgX 톤 + 파란 하늘빛 → 민트가 `#c8fcff` 청록으로 뜸 → Standard + 하늘/조명 분리로 `#bddcc8`
- 파티클 방출체를 `hide_render` → 풀도 같이 사라짐 → 방출체 보이기만 끔
- 파티클 인스턴스가 X축으로 90° 누움 → 원본을 반대로 눕혀 둠
- 줄 단위 긴 면에 밀도를 주면 뭉침이 안 생김 → 1.5m 칸 방출 면

## 샘플 대비 남은 차이

1. 풀이 시안보다 막대 느낌이다(잎이 곧고 굵기가 같음). 잎 끝을 가늘게 하고 휘게 하는 형태가 필요하다.
2. 턱 경계가 얇은 짙은 선으로 보인다. 시안은 턱 윗면 가장자리에 풀이 흘러내린다.
3. 구름이 평평한 흰 공이다. 시안은 뭉게 블록 구름.
4. 전경은 섹터 가장자리가 직선으로 잘린다(이웃 섹터 없음).
5. 뒤에서 본 캐릭터는 머리만 보인다(스케일은 맞음).
6. 게임 연결(glb 내보내기, 유닛 랩·전진 웨이브)은 아직 없다.
