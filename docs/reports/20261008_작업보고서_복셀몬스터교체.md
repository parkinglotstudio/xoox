# 작업 보고서 — 복셀 몬스터 교체

1. 쓰던 매끈한 몬스터를 빼고, 블록으로 쌓은 몬스터 45종으로 바꿨다. 오브젝트 툴과 테스트 게임 둘 다.
2. 바꾼 파일
   - `src/stage/monsters/voxelMonster.ts` — 복셀 몬스터를 불러오고 마리마다 복사.
   - `src/tools/objectTool/main.ts` — 분류 「복셀 몬스터」 45종. 걷는 글로브 5종과 몬스터 원본 묶음은 목록에서 뺌.
   - `src/main.ts` — 외출 웨이브 몬스터를 복셀로.
   - `src/tools/forestPlay/PlayCombat.ts`, `main.ts` — 숲 플레이 사냥 몹을 복셀 Mushnub로.
   - `src/tools/forestPlay/PlayUnitCatalog.ts` — 배치 목록에서 옛 몬스터 글로브를 뺌.
   - `src/tools/forestMap/main.ts` — 숲 맵 툴에서 나오는 적도 복셀.
3. 하지 않은 일
   - 유닛랩 포탑 사격 미리보기의 동작 블록(플립북)은 그대로 둠.
   - UFO 4종 글로브는 몬스터 45종과 달라서 목록에 남김.
   - 케니 건물 팩은 그대로 둠.
4. 지시자가 보면 되는 핵심
   - 오브젝트 툴 「복셀 몬스터」 45개. Mushnub가 네모 블록으로 보임.
   - 숲 플레이에서 적 1을 내면 클립 없는 복셀 몹이 잡힘. `tsc -b` 통과.
   - 외출 웨이브의 슬라임·버섯·선인장도 같은 블록 몬스터를 씀.
5. 다음 지시 전에 막힌 질문. 없으면 `없음`
   - 없음
