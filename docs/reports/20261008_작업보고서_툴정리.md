# 작업 보고서 — 상단 툴 정리

1. 상단 툴을 하나씩 보고, 옛 섬·방랑자를 쓰는 겹친 툴은 뺐다. 오브젝트 툴에는 빠졌던 모델과 점구름을 다시 넣었다.
2. 바꾼 파일
   - `src/tools/toolsCatalog.ts` — 상단에서 키트·방랑자애니·3D뷰·습격·스킬프로토를 뺌.
   - `src/tools/objectTool/main.ts` — 점구름 형태, 몬스터 모델, 포탑 부품, 초기 유닛, 리아 스프라이트 비율을 목록에 넣음. 190개.
   - `src/tools/unitLabTool/main.ts` — 유닛랩의 옛 섬 맵 버튼이 정화 숲으로 감.
   - `forest-play-tool.html` — 방랑자 링크를 뺌.
   - `vite.config.ts`, `package.json` — 뺀 툴의 실행 항목을 지움.
   - 페이지 파일은 `_backups/20261008_tool_dedupe/` 에 복사한 뒤 루트에서 지움.
3. 하지 않은 일
   - 레이아웃·HUD·시나리오·로그·숲 플레이·숲 맵·프롭·유닛랩·캐릭 비교·펫 툴은 둠.
   - 시나리오 문장 안의 지역 이름은 그대로 둠.
   - `sector-editor.html` 등 섬 맵 편집 파일은 허브에 없지만 폴더에는 남아 있음.
4. 지시자가 보면 되는 핵심
   - 게임 위 버튼은 숲플레이, 오브젝트, 레이아웃, HUD, 시나리오, 로그.
   - 오브젝트 툴 190개. 몬스터도 그림이 나온다.
   - 확인: `tsc -b` 통과. 오브젝트 툴과 게임 상단 바를 브라우저에서 봄.
