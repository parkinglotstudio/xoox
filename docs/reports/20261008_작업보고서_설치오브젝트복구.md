# 작업 보고서 — 설치 오브젝트 복구

1. 받아 둔 케니 팩과 쿼터니우스 몬스터 원본을 오브젝트 툴에만 다시 넣었다. 목록은 618개.
2. 바꾼 파일
   - `data/tools/unit_lab/installed/` — 케니 타워디펜스 160, 케니 공장 143, 케니 생존 80, 몬스터 원본 45. `manifest.json`
   - `src/tools/objectTool/main.ts` — 그 목록을 툴에 붙임.
   - `src/tools/toolsCatalog.ts` — 오브젝트 툴 설명.
   - `scripts/_gen_installed_manifest.mjs` — 목록을 다시 만들 때 쓰는 스크립트.
3. 하지 않은 일
   - 본편 게임에는 넣지 않음.
   - 이미 있던 숲 유닛·숲 몬스터(맞춰 둔 q_ 모델)는 그대로 둠. 원본은 「몬스터 원본」으로 따로 있음.
   - KayKit 참고 캐릭터 2개는 넣지 않음.
4. 지시자가 보면 되는 핵심
   - 오브젝트 툴 분류에 케니 타워디펜스, 케니 공장, 케니 생존, 몬스터 원본이 있다.
   - 몬스터 원본 Mushnub가 툴에서 열리는 것을 확인했다.
   - 예전에 팩 160여 개 중 일부만 유닛랩에 골라 넣었던 것을, 이번엔 받은 파일 전부 툴 목록에 올렸다.
5. 다음 지시 전에 막힌 질문. 없으면 `없음`
   - 없음
