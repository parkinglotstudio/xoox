# 작업 보고서 — 숲플레이자동사냥

숲 플레이 툴의 자동 사냥을 네비 메시 위에서 앞줄 8.2m, 6m 후퇴, 9m 접근, 직선 착탄으로 맞췄다.

## 바꾼 파일

- `src/tools/forestPlay/PlayCombat.ts` — 슬롯 추적, 거리 이동, 착탄 지연, 앞줄 쌍권총/뒷줄 바주카, 사망 투명
- `src/tools/forestPlay/PlayCharacter.ts` — 쏘기 클립이 걷기에 바로 잘리지 않음
- `src/tools/forestPlay/main.ts` — 자동 사냥 중 무기 셀렉트 표시
- `docs/handoff/20260927_숲플레이통합/COMBAT_PLAN.md`
