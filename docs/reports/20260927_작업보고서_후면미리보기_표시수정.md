# 작업 보고서 — 후면 미리보기·오브젝트 표시 수정

숲맵 툴 왼쪽 아래에 실시간 후면 미리보기와 카메라 조절을 추가하고, 근거리 장식이 숨겨질 수 있는 컬링 조건을 수정했다.

## 지시자가 보면 되는 핵심

- 기존 화면에서 이동하면 왼쪽 아래 미리보기의 캐릭터와 카메라가 따라간다. 같은 씬을 공유하므로 설치·몬스터·정화 상태도 동기화된다.
- 드래그 좌우/상하 회전, 휠 거리, 슬라이더 각도·거리·높이·시야각, 게임 기본값 복원이 가능하다.
- TypeScript 및 회귀 검증 통과. 실제 브라우저 화면 검수·스크린샷은 기존 보안 정책 차단으로 미완료다.

## 완료 내용

### 미리보기

- 후면 TPS 방식으로 구성했다. 사용자 표현의 후면 FPS를 캐릭터 뒤에서 게임을 보는 화면으로 해석했다.
- `journey3d_layout.json`의 캐릭터 키, TPS 거리·높이·앞보기 배수, FOV를 로드한다. 현 설정 기준 거리 6.24m, 높이 약 3.705m, FOV 72도다.
- 게임의 후면 카메라 추적 방식과 동일하게 위치를 보간한다. 회전 각도는 미리보기에서만 조절한다.
- 기존 캐릭터 이동·클릭 이동·미니맵 이동을 그대로 사용한다. 미리보기 조작은 지도 이동 클릭으로 전달되지 않는다.
- 같은 WebGL 렌더러에서 두 번째 viewport를 그린다. 게임 시뮬레이션과 애니메이션을 두 번 진행하지 않는다.
- 미리보기에서는 이동 마스크·경로·캐릭터 링·건설 자리 글자 같은 편집 보조물을 숨긴다. 렌더 후 원래 표시 상태를 복구한다.
- 편집 패널 높이를 줄여 왼쪽 아래 미리보기와 겹치지 않도록 하고, 낮은 창에서는 패널을 오른쪽으로 배치한다.
- 본 게임 전체를 임베드한 것은 아니다. 카메라 기본 구도를 공유하는 현재 숲맵 씬의 실시간 미리보기이며 게임 HUD·안개·후처리를 완전히 동일하게 재현한 것은 아니다.

### 오브젝트 사라짐 점검

확인한 문제 조건: 풀·꽃 묶음은 카메라와 **묶음 중심 사이의 3D 거리**만으로 표시 여부를 정했다. 큰 묶음의 가장자리가 가까워도 중심이 멀면 전체가 숨겨지고, 카메라 높이도 판정에 포함됐다.

- 묶음 전체 bounding box에 대한 수평 최단 거리로 수정했다. 가까운 가장자리가 보이는 범위면 묶음을 유지한다.
- GLB 인스턴스의 bounding box/sphere를 다시 계산해 전체 인스턴스를 포함하도록 했다.
- 메인 카메라와 미리보기 카메라 렌더 전에 각각 표시 판정을 수행한다. 한 카메라가 숨긴 장식이 다른 카메라에도 그대로 숨겨지는 것을 방지한다.
- 이 문제 조건은 코드와 회귀 검증으로 확인했으나, 사용자가 목격한 모든 사라짐 현상의 원인이라고 단정하지 않는다.
- 설치 건물은 기존 전투 로직상 HP가 0이 되면 파괴돼 숨겨진다. 거리 컬링과 별개다. 근접 때 건물 자체가 사라지는 경우 전투 일시정지 상태와 HP를 함께 확인해야 한다.
