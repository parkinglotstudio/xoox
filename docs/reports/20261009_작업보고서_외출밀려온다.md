# 작업 보고서 — 외출밀려온다

1. 외출 싸움이 시작되면 「싸운다」 글 대신, 숲 가운데에 「오염이 밀려온다」가 뜨고 둘이 앞으로 걷게 했다.
2. 바꾼 파일
   - `src/main.ts`
   - `src/style.css`
   - `docs/gdd/11_CHANGELOG.md`
3. 하지 않은 일: 왼쪽·가운데·오른쪽 버튼, 포탑을 둘 다 세우는 것, 페이지 이동 버튼은 그대로다.
4. 로비에서 외출 → 권총 → 정화 진지 → 가운데 → 투석. 숲 위에 「오염이 밀려온다」가 보였고, 버튼은 연사·사선·관통이었다. 「싸운다」는 로그에 없었다.
5. 없음
