# 작업 계획 — D 원본 스프라이트 비율 별도 시안
작성: Codex · 2026-09-27

## 목표
기존 D를 보존하고 D-SP01을 추가한다. 기준은 사용자가 첨부한 유닛 랩의 원본 스프라이트이며 실제 ingame_idle 첫 프레임을 측정한다.

## 범위
- D의 얼굴·머리카락·옷·색상을 유지하며 인체 비율만 변경.
- 머리 약 49%, 몸통/다리 길이와 관절 위치를 스프라이트 약 4.4등신에 맞춤.
- 18개 동작의 새 골격, 손 무기 위치, 발 접지를 재계산.
- 별도 GLB/Blender 원본, 유닛 랩 선택 항목, 비교 스크린샷 및 보고서.

## 검증
원본 D GLB/제작 스크립트 해시 유지, 18동작/표정/총구 연결, 유한 좌표와 지면 확인, 앞·뒤 시각 비교.
그룩봇 정기 확인은 사용자 지시로 중지하였다. 본 작업은 이번 채팅 직접 지시에 따른다.

## 추가 사용자 요청 — 3.5등신
기존 D 및 스프라이트 비율을 보존하고 D-35를 추가한다. 정수리~턱(꼬리머리 제외) 기준 3.5등신이며 전체 키는 약 1.9m로 정규화한다. 얼굴은 균일 축소하여 납작해지지 않게 하고 몸통·팔다리 골격과 18개 동작을 다시 계산한다.
