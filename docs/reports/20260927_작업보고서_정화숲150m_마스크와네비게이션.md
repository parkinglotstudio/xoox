# 작업 보고서 — 150m 정화 숲과 이동 마스크

150 × 150m Blender 숲 맵의 정화 전후 모델, 공통 이동 마스크, 캐릭터 이동 차단 및 몬스터 생성·경로 확인 툴을 구현했습니다.

## 확인 위치

http://localhost:5179/forest-map-tool.html

- 정화 후가 기본. 정화 전으로 전환해도 지형·이동 마스크는 동일합니다.
- 전체 보기 / 캐릭터 시점, 이동 마스크 표시, 미니맵 클릭 이동, WASD 이동.
- 몬스터 12마리 리젠 → 추적 시작으로 숲을 우회하는 경로를 확인합니다.
- 기존 유닛 랩과 툴 목록에 새 숲 맵 링크를 추가했습니다.

## 구성

- 전체 150 × 150m, 주요 공터 3곳과 동쪽 순환 연결 구간.
- 주요 연결 폭 22~24m. 격자 경계와 캐릭터 반경을 제외한 실제 통행 폭은 조금 줄어듭니다.
- 평지 7,864㎡, 나머지는 진입 불가 숲. 모든 평지 셀은 하나의 연결 영역입니다.
- 집·도로·바다 없이 숲과 바위로 외곽을 차폐합니다.
- 나무 1,251개, 관목 1,593개, 바위 군락 446개, 낮은 꽃·지피 군락 1,885개. 반복 메시를 GPU 인스턴싱하고 30m 공간 단위로 묶었습니다.
- 정화 후 GLB 2.84MB / 약 69.7만 삼각형, 정화 전 2.75MB / 약 38.2만 삼각형. 전체 맵 수치이며 캐릭터는 별도입니다.

## 마스크와 다른 툴 연동

`/maps/forest150/manifest.json`의 `navigation`과 `states`를 함께 읽어 사용하세요. 구형 `/maps/block/manifest.json`은 이전 아일랜드 맵입니다.

- 마스크: 300 × 300셀, 셀당 0.5m. `walkable`은 1=평지, 0=숲/진입 불가.
- 좌표: x 동쪽, y 북쪽, 미터. JSON row 0은 남쪽, Three.js는 `(x, 0, -y)`.
- PNG 위쪽은 북쪽. 흰색 평지 / 검정 숲입니다. **PNG 대신 JSON을 판정의 기준으로 사용**해야 축·색공간 혼동을 피할 수 있습니다.
- `new ForestNavigation(data)` 후 `canStand`, `move`, `findPath`, `spawnPoints`를 사용합니다.
- 플레이어 반경 0.6m, 몬스터 반경 0.65m로 검증했습니다. 다른 크기는 호출 시 반경을 넘깁니다.
- 이동은 원과 막힌 격자 사각형의 교차 및 이동 구간 검사를 사용해 빠른 이동의 관통을 막습니다.
- 경로는 4방향 A* 탐색 후 캐릭터 반경으로 안전한 구간만 단순화합니다. 대각선 모서리를 무시하고 지나가지 않습니다.
- 두 정화 상태가 같은 JSON을 참조하므로 색상 변화로 충돌이 바뀌지 않습니다.
- 레벨 모양은 생성 스크립트의 `rooms`, `links`, `playable`에서 수정해 **모델과 마스크를 함께 재생성**합니다. Blender에서 임의로 소품만 이동하면 마스크는 자동으로 바뀌지 않습니다.
- 향후 배포는 새 release 폴더 생성 → 검증 → manifest의 revision/경로 갱신 순서입니다. 현재 숲 툴은 새로고침 시 최신 manifest를 읽습니다.

## 검증

- TypeScript 전체 프로젝트 `tsc --noEmit` 통과.
- 평지 31,456셀 모두 연결 확인.
- 공터 경로, 안전 생성 60지점과 각 지점의 복귀 경로 검증 통과.
- 대량 이동 입력 500건, 얇은 벽 관통, 경계 반경, 바깥 좌표, 연결되지 않은 목표 검증 통과.
- 브라우저에서 정화 전후 로드, 마스크 표시, 12마리 생성·우회 추적, 미니맵 클릭 이동 확인.
- 최종 GLB의 배포 파일과 생성 파일 SHA256 일치 확인.
- 현재 PC 내장 브라우저에서 전체 보기와 12마리 추적은 약 31~35 FPS 관찰. 기기별 목표 성능 통과를 의미하지 않습니다.

## 하지 않은 일

- 본편 레이드·전투 시스템에 새 맵과 내비게이션을 연결하는 작업.
- 몬스터끼리의 충돌 회피, 웨이브/리젠 타이머, 실제 전투와 정화 영역의 점진 변화.
- 생성 이미지와 동일한 수준의 최종 아트 마감, 타깃 기기별 LOD·최적화. 현재는 공간 및 이동 검증이 가능한 첫 구현입니다.
