# 작업 계획 — 디펜스 3형태 후 복셀 펫 4종

작성: Codex(아스트라)  
착수: 2026-10-04 09:11 KST  
승인: 이 대화에서 사용자가 「이제 작업 진행」 및 「작업 다 끝나면 펫 추가 만들고 거기까지만」 지시.

## 순서와 종료 범위

1. 기존 forest-play 툴의 디펜스 세 형태를 구현하고 실행·시간·적 공격·시설 붕괴를 검증한다.
2. 사용자 제공 그림 4장을 기존 BCAT 파이프라인에 맞춰 복셀 펫으로 제작한다. 달리기 클립을 추가하고 모델·리깅·동작을 툴에서 비교한다.
3. 스크린샷·소스·제작법·검증 결과·보고서와 Codex 상태 행을 갱신하고 종료한다.

## 디펜스 기준

- 북쪽 길 하나 → 남쪽 본진. 포탑 5 / 방어물 4 / 본진 1.
- 기존 모델 형태와 색을 유지하고, 시설 HP는 실제 적 공격으로만 감소한다.
- 캐릭터 없는 초기 장면은 시간 종료이며 승패를 추가하지 않는다.
- 타워 45초, 웨이브 20초 × 3 + 사이 5초 × 2, 기지 60초.
- 플레이어·펫·본편·필러·자원·강화 연결은 이 디펜스 구현에 넣지 않는다.
- D10의 상충 표현은 공통 기준인 forest-play 내부 범위로 한정한다. 새 HTML 진입점을 만들지 않고 기존 forest-play 안에서 모드를 확인하며 본편과 forest-map은 수정하지 않는다. 이 해석을 진행 보고에 명시한다.
- 문서의 이전 구현 금지 단계는 사용자의 이번 직접 착수 지시로 변경됐다. 확정된 형태·시간·모델 보존 규칙은 유지한다.

## 펫 기준

`3NOFILTER.png`, `Australian Cattle Dog1- Flux.png`, `Australian Cattle Dog2- Lumos.png`, `Norwegian Forest Cat - Gizmo.png`의 귀·눈·털/장비·배색·비대칭을 따로 반영한다. 기존 고양이 리소스는 보존하고 신규 폴더와 미리보기에서 선택할 수 있게 한다. 걷기와 달리기를 구분하고 앉기·서기 중간 전환을 포함한다.

## 협업·검증

Codex 새 모듈을 중심으로 구현하고 기존 숲 툴 연결은 필요한 최소 변경으로 기록한다. 수정 전 백업 및 동시 변경을 확인하고 다른 에이전트의 변경은 덮어쓰지 않는다. 충돌이나 추가 설계 의견이 생기면 안전히 저장하고 의견서로 전달한다. 커밋·푸시는 하지 않는다.

정기 확인은 기존 설정대로 오늘 13~23시 매시 정시, 자정 종료다. 현재 제작은 사용자의 직접 착수 지시에 따른다.
