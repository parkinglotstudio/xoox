## 핵심 — 원본 비교 후 보정

### 얼굴

| 항목 | 첫 제작본에서 확인한 차이 | BCAT02 보정 |
|---|---|---|
| 귀 | 폭이 좁고 원본의 벌어짐·림 두께가 부족 | 삼각 귀 폭·높이 확대, 바깥쪽으로 벌어진 형태, 두꺼운 외곽/밝은 안쪽/점무늬/분절 추가 |
| 귀 뿌리 | 확대 시 헤드셋 위 연결 공간이 떠 보임 | 아래 연결 블록을 추가해 귀와 헤드셋 사이를 연결 |
| 정수리 | 넓고 납작한 판이 겹친 형태 | 중앙의 높은 직육면체와 좌우의 낮은 단차로 재제작 |
| 회색 이마판 | 너무 높은 위치 | 중심 Z를 0.739m에서 0.674m로 내리고, 폭 0.081→0.096m, 높이 0.068→0.077m로 조정 |

| 눈 모서리 | 단순 사각형으로 원본의 안쪽 사선과 아래 단차가 없음 | 안쪽 위 사선, 아래 바깥 모서리 단차, 눈썹 안쪽 사선 면 추가 |

| 눈 색 | 초기 GLB에서 발광이 흰색으로 더해져 분홍빛 | 붉은 발광값을 명시하고 세기를 낮춤 |

숫자는 제작 좌표/치수의 변경 기록이다. 시안에서 실제 미터 단위를 추출했다는 의미는 아니다. 정면·3/4·얼굴 확대에서 시안을 다시 확인하며 보정했다.

### 몸과 표면

- 스카이블루/시안, 차콜 베스트, 라임 목·가슴 포인트, 퍼플 관절, 헤드셋 삼각 발바닥 로고, 작은 등 핀과 큐브 체인 꼬리를 제작했다.
- 작은 모서리 면과 하나의 공유 마모 텍스처를 사용했다. 큐브마다 런타임 오브젝트를 만들지 않는다.
- 어깨판과 관절 장식은 상단 다리 본을 따른다.
- 초기 앉기에서 가려진 목 장식을 보정했고 꼬리가 다리 안쪽으로 들어가지 않도록 몸 바깥으로 도는 경로를 만들었다. 반대편 꼬리는 시점에 따라 일부 가려진다.

## 동작과 전환

| 클립 | 길이 | 역할 |
|---|---:|---|
| `walk` | 1.0초 | 네발 제자리 걷기 |
| `idle_sit` | 4.0초 | 앉아서 호흡·머리·귀·꼬리가 조금씩 움직임 |
| `idle_look` | 5.0초 | 앉은 상태에서 좌우를 살피는 루프 |
| `attack_laser` | 0.7초 | 서서 조준·짧은 머리 반동·회복 |
| `stand_up` | 1.0초 | 골반을 올리고 뒷발을 순차적으로 옮기며 꼬리를 폄 |
| `sit_down` | 1.0초 | 골반을 내리고 뒷다리를 접으며 꼬리를 옆으로 감음 |

- 기본 4동작과 사용자 요청으로 추가한 전환 2동작, 총 6클립이다.
- UI의 **서기**는 공격 클립의 중립 포즈를 정지시켜 표시한다. 별도 일곱 번째 서기 클립은 없다.
- 앉은 동작에서 걷기/서기/레이저로 이동하면 `stand_up`을 거친다. 서 있는 동작에서 앉은 대기/두리번으로 이동하면 `sit_down`을 거친다.
- 전환 끝에서 요청한 동작으로 자동 연결하며, 클립 연결부에는 0.18초 혼합을 적용한다.
- 전환은 단순 페이드만 추가한 것이 아니다. Blender에서 중간 골반 위치·다리 관절·뒷발 순서·꼬리 방향을 키프레임으로 구웠다.
- 두 눈 레이저는 head 본의 실제 눈 기준점에서 나온다. 공격 시간 0.18~0.30초에만 빔이 나오며 착탄 잔상은 0.48초까지다. 검수용 표적에 3초 간격으로 반복한다.

## 검증

- Blender 5.2.2에서 제작 및 GLB 내보내기 성공.
- 고양이 툴 TypeScript strict 검사 통과.
- Chrome에서 최종 GLB의 6클립을 읽고 정면·측면·후면·얼굴 확대를 확인했다.
- 기본 루프 3종의 첫/마지막 키 값 차이 0, 비정상 숫자 좌표 0개.
- 각 클립 9시점의 스킨 변형 좌표에서 바닥면(-0.001m) 대비 최대 하향 오차는 약 0.14mm였다. 이는 샘플 검사이며 모든 프레임의 일반 충돌 검증을 뜻하지 않는다.
- 눈 레이저는 0.10초 꺼짐 / 0.23초 켜짐 / 0.60초 꺼짐. 대기 전환 시 잔류 FX 없음.
- 일시정지 전후 시간 차이 0.
- 자동 일어서기: 골반 Y **0.173 → 0.264(중간) → 0.355m**, 최종 상태 `stand`.
- 자동 앉기: 골반 Y **0.355 → 0.264(중간) → 약 0.173m**, 최종 상태 `idle_sit`.
- 브라우저 실행 오류와 리소스 로딩 오류가 없는지 검증 JSON으로 남겼다.
- 프레임 비용은 영상 녹화를 포함한 headless Chrome 화면 통계만 기록했다. 모바일이나 다수 펫 성능을 보장하는 벤치마크는 수행하지 않았다.
