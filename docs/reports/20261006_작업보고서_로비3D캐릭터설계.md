# 작업 보고서 — 로비 3D 캐릭터 설계

1. 로비의 점구름 펫을 루온·리아 3D로 바꾸고 전환 버튼을 다는 설계를 채팅에 올렸다. 코드는 승인 전이다.
2. 바꾼 파일
   - `docs/status/BOARD.md`
3. 하지 않은 일
   - `src/lobby.ts`와 스타일은 수정하지 않았다.
   - 외출 전투 파티 선택에는 연결하지 않았다.
4. 지시자가 보면 되는 핵심
   - 분류는 Bounded. 배 홈 화면의 펫 점구름 자리에 한 명만 세운다.
   - 버튼은 루온 / 리아. 모델은 유닛랩과 같은 GLB, 대기는 idle.
   - 승인 후에만 구현하고 로비에서 두 버튼을 눌러 확인한다.
5. 다음 지시 전에 막힌 질문. 이 설계로 구현해도 되는지.
