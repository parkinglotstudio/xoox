# 작업 보고서 — 20260926 D 얼굴색·그림자 보정

작성: Codex

## 한 줄

D 얼굴을 원본의 밝은 복숭아색에 가깝게 보정하고 홍조를 맞췄다. 얼굴이 받는 머리 그림자 농도는 기존의 22%로 줄여 비교 툴과 유닛 툴에 같은 설정을 적용했다.

## 바꾼 파일

- `src/tools/unitLabD/FaceAppearance.ts`: D 피부·홍조의 색상 반응과 얼굴 그림자 강도를 관리하는 공통 보정 함수.
- `src/tools/unitLabD/main.ts`: 원본 비교 툴에 적용.
- `src/tools/unitLabTool/CharacterLab.ts`: D 원본/블록 두 복제본에 적용하고 추가 소재 해제 처리 재사용.
- `scripts/unit_lab_d/capture_face_before.mjs`, `review_face_tone.mjs`, `verify_face_appearance.mjs`: 수정 전 캡처, 후보 비교, 최종 검증.

## 핵심

그림자만 줄인 상태는 얼굴 중앙 RGB가 약 (220,196,158)로 원본보다 누렇고 어두웠다. 피부와 홍조를 따로 보정해 원본 색에 접근했다.

- 피부 보정은 `D_head_clean`만 적용한다. 머리·브로치·의상에는 색 보정을 적용하지 않는다.
- 눈·입·표정 메시에는 그림자 완화만 적용한다.
- 얼굴의 볼·턱 면 방향에 따른 명암과 턱 아래 음영은 남긴다.
- 공통 광원의 색과 세기는 바꾸지 않았다.
- A의 기존 얼굴 그림자 농도 0.18은 유지했다.

셰이더의 선형 확산색 배율은 피부 (2.80,1.42,1.54), 홍조 (2.15,1.17,1.37)다. 이 값은 최종 화면 밝기의 배수가 아니다. 기존 조명과 톤 매핑을 거친 화면 색상을 원본에 맞추기 위한 값이다.

## 색상 표본

같은 카메라·idle 0초·공통 조명에서 측정했다. 아래 값은 중앙 피부와 홍조의 작은 영역 중앙값이며 얼굴 전체의 완전 일치를 뜻하지 않는다.

| 표본 | 원본 그림 | 수정 전 | 수정 후 |
|---|---|---|---|
| 피부 RGB | 250,217,187 | 210,182,142 | 250,216,190 |
| 홍조 RGB | 246,166,150 | 209,137,109 | 252,174,150 |

표본 범위: 원본 720×720 얼굴 이미지에서 피부 x318–396/y467–509, 홍조 x188–229/y520–538. 1500×1120 툴 캡처의 모델 피부 x1105–1149/y720–746, 홍조 x948–978/y765–782. 형태 차이가 있으므로 대응 영역을 수동 지정했다.

## 검증

- 대상 TypeScript 검사 통과, 최종 브라우저/셰이더 오류 0.
- 정면·사선·얼굴 확대·눈 깜박임 캡처 확인.
- D 비교 툴의 3개 소재와 유닛 툴 원본/블록의 총 6개 소재에 같은 값 적용 확인.
- A로 전환 후 D 보정이 적용된 소재 0개, A 그림자 계수 0.18 유지 확인.
- 동일 확대 화면의 윗머리 표본 영역에서 수정 전후 최대 픽셀 차이 0.
