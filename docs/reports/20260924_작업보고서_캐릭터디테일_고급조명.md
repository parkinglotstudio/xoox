# 작업 보고서 — 캐릭터디테일 고급조명

작성: Claude

## 한 줄

캐릭터 블록을 더 잘게(2.6cm, 키 70칸) 쓸 수 있게 하고, 블록 AO·블록 테두리·그림자·환경광·림 라이트·톤 매핑으로 고급 조명을 넣었다. 원본+디테일 블록 캐릭터를 같이 띄워도 61fps.

## 바꾼 파일

- `src/tools/unitLabTool/VoxelMesh.ts`
  - `buildGreedy`: 면마다 네 모서리 블록 AO 계산(모서리 그늘이 같은 면끼리만 합침), AO 대각선 뒤집기, 선형 색·AO 속성 추가
  - `makePremiumMaterial`: 표준 물리 재질 + 정화 색 번짐·피격 발광·블록 AO·블록 테두리 음영
  - `VoxelUnit.premium`(기본 켬): 합친 메시가 고급 재질·그림자 사용
- `src/tools/unitLabTool/main.ts` — 부드러운 그림자(1024), ACES 톤 매핑, 방 조명 반사(환경광), 뒤쪽 푸른 림 라이트, 바닥은 가벼운 Lambert. 크기 버튼 「디테일 (캐릭터)」 70칸. 「고급 조명」 끄기(비교용)
- `src/tools/unitLabTool/CharacterLab.ts` — 표면 점 9만 → 22만(작은 블록에서도 빈칸 없게), 재질 바뀌면 블록 다시 만들기
- `unit-lab-tool.html` — 고급 조명 체크, 칸 수 최대 60 → 100

## 하지 않은 일

- 낱개 블록(연출 중)과 전투 미리보기의 적 플립북은 예전 간단 조명 그대로다.
- 폰 실측 없음. 본편 연결 없음.

## 핵심

- 디테일 블록 캐릭터: 블록 13,799개 → 합친 삼각형 약 4만(AO 때문에 합치기가 조금 덜 됨).
- 부하 실측(이 PC, 캐릭터 화면): 처음 24.1ms → 원인은 부드러운 그림자 2048(약 12ms)과 화면을 덮는 바닥의 환경광 반사(약 5ms). 그림자 1024 + 바닥 Lambert로 9.9ms(측정 동기화 대기 포함), 그림자 추가 비용 1.4ms.
- 합친 큰 면에도 블록 경계가 새겨져 레고처럼 칸이 보이고, 맞닿은 안쪽 모서리가 어두워져 입체감이 산다.
