# 스프라이트 제작 스펙 【확정】

> **갱신:** 2026-07-21  
> **목록:** [00_ANIM_LIST.md](./00_ANIM_LIST.md)  
> **스타일:** 흰 스티커 외곽 + 굵은 카툰 라인 · 보블은 애니만(스프링 미도시)

---

## 1. 캔버스

| 항목 | 값 |
|------|-----|
| 셀 크기 | **256 × 256** px 권장 (모바일) · 시범은 상대적으로 커도 OK |
| 시트 | idle = **한 장에 가로 6셀** (`{char_id}_idle_6frame_sheet.png`) |
| 배경 | 투명 권장 · 미리보기용 `#E8FFF4` 허용 |
| 외곽 | 실루엣 합친 뒤 **흰 보더** (셀 대비 얇게) |
| 세이프 | 캐릭터는 셀 안쪽 ~10% 마진 |
| 뷰 | 시범·카드 = **정면** · 인게임 무대 = **3/4 옆** ([03_WORK_ORDER §0.1](./03_WORK_ORDER.md)) |
| idle 각 | **±6~8°** 이내 · 과한 기울임 금지 |
| 로비 / 카드 | **흰색** 스티커 보더 유지 |
| **인게임 스프라이트** | **검정(진한) 카툰 외곽선** + **투명 배경** (흰 보더 쓰지 않음) |
| **셀 스케일 【고정】** | 한 캐릭터의 **모든 슬롯·모든 프레임**에서 캐릭터 크기·발 기준선·머리 pivot 동일. 동작마다 확대/축소 금지 |

## 2. 프레임 수 (고정)

| anim | frames | fps 권장 | 루프 |
|------|--------|----------|------|
| idle | 6 | 8 | ping-pong 또는 순환 (0-1-2-3-2-1) |
| move | 4 | 10 | 순환 |
| attack | 4 | 12 | 1회 |
| hit | 3 | 12 | 1회 |
| win | 3 | 8 | 마지막 홀드 |
| lose | 3 | 8 | 마지막 홀드 |

**A1 합계:** 6+4+4+3+3+3 = **23프레임 / 캐릭터**

## 3. 시트 레이아웃

### 3.1 단애니 스트립

가로 1행: `frame_0 … frame_n-1`  
파일: `{char_id}_{anim}_strip.png`  
크기: `(512 × N) × 512`

### 3.2 A1 마스터 시트

```
[ idle×6 ]
[ move×4 ][ attack×4 ]  … 또는 그리드 6행
[ hit×3 ][ win×3 ][ lose×3 ]
```

파일: `{char_id}_a1_sheet.png`  
1차 납품은 **애니별 스트립 + A1 한 장 요약** 병행.

## 4. 파츠 분리 (보블 idle)

| 파츠 | 역할 | idle |
|------|------|------|
| `body` | 몸통·다리 스텁 | **고정** |
| `head_hair` | 머리+머리카락 | **좌우 ±6~10° 또는 ±12px** |
| `face` | 눈·입 (교체용) | idle는 기본 표정 고정 |

합성 순서: body → head_hair → face → **흰 보더 bake**

> 이미지 생성기가 파츠 PSD를 못 줄 때는 **완성 프레임 스트립**으로 납품하고, 파츠는 후속 리깅용 메모로 남긴다.

## 5. idle 보블 키

| frame | 머리 |
|-------|------|
| 0 | 중앙 |
| 1 | 살짝 왼쪽 |
| 2 | 더 왼쪽 |
| 3 | 중앙 |
| 4 | 살짝 오른쪽 |
| 5 | 더 오른쪽 |

몸통·발 위치 불변. 스프링/코일 **금지**.

## 6. 포즈 가이드 (A1)

| anim | 포즈 |
|------|------|
| move | 몸 상하 bounce, 머리 idle보다 작게 |
| attack | 전방 기울임 → 타격 → 복귀 |
| hit | 뒤로 기울 + 눈 깜빡 |
| win | V포즈/손들기 짧게 |
| lose | 주저앉거나 별 깜빡 |
