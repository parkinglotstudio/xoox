# 향아 — 인게임 공격(attack) 【애니 컨셉 · 기준 실례】

> **장수 공통 연출 SSoT:** [`../../_guide/07_INGAME_ATTACK.md`](../../_guide/07_INGAME_ATTACK.md) ← **다음 캐릭은 여기부터**  
> **뷰:** 인게임 3/4 옆 · 검정 라인 · 오뚜기 콘 · 손·발 없음  
> **원칙:** 몸/머리가 주연. 팔·무기 연출 금지.  
> **엔진:** `docs/art/sprites/hyanga/engine/attack_a/` · `attack_b/`

---

## 전체 전투 흐름

```
idle → (빠름) move 접근 → Attack A 또는 B → 복귀 → idle
```

| 구간 | 담당 | 비고 |
|------|------|------|
| 접근 | `move` 시트 | **재생만 더 빠르게** (새 스프라이트 불필요) |
| 공격 | `attack_a` 또는 `attack_b` | 아래 키포즈 |
| 복귀 | attack 끝 프레임 + 코드 위치 복귀 | A는 `return` 포즈 필수 |
| 대기 | `ingame_idle` | |

---

## Attack A — 돌진 (hairball)

**한 줄:** 가까이 가서 웅크리며 말고 → **머리카락 공**으로 들이받고 → 풀어서 돌아온다.

| # | 키 | 순간 | 원본 | 상태 |
|---|-----|------|------|------|
| 0 | `crouch` | 적 앞에서 힘 모음 · **몸을 웅크림** (콘→둥글게) | `…_attack_a_00_crouch.png` | **신규** |
| 1 | `fly` | 머리카락 공 비행 | `…_hairball_fly_v2.png` | 있음 |
| 2 | `hit` | 임팩트 (스파크 OK, 적은 그리지 않음) | `…_hairball_hit_v2.png` | 있음 |
| 3 | `return` | 공→콘으로 풀리며 자세 복귀 | `…_attack_a_03_return.png` | **신규** |

코딩: 캐릭터 X 돌진·복귀 궤적. 스프라이트는 포즈만.

---

## Attack B — 제자리 마법 (헤어 루프)

**한 줄:** 자리 不動. **같은 몸·얼굴 고정**, 위로 선 머리카락만 살짝 떠는 2프레임 루프.

| # | 키 | 순간 | 원본 | 상태 |
|---|-----|------|------|------|
| 0 | `peak` | 헤어 상승 정점 (마스터) | `…_attack_b_01_peak.png` | 사용 |
| 1 | `peak_loop` | 동일 샷 · **헤어만** 미세 흔들림 | `…_attack_b_01_peak_loop.png` | 사용 |

`b_00_charge` / `b_02_release` 는 스케일 불일치로 **미사용**(보관만).
