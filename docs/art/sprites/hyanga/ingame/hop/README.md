# 향아 — 보드 점프(hop) 【애니 컨셉】

> **레퍼런스:** Monopoly Go 토큰 칸이동 + **공중은 어택과 같은 머리카락 공**  
> **뷰:** 인게임 3/4 옆 · 검정 라인 · 오뚜기 콘  
> **프레임:** 키포즈 (궤적·회전은 코딩)

## 한 줄

칸 이동용 **토큰 점프**.  
도약·착지는 일반 몸 · **공중만 머리카락 공으로 빙글** (어택 hairball과 톤 맞춤).

| 0 | `crouch` | 도약 준비 | 한 장 스트립에서 분리 |
