## 2. 매 생성 직전 체크 (전부 ✓ 후에만 그림)

- [ ] 배경 = 올리브 크로마키 (검정 아님)

- [ ] win이면: 즐거움 = **깜빡 + 헤어 춤** (과장 손·주연 미소 아님)
