## 향아에서 읽어야 할 것

| 항목 | 내용 |
|------|------|
| 고유 컷 | **2장** `run_a` / `run_b` |
| 시트 | 4프레임 `A B A B` · 각 ~170ms · loop |
| **변화량** | 몸·기울기·얼굴·원뿔 **고정에 가깝게** · **헤어 팁(끝) 모양**만 미세 |
| 하면 안 됨 | 프레임마다 몸·기울기·실루엣을 크게 다시 그림 (연결 끊김) |
| 하면 안 됨 | **크기만** 키우기/줄이기로 루프 만들기 (win과 동일 · 형태 변화여야 함) |

## 깜빡

| 항목 | 내용 |
|------|------|
| 빈도 | idle과 같이 **가끔만** (`playback: rare_blink` / `idle_rare_blink` 계열) |
| 평소 | open 눈 유지한 채 머리 끝만 루프 |
| 제작 | 이동 기울기 마스터 위에서 깜빡 컷이 필요하면 **같은 몸**으로 half/closed 추가 |

## 장수 제작 순서

1. 향아 move **이미지부터** 다시 보고 시작  
2. 캐릭터 **기울기 마스터 1장** 확정 (idle 디자인 유지 · 진행 방향 오른쪽)  
3. **머리 끝만** 다른 1장 → `run_b`  
4. `A B A B` 팩 + rare_blink 세팅  
5. idle과 **높이·피봇** 맞춤
