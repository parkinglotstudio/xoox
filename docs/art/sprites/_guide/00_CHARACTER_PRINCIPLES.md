## 한 줄

감정·상태·타격감 = **머리 + 머리카락(+눈)**.  
몸은 **오뚝이(삼각뿔·원뿔) 받침**.  
**팔·발은 있다** — 팔은 **옷(소매) 형태만**, 발은 **옷에 가려진 느낌**. (삭제·바지 노출 금지)  
**몸 두께 = 향아 급** (머리 대비 몸 폭 약 **1.05~1.20**, 향아≈1.07 · 주유 v6≈1.16 유지). 마름(≈1.03↓)·과뚱(≈1.40↑) 금지.

장수 컨셉서: [`../_concept_final/00_ROSTER_CONCEPT.md`](../_concept_final/00_ROSTER_CONCEPT.md)  
인게임 idle 재생(4고유→10프레임 왕복): [`05_INGAME_IDLE_PLAYBACK.md`](./05_INGAME_IDLE_PLAYBACK.md)

## 필수 규칙

| 항목 | 규칙 |
|------|------|
| 감정/행동 | 머리 각도 · 헤어 실루엣 · 눈 (몸·팔로 과하게 표현 금지) |
| **헤어 루프 【확정】** | win/move 등 A↔B는 **머리카락 모양·표현 변화**로만. **크기만 키우기/줄이기 금지**. 상세: `08_INGAME_WIN.md` |
| 몸 | 오뚝이 콘 · **향아와 같은 두께감** · 크게 구르거나 보폭 금지 |
| **하단 원뿔 각도 【확정】** | 인게임 대기 몸통은 **삼각뿔/원뿔**. **바닥이 넓고 위가 좁은 각도(실루엣)를 장수·프레임마다 항상 유지.** 앞으로 기울어 “이동”처럼 보이게 금지. 머리 중심은 원뿔 중심축 위에 수직으로 올림. 기준: 유비 `liubei_ingame_idle_base_v4` |
| **인게임 idle 제작** | **고유 그림 4장**(open/narrow/half/closed)만 그림 → 재생은 왕복+홀드로 **10프레임**. 10장 전부 신규 금지. 상세: `05_INGAME_IDLE_PLAYBACK.md` |
| 몸 폭 비 | 머리 폭 대비 **1.05~1.20** (기준 향아≈1.07) |
| **헤어 ↔ 옷 색** | **메인 헤어색 ≠ 메인 옷색**. 인게임 축소 시 뭉개짐 방지. 헤어 시그니처 유지 · 옷으로 대비. 악센트만 동일 계열 OK |
| 팔 | **있음** · 손/팔짱 금지 · **소매·옷 볼륨 실루엣으로만** 암시. **예외:** win 손 미세 움직임 |
| 발·다리 | **있음** · 바지·노출 금지 · **헴/스커트/케이프에 가려진 느낌** |
| 로비 vs 인게임 | 로비=`_concept_final` 정면 스티커 · 인게임=**3/4~옆 · 눈 하나 · 검정 라인** (별도 장) |
| 크기 기준 | **항상 idle** (같은 캐릭터 모든 애니는 idle 체감 크기) |
| 스케일/오프셋 | JSON 값은 **원본팩(`_pre_scale_backup` / `_pre_offset_backup`) 대비 절대값** |
| 재생성 | **전체 프레임 재생성 선호**. 부분 얼굴 합성 비권장 (win 교훈) |
| 형식 | 512셀 시트 + JSON. 본 리깅/애니메이터 **없음** |
