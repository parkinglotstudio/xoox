## Attack A — 돌진 (헤어 변형) 【4장】

**연출:** 웅크리며 모은다 → **머리카락이 캐릭 시그니처 형태로 감긴 채** 날아간다 → 타격 → 풀리며 복귀.

| # | role | 순간 | duration 참고(향아) |
|---|------|------|---------------------|
| 0 | `crouch` | 힘 모음 · 몸 웅크림 (콘→둥글게) · **아직 풀 변형 전** | ~180ms |
| 1 | `fly` | 헤어 변형 돌진 (시그니처 실루엣) | ~140ms |
| 2 | `hit` | 임팩트 · 헤어볼 **진행쪽 살짝 짜부(타원)** · 스파크 OK · **적 없음** | ~160ms |
| 3 | `return` | 변형 풀리며 콘/자세 복귀 | ~220ms |

`loop: false` · 셀 512 · pivot `bottom-center` · idle 높이 맞춤.

### fly 연출 규칙 【확정 · 유비에서 합의】

| 해야 함 | 내용 |
|--------|------|
| **머리카락으로 읽히기** | 가닥·윤기·록 질감 유지. 살아 있는 헤어 |
| **시그니처 암시** | 그 장수의 대표 이미지(상투·복숭아·언월 등)를 **실루엣으로만** 은은히 |
| 향아 패턴 | 몸이 헤어에 감기고 얼굴이 삐져나옴 (hairball 계열) |

| 하면 안 됨 | 이유 |
|-----------|------|
| **노골적 오브젝트** | 과일·무기·투구를 그대로 그리면 머리카락이 안 보임 (유비 peach v1 실패) |
| 팔·손으로 때리기 | 원칙 위배 |
| 적/UI 넣기 | 키포즈 오염 |

### 제작 순서 (장수마다)

1. **향아** `attack` 이미지·엔진 팩을 **먼저 읽기**  
2. 그 장수 **idle 기준본** + 시그니처 모티프 확인  
3. **`fly` 스틸 1장**부터 합의 (변형의 얼굴)  
4. `crouch` → `hit` → `return` 3장  
5. 엔진 빌드 · idle 스케일 맞춤 · studio 검수

## Attack B — 제자리 마법 캐스팅 【확정 · 2026-07-23】

**한 줄:** 자리 不動. 몸이 거의 고정된 채 **머리카락이 위로 올라가는** 캐스팅.  
향아 peak 루프를 **왕복 캐스팅**으로 확장한 장수 공통 연출.

### 재생 흐름 (고유 그림 vs 시트)

```
기본 idle → 중간(상승) → 최종 캐스팅A → 최종 캐스팅B → 중간(동일) → 기본 idle
```

| 구간 | 소스 | 그릴까? |
|------|------|---------|
| 기본 idle | 기존 `ingame_idle` open | 재사용 (안 그림) |
| **중간** | `mid` — 헤어가 위로 올라가는 **중간** | **신규 1장** |
| **최종 캐스팅** | `peak` + `peak_loop` (정점 · 헤어만 미세) | **신규 2장** |
| 중간 복귀 | `mid` 재사용 | — |
| idle 복귀 | idle open 재사용 | — |

→ **새로 그릴 고유 컷 = 3장** (`mid` · `peak` · `peak_loop`)

### 연출 규칙

| 항목 | 내용 |
|------|------|
| 몸 | idle과 같은 원뿔·자리 · **거의 고정** |
| 헤어 | 위로 상승 · 시그니처 암시는 **은은** · 머리카락 질감 유지 |
| 표정 | **공격/캐스팅 표정** (웃음 금지) |
| peak_loop | peak와 몸·얼굴 동일 · 헤어가 **위↔아래**로 분명히 통통 (끝이 안 움직이면 실패) |
| hit 짜부 | fly의 둥근 말림 → 부딪힌 쪽이 **살짝 납작** (과한 찌그러짐 X) |

향아 참고: `hyanga/engine/attack_b/` (peak↔peak_loop). 장수는 mid를 넣어 왕복.
