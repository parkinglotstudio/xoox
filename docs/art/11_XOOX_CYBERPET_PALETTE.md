## 3. 공통 문법 (캐릭·환경 둘 다)

1. **바탕은 어둡다.** 키비주얼은 순흑 `#000000`. 로비/월드는 네이비 밤(`#030D18`~`#071726`). 흰 스튜디오 금지.
2. **아웃라인** 진한 검정. 셀셰이딩. 포토리얼 털/금속 금지.
3. **텍스처** 점묘·해칭·스크래치. 매끈한 새제품 금지.
4. **유기 vs 기계** 한 화면에 같이. 털/나무 부두 vs 판금/케이블.
5. **발광 = 생명색.** 눈·코어·귀 안·꼬리 끝·발끝, 또는 건물 슬릿·패널. **면 전체를 네온으로 칠하지 않음.** 개체당 메인 1색 + 보조 최대 1색.
6. **실루엣이 먼저 읽힌다.** 캐릭은 품종, 로비는 「부두 + 판금 타워」.
7. **중고감.** 볼트·리벳·패널 라인·칩핑.

피함: 보라 네온 일색 · 고딕 성 · 오두막 무지개 · 리얼 메가시티 · 블룸으로 형태 뭉개기.

## 6. 정화 전 / 후

| 상태 | 무엇이 바뀌나 | 무엇이 안 바뀌나 |
|---|---|---|
| **오염 (로비 before)** | 바탕이 밤·안개. 색이 슬릿으로만. 시안이 탁함(`#106F83`) | 판금 타워 구도, 부두, 네온 삼원 |
| **정화 완료 (캐릭 키비주얼)** | 흑바탕에서 바디 색이 면으로 읽힘. 코어가 `#0DDD79` / `#0FBEC7`처럼 또렷 | 같은 부품 언어(코어·귀·볼트) |
| **로비 after (현행)** | 같은 구도, 인상주의 다채 색면 (인게임 정화 하늘과 맞춤, 2026-08-27) | 부두→군도 카메라 |

캐릭 정화 완료 ≠ 인상주의 유화. 유화는 **땅/하늘이 숨 쉴 때**의 레이어이고, 펫·UI 크롬은 항상 이 문서 §3~5의 셀+네온 점이다.

## 7. 작업 체크 (새로 그리기 전)

- [ ] §2 이미지 중 **해당 레이어 원본을 열었는가**
- [ ] 여정 하늘·원경이면 [`gdd/46`](../gdd/46_여정3D_원경_맵컨셉.md)과 v16을 열었는가 (하늘/산 분리 작화 아닌가)
- [ ] 어두운 바탕인가 (흰/회색 스튜디오 아닌가)
- [ ] 네온이 면이 아니라 점·띠인가
- [ ] 시안이 주 생명색인가. 마젠타·옐로는 포인트인가
- [ ] 보라 범벅·고딕 성·오두막 무지개를 기본 톤으로 쓰지 않았는가
- [ ] 발광색이 3개 이상 동시에 면을 차지하지 않는가
- [ ] 마모/볼트/패널이 있는가
- [ ] hex가 이 표 근처인가 (감으로 새 네온을 만들지 않았는가)

## 8. 에이전트 규칙

1. 아트·UI 생성/수정 전에 이 파일을 읽는다.
2. 이미지 생성 시 `reference_image_paths`에 §2 해당 PNG를 넣는다.
3. 새 팔레트를 문서 없이 하드코딩하지 않는다. 예외 색이 필요하면 이 표에 행을 추가한 뒤 쓴다.
4. `37`·코지 컨셉 PNG(`lobby_layout_concept_landscape.png`)는 레이어 구조 참고만. 색의 정본이 아님.
