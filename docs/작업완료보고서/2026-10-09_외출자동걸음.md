# 작업 완료 보고서 — 외출 자동 걸음

1. 날짜·시간: 2026-10-09 20:03
2. 작업 요약: 영상 연출을 지금 외출에 붙였다. 싸우는 동안 나오던 「전진」「후퇴」를 없애고, 무리가 시작되면 루온과 리아가 앞으로 한 걸음(4m) 스스로 걷게 했다. 위에는 「오염이 밀려온다」가 잠깐 뜬다. 그때 고르는 것은 성장 카드뿐이다.
3. 변경·생성 파일
   - `src/main.ts`
   - `docs/gdd/58_층연출_챕터와시스템.md`
   - `docs/gdd/11_CHANGELOG.md`
   - `docs/reports/20261009_작업보고서_외출자동걸음.md`
4. 확인·검증: `http://localhost:5173/` 에서 게임 스타트 → 스킵 → 외출. 권총, 정화 진지, 가운데, 투석을 눌렀다. 싸움 버튼은 연사·사선·관통만 있었고 전진·후퇴는 없었다. 연사를 고르자 「성장했다 / 연사」 카드가 떴고, 숲에서 둘이 쏘는 장면도 보였다. 걸음은 약 0.8초라 캡처 전에 끝났다.
5. 남은 이슈: 지금은 한 걸음이다. 영상처럼 계속 걸어가면 정화 진지와 포탑이 뒤에 남는다. 더 멀리 걷게 할지는 보고 말해 주면 된다.
